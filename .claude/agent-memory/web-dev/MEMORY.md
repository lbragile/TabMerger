# web-dev Memory Index

- [Flex img collapse on mobile](learnings/navbar-flex-collapse.md) — next/image in nested flex rows can collapse to 0x0 at narrow viewports without shrink-0; verify logo/icons at 375px with actual boundingBox checks, not just screenshots.
- [CHANGELOG.md parsing](learnings/changelog-md-parsing.md) — build-time parser for semantic-release's generated changelog: path resolution from packages/web, angular-preset heading/section format, the `**scope:**` double-colon trap, ENOENT-as-empty-not-error.
- [Module-scope SDK construction crash](learnings/module-scope-sdk-construction-crash.md) — Stripe/Supabase clients constructed with `!`-asserted env vars kill `next build` or every request; server.ts's client is reached from Navbar on every request too (not just build-safe), auth-js degrades getUser() to null rather than throwing, fail-loud-vs-degrade line, repro steps.
- [Playwright authenticated-project leak](learnings/playwright-authenticated-project-leak.md) — unrestricted specs run under every project; unauthenticated-redirect tests need `test.use({storageState:{cookies:[],origins:[]}})` per-describe or they flip meaning under `authenticated`; also `.env.local` isn't auto-loaded for the Playwright process locally.
- [Coming-soon flag + a11y heading name](learnings/coming-soon-flag-a11y-name.md) — never nest a "Coming soon" badge span inside a heading element, it breaks exact-match getByRole('heading') tests; also multiple agents touch the same pricing/dashboard files during the AI_ENABLED rollout, re-read before editing.
- [Sharing is fully client-side](share-bundle-pattern.md) — `lib/sharing.ts`, no API route (deleted 2026-09-26); matches the extension exactly, never reintroduce a server-side share route
- [RTL findBy hangs on duplicate text](learnings/rtl-findby-hangs-on-duplicate-text.md) — shadcn Select mirrors its label into a hidden native `<option selected>`; `findByText` on that label times out (not throws) because `waitFor` swallows "multiple elements" every poll — scope to `findByRole('combobox')` instead.
- [lucide-react has no brand icons](learnings/lucide-no-brand-icons.md) — a `Github` import compiles but is `undefined` at runtime ("invalid element type" that doesn't name the icon); inline the SVG mark instead, as `GitHubMark` in the beta page does
- [Firefox beta Blob rewrite](learnings/firefox-beta-blob-rewrite.md) — external Next.js rewrite passes upstream Content-Type/Cache-Control through; proxy.ts matcher exclusion; module-eval-time env gate testing pattern.
- [Multi-ID/multi-transport extension messaging](learnings/extension-messaging-multi-transport.md) — NODE_ENV==='test' vs 'development' dev-ID gating trap, module-scope cache pollution across tests causing silent multi-second timeouts, SYNC_AUTH's fire-and-forget undefined response, Firefox postMessage relay security (source/origin/requestId, never targetOrigin '*')
- [hasCloudSync gating helper](learnings/cloud-sync-gating-helper.md) — single `lib/cloudSync.ts` gate (paid tier + entitled status) for all dashboard/account sync UI; skip queries not just JSX; StatsOverview `showSyncStats` prop + grid reflow; existing test mocks need `status: 'active'` added once a page adopts it
- [og-preview fallback sources](learnings/og-preview-fallback-sources.md) — 60% baseline hit rate measurement, itemprop/JSON-LD/icon fallback chain + imageKind field, unquoted-attribute ATTR_RE fix, and the pattern of exporting pure extraction functions to unit-test a node:http(s)-based route without mocking the network
- [Web dev learnings (general)](web-dev-learnings.md) — dashboard E2EE decryption, Radix focus races, GA4/PostHog/Sentry setup, E2E auth fixture, share-link base64 `+` trap, set-state-in-effect boundaries, og-preview privacy and ReDoS fixes
- [TS strict + lazy useState initializer](learnings/learnings_ts_strict.md) — strict already on; read localStorage in a lazy `useState` initializer instead of setState in an effect
- [SYNC_AUTH via externally_connectable](learnings/sync-extension-auth-external-message.md) — web app forwards the Supabase session to the extension from `useSyncExtensionAuth` (mounted in SyncIndicator); tests must mock `auth.onAuthStateChange`
