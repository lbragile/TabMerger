Completed WCAG 2.1 AA accessibility audit. All fixes applied and lint passes.

**Why:** Requested full audit covering color contrast, keyboard nav, ARIA, semantic HTML, and images.

**How to apply:** Future component work should follow the patterns in `design-system-learnings.md`.

## Fixes applied

### Extension popup (`packages/extension/src/components/`)

**Tab.tsx**
- Outer row `<div tabIndex={0}>` now has `onKeyDown` to open tab on Enter/Space
- Note icon `<span>` → `<button>` with `aria-label="Edit tab note"`
- Reminder icon `<span>` → `<button>` with `aria-label="Edit tab reminder"`
- Chrome group tag: when `isNowOpen` → `<button>` with `aria-label="Reopen Chrome group: ..."`; when not → decorative `<span aria-label>`
- Delete X button → `aria-label={isNowOpen ? 'Close tab' : 'Remove tab'}`
- Drag handle → `aria-label="Drag to reorder tab"` (conditional on !selectionMode)

**Window.tsx**
- Window note icon `<span>` → `<button>` with `aria-label="Edit window note"`
- Star `<Button>` → `aria-label={starred ? 'Unstar window' : 'Star window'}`
- MoreHorizontal `<Button>` → `aria-label="More window options"`
- Drag handle → `aria-label="Drag to reorder window"`

**GroupItem.tsx**
- Color swatch `<button>` → `aria-label="Change group color"` + `focus-visible:ring-2`
- Star `<button>` → `aria-label={starred ? 'Unpin group' : 'Pin group'}` + `focus-visible:ring-2`
- Drag handle → `aria-label="Drag to reorder group"`

**Windows/index.tsx**
- Group note `<span>` → `<button>` (had aria-label but no tabIndex — not keyboard-reachable)
- Clock button → `aria-label="Remove N stale tabs"`
- MoreHorizontal → `aria-label="More group options"`

**SidePanel/index.tsx**
- Session restore button → `aria-label="Restore session: {session.name}"` for context

**SidePanel/GroupContextMenu.tsx**
- Wrapper `<div>` → added `role="button"` + `aria-label={group.name}` + `onKeyDown` for Enter/Space

**SelectionActionBar.tsx**
- Cancel X button: `title` → `aria-label="Cancel selection"`

### Web app (`packages/web/`)

**Navbar.tsx**
- `text-foreground/60` → `text-foreground/75` (4.4:1 → ~5.5:1 contrast, passes AA)
- Avatar dropdown trigger → `aria-label="Account menu"`

**Hero.tsx**
- Rating star SVG → `aria-hidden="true"` (decorative)

**FAQ.tsx**
- Added `aria-controls={id}` on accordion button, `id` on answer panel
- Added `aria-hidden="true"` on decorative ChevronDown icon

**ShareBundleContent.tsx**
- Pre-existing lint warning (unused eslint-disable directive) fixed by removing directive
