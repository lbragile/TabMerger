<QuickAnswer>

Open [TabMerger](/features), go to **Settings → Data** and press **Import file**. Choose a OneTab export or a plain list of links (`.txt`), a bookmarks file (`.html`) or a TabMerger backup (`.json`). TabMerger shows how many groups it found, and after you confirm, adds them next to your own. Each OneTab list and each top-level bookmarks folder becomes its own group.

</QuickAnswer>

<Section id="problem" title="Saved tabs, stuck somewhere else">

Years of OneTab lists. A bookmarks folder per trip. A backup from an old laptop. All of it is saved, none of it is searchable in one place, and moving it by hand, link by link, is the kind of job that never happens.

Import turns that job into one file and one click.

</Section>

<Section id="why" title="Why import works the way it does">

- **It only ever adds.** An import puts the file’s groups next to yours and never touches what you have, so trying a file is safe.
- **It asks first.** Before anything is added, TabMerger tells you how many groups it found in which file, and waits for your **Import** click.
- **Every entry is checked.** Only real web addresses come in. Bookmarklets, `javascript:` links and anything that isn’t an absolute address are skipped and counted, and the message afterwards says how many.
- **Structure is kept where the file has it.** A TabMerger backup brings back windows, names, colours, notes, stars and reminder times; the formats of other tools become one group per list or folder.
- **Your plan’s limits are checked up front.** On Free, an import that would go past 5 groups or 50 tabs stops before adding anything, and says what the file contains.

</Section>

Two details worth knowing:

- **Bookmarks:** only folders at the top level of the file become groups, and links sitting outside any folder are left out. In a full export from Chrome or Edge, the bookmarks bar arrives as one group (its subfolders folded in), while each folder kept in **Other bookmarks** or **Other favorites** becomes its own group.
- **TabMerger backups:** the file’s **Now Open** (the tabs that were open when it was exported) isn’t imported. Save open tabs into a group before exporting if you want them in the file.

</Section>

<Section id="steps" title="Import a file">

1. Open TabMerger, then **Settings** → **Data**.
2. Under **Import & export**, press **Import file** and choose your `.txt`, `.html` or `.json` file.
3. Check the count and press **Import**. The new groups appear in the sidebar; rename them as you like.

<Section id="habits" title="Good habits">

- **Rename imported groups** right away; “Imported 1” is only a placeholder.
- **Import big archives in parts** on Free, or upgrade first, since an import over the limits is stopped as a whole.
- **Keep a TabMerger export** as your own backup: **Export JSON** saves every group in one file. What’s inside is described in [exporting open tabs](/blog/export-open-tabs).
- **Sort after importing** with **Sort by title** or **Sort by URL** in the group’s **⋯** menu, and clear repeats with **Deduplicate tabs**.

</Section>
