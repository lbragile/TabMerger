<QuickAnswer>

כדי לשמור את כל הכרטיסיות הפתוחות בחלון הנוכחי בתיקיית סימניות חדשה, לוחצים על <bdi><Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd></bdi> (או <bdi><Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd></bdi> ב-Mac). זה עובד ב-Chrome, ב-Edge וב-Firefox. כדי שהכרטיסיות ייפתחו מחדש אוטומטית, מפעילים את **אני רוצה להמשיך מהמקום שבו הפסקתי** (<bdi dir="ltr">Continue where you left off</bdi>) ב-Chrome, את **Open tabs from the previous session** ב-Edge או את **פתיחת חלונות ולשוניות קודמות** (<bdi dir="ltr">Open previous windows and tabs</bdi>) ב-Firefox. כדי לשמור **את כל החלונות בבת אחת** ולחפש בכרטיסיות אחר כך, משתמשים ב-[TabMerger](/features): לחיצה אחת שומרת את כל החלונות הפתוחים בקבוצה בעלת שם.

</QuickAnswer>

<InstallCta>שומרים את כל החלונות הפתוחים בלחיצה אחת. חינם ל-Chrome, ל-Edge ול-Firefox.</InstallCta>

<Section id="bookmark" title="1. סימניות לכל הכרטיסיות בלחיצה אחת">

כל הדפדפנים הגדולים שומרים את הכרטיסיות של חלון כתיקייה של סימניות. התיקייה נשארת עד שמוחקים אותה, ומסתנכרנת אם התחברתם לדפדפן.

<Section id="startup" title="2. לגרום לדפדפן לפתוח הכול מחדש בהפעלה">

אם הפעלות מחדש ועדכונים הם מה שמעלים לכם כרטיסיות, אפשר לתת לדפדפן להחזיר את הסשן. צילומי המסך מציגים את הממשק באנגלית; כשהשם בעברית שונה, השם באנגלית מופיע בסוגריים בפעם הראשונה.

<BrowserPanels section="startup">
<BrowserPanel browser="chrome">

ב-Chrome: **הגדרות ← כשפותחים את הדפדפן ← אני רוצה להמשיך מהמקום שבו הפסקתי** (<bdi dir="ltr">Settings → On startup → Continue where you left off</bdi>). אפשר גם להדביק את `chrome://settings/onStartup` בשורת הכתובת.

<AnnotatedFigure src="/blog/save-all-open-tabs/chrome-startup-setting.webp" alt="ההגדרות של Chrome בקטע On startup (כשפותחים את הדפדפן), כשהאפשרות Continue where you left off (אני רוצה להמשיך מהמקום שבו הפסקתי) מסומנת" width={1600} height={655} boxes={[{ id: 'startup-option' }]} source="chrome://settings/onStartup · Chrome 157.0.8103.79">ההגדרה On startup (כשפותחים את הדפדפן) ב-Chrome, כשהיא מוגדרת לפתוח מחדש את הסשן האחרון.</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="edge">

ב-Edge: **הגדרות** ← <bdi dir="ltr">**Start, home, and new tab page → On startup → Open tabs from the previous session**</bdi>. אפשר גם להדביק את `edge://settings/startHomeNTP` בשורת הכתובת.

<AnnotatedFigure src="/blog/save-all-open-tabs/edge-startup-setting.webp" alt="ההגדרות של Edge בקטע Start, home, and new tab page, כשהאפשרות Open tabs from the previous session מסומנת" width={1600} height={636} boxes={[{ id: 'startup-option' }]} source="edge://settings/startHomeNTP · Edge 157.0.4341.60">ההגדרות Start, home, and new tab page ב-Edge, כשהן מוגדרות לפתוח מחדש את הסשן האחרון.</AnnotatedFigure>

</BrowserPanel>
