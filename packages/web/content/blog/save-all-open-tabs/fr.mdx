<QuickAnswer>

Pour enregistrer tous les onglets ouverts, appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> sur Mac) : chaque onglet de la fenêtre active devient un favori dans un nouveau dossier. Cela fonctionne dans Chrome, Edge et Firefox. Pour que les onglets se rouvrent tout seuls, activez **Reprendre où vous avez arrêté** (« Continue where you left off », Chrome), **Open tabs from the previous session** (Edge) ou **Ouvrir les fenêtres et onglets précédents** (« Open previous windows and tabs », Firefox). Pour enregistrer **toutes les fenêtres d’un coup** et retrouver les onglets plus tard par une recherche, utilisez [TabMerger](/features) : un clic enregistre toutes vos fenêtres ouvertes dans un groupe nommé.

</QuickAnswer>

<Section id="bookmark" title="1. Mettre tous les onglets en favoris d’un seul raccourci">

Tous les grands navigateurs enregistrent les onglets d’une fenêtre sous forme de dossier de favoris. Le dossier reste jusqu’à ce que vous le supprimiez, et il se synchronise si vous êtes connecté au navigateur.

Les captures des navigateurs montrent l’interface en anglais. Quand le libellé français diffère, l’anglais est indiqué entre parenthèses la première fois.

<BrowserPanels section="bookmark">
<BrowserPanel browser="chrome">

1. Cliquez sur n’importe quel onglet de la fenêtre à conserver.
2. Appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> sur Mac).
3. Nommez le dossier, choisissez son emplacement et cliquez sur Enregistrer.
4. Pour les rouvrir plus tard, appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>, trouvez le dossier et ouvrez tous ses favoris.

<Section id="closed" title="3. Récupérer des onglets déjà fermés">

Appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>) pour rouvrir le dernier onglet ou la dernière fenêtre fermés ; appuyez de nouveau pour remonter plus loin. Pour quelque chose de plus ancien, ouvrez l’historique avec <Kbd>Ctrl</Kbd>+<Kbd>H</Kbd>. Si tout le navigateur a planté ou s’est fermé, suivez notre guide pour [restaurer les onglets après un plantage](/blog/restore-tabs-after-crash).

<Section id="groups" title="4. Groupes d’onglets : utiles pour se concentrer, limités pour enregistrer">

- **Chrome** peut enregistrer un groupe et le rouvrir, mais les extensions ne voient pas un groupe enregistré une fois fermé ([API tabGroups](https://developer.chrome.com/docs/extensions/reference/api/tabGroups)).
- Les groupes de **Firefox** restent sur l’appareil et ne passent pas par Firefox Sync.
- **Edge** n’a plus de Collections depuis Edge 149 ([par quoi les remplacer](/blog/edge-collections-replacement)).

Notre [guide des groupes d’onglets de Chrome](/blog/chrome-tab-groups) explique pas à pas comment enregistrer, rouvrir et synchroniser des groupes.

<Section id="tabmerger" title="5. Enregistrer tous les onglets ouverts de toutes les fenêtres avec TabMerger">

Les méthodes intégrées couvrent chacune une fenêtre, un redémarrage ou un onglet fermé à la fois. [TabMerger](/features), notre extension gratuite pour Chrome, Edge et Firefox, liste toutes les fenêtres ouvertes sous **Ouverts maintenant** et les enregistre toutes dans un seul groupe.

<ScreenshotThemeToggle />

1. Cliquez sur **Ajouter un groupe** et donnez-lui un nom, par exemple « Onglets ouverts, 19 nov. » (« Open tabs, Nov 19 » sur les captures).
2. Ouvrez le menu **⋯** du groupe et choisissez **Fusionner avec l’actuel**, qui ajoute vos fenêtres de navigateur ouvertes. (*Remplacer par l’actuel* remplace plutôt les fenêtres du groupe.)
3. Fermez les fenêtres quand vous voulez. Le groupe garde les deux fenêtres et les dix onglets.

### Fermé par erreur ?

**Fermés récemment** garde chaque onglet et chaque fenêtre que vous fermez, classés par jour, avec une bande qui indique l’heure. L’offre gratuite les garde 2 jours, Pro 30. <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> cherche dans les onglets ouverts, enregistrés et fermés ; commencez par `closed:` pour ne chercher que les onglets fermés.
