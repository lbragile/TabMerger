<QuickAnswer>

Press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> on a Mac) to bookmark every tab in the current window into a new folder. It works in Chrome, Edge and Firefox. To reopen tabs automatically, turn on **Continue where you left off** (Chrome), **Open tabs from the previous session** (Edge) or **Open previous windows and tabs** (Firefox).

</QuickAnswer>

<Section id="bookmark" title="1. Bookmark all tabs in one keystroke">

Every major browser saves a window’s tabs as a folder of bookmarks. The folder stays until you delete it, and syncs if you’re signed in to the browser.

<BrowserPanels section="bookmark">
<BrowserPanel browser="chrome">

1. Click any tab in the window you want to keep.
2. Press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> on a Mac).
3. Name the folder, choose where it goes, and click Save.
4. To reopen later, press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>, find the folder and open all of its bookmarks.

<AnnotatedFigure src="/blog/save-all-open-tabs/chrome-bookmarks-folder.webp" alt="Chrome bookmark manager with the folder Tab manager research selected, listing six saved pages" width={1600} height={524} eager boxes={[{ id: 'folder' }]} source="chrome://bookmarks · Chrome 157.0.8103.79">Chrome’s bookmark manager after Ctrl+Shift+D: the new folder holds one bookmark per tab of the window.</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="edge">

1. Click any tab in the window you want to keep.
2. Press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> on a Mac). Edge saves the tabs as favorites in a new folder.
3. Name the folder and save it.
4. To reopen later, press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> for Favorites, find the folder and open all of them.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. Click any tab in the window you want to keep.
2. Press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> on a Mac) to bookmark all tabs.
3. Name the folder and click Save.
4. To reopen later, press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> to open the Library and open all of the folder’s bookmarks.

<Section id="startup" title="2. Make the browser reopen everything on startup">

If restarts and updates are what lose your tabs, let the browser bring the session back.

<BrowserPanels section="startup">
<BrowserPanel browser="chrome">

In Chrome: **Settings → On startup → Continue where you left off**. Or paste `chrome://settings/onStartup` into the address bar.

<AnnotatedFigure src="/blog/save-all-open-tabs/firefox-startup.webp" alt="Firefox Settings, Home and startup, with Open previous windows and tabs checked" width={940} height={760} boxes={[{ id: 'startup-option' }]} source="about:preferences#home · Firefox 159.0.1">Firefox 159 keeps the option under Home and startup; older guides say General.</AnnotatedFigure>

<Section id="groups" title="4. Tab groups: good for focus, limited for saving">

- **Chrome** can save a group and reopen it, but extensions can’t see a closed saved group ([tabGroups API](https://developer.chrome.com/docs/extensions/reference/api/tabGroups)).
- **Firefox** groups stay on the device and don’t travel with Firefox Sync.
- **Edge** no longer has Collections, starting with Edge 149.
