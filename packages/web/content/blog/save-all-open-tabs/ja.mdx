<QuickAnswer>

開いているタブをすべて保存するには、<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>（Mac では <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>）を押します。現在のウィンドウのタブがすべて、新しいブックマーク フォルダに保存されます。Chrome、Edge、Firefox のどれでも使えます。タブを自動で開き直したい場合は、Chrome の「前回開いていたページを開く」（Continue where you left off）、Edge の「Open tabs from the previous session」、Firefox の「前回のウィンドウとタブを開く」（Open previous windows and tabs）をオンにします。**すべてのウィンドウを一度に** 保存して、あとでタブを検索したいなら、[TabMerger](/features) を使いましょう。クリック一つで、開いているウィンドウをすべて名前付きのグループに保存できます。

</QuickAnswer>

<InstallCta>開いているウィンドウをワンクリックですべて保存。Chrome、Edge、Firefox 向けに無料です。</InstallCta>

<Section id="bookmark" title="1. キー操作一つですべてのタブをブックマーク">

主要なブラウザはどれも、ウィンドウのタブをまとめてブックマークのフォルダとして保存できます。フォルダは削除するまで残り、ブラウザにログインしていれば同期もされます。

<BrowserPanels section="bookmark">
<BrowserPanel browser="chrome">

1. 残したいウィンドウのタブをどれか一つクリックします。
2. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>（Mac では <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>）を押します。
3. フォルダに名前を付け、保存先を選んで「保存」をクリックします。
4. あとで開き直すときは <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> を押し、フォルダを探して中のブックマークをすべて開きます。

<AnnotatedFigure src="/blog/save-all-open-tabs/chrome-bookmarks-folder.webp" alt="Chrome のブックマーク マネージャ。フォルダ「Tab manager research」が選択され、保存した6ページが並んでいる" width={1600} height={524} eager boxes={[{ id: 'folder' }]} source="chrome://bookmarks · Chrome 157.0.8103.79">Ctrl+Shift+D を押した後の Chrome のブックマーク マネージャ（Bookmark Manager）。新しいフォルダに、ウィンドウのタブ1つにつき1つのブックマークが入っています。この記事のブラウザのスクリーンショットは英語版の画面です。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="edge">

1. 残したいウィンドウのタブをどれか一つクリックします。
2. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>（Mac では <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>）を押します。Edge はタブを新しいフォルダにお気に入り（Favorites）として保存します。
3. フォルダに名前を付けて保存します。
4. あとで開き直すときは <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> でお気に入りを開き、フォルダを探してすべて開きます。

<AnnotatedFigure src="/blog/save-all-open-tabs/edge-bookmarks-folder.webp" alt="Edge のお気に入り（Favorites）。フォルダ「Tab manager research」が開き、6ページとそのアドレスが並んでいる" width={1600} height={553} boxes={[{ id: 'folder' }]} source="edge://favorites · Edge 157.0.4341.60">同じショートカットを押した後の Edge のお気に入り。タブが新しいフォルダにお気に入りとして保存されています。</AnnotatedFigure>

3. フォルダに名前を付けて「保存」をクリックします。
4. あとで開き直すときは <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> で「ブラウジングライブラリー」（Library）ウィンドウを開き、フォルダのブックマークをすべて開きます。

<Section id="startup" title="2. 起動時にすべてを開き直すようにする">

再起動やアップデートでタブが消えてしまうなら、ブラウザに前回のセッションを復元させましょう。

<BrowserPanels section="startup">
<BrowserPanel browser="chrome">

Chrome では **設定 → 起動時 → 前回開いていたページを開く**（Settings → On startup → Continue where you left off）を選びます。アドレスバーに `chrome://settings/onStartup` を貼り付けても開けます。

<AnnotatedFigure src="/blog/save-all-open-tabs/chrome-startup-setting.webp" alt="Chrome の設定の「On startup」（起動時）で「Continue where you left off」（前回開いていたページを開く）が選択されている" width={1600} height={655} boxes={[{ id: 'startup-option' }]} source="chrome://settings/onStartup · Chrome 157.0.8103.79">前回のセッションを開き直すように設定した、Chrome の「起動時」。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="edge">

Edge では **設定 →「Start, home, and new tab page」→「On startup」→「Open tabs from the previous session」** を選びます。アドレスバーに `edge://settings/startHomeNTP` を貼り付けても開けます。

<AnnotatedFigure src="/blog/save-all-open-tabs/edge-startup-setting.webp" alt="Edge の設定の「Start, home, and new tab page」で「Open tabs from the previous session」が選択されている" width={1600} height={636} boxes={[{ id: 'startup-option' }]} source="edge://settings/startHomeNTP · Edge 157.0.4341.60">前回のセッションを開き直すように設定した、Edge の「Start, home, and new tab page」。</AnnotatedFigure>

<BrowserPanel browser="firefox">

<Section id="closed" title="3. 閉じてしまったタブを取り戻す">

<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>（<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>）を押すと、最後に閉じたタブかウィンドウが開き直します。続けて押すと、さらに前に閉じたものへさかのぼります。もっと前のものは <Kbd>Ctrl</Kbd>+<Kbd>H</Kbd> で履歴を開いて探します。ブラウザ全体がクラッシュしたり終了したりした場合は、[クラッシュ後にタブを復元する方法](/blog/restore-tabs-after-crash)の手順に沿って進めてください。

<Section id="groups" title="4. タブグループ：集中には便利、保存には不向き">

- **Chrome** ではグループを保存して開き直せますが、閉じた保存済みグループは拡張機能からは見えません（[tabGroups API](https://developer.chrome.com/docs/extensions/reference/api/tabGroups)）。
- **Firefox** のグループはそのデバイスにだけ残り、Firefox Sync では同期されません。
- **Edge** のコレクションは Edge 149 で廃止されました（[代わりに使えるもの](/blog/edge-collections-replacement)）。

グループの保存、開き直し、同期のしかたは、[Chrome のタブグループ ガイド](/blog/chrome-tab-groups)で順を追って説明しています。

<Section id="tabmerger" title="5. TabMerger ですべてのウィンドウを一度に保存する">

ブラウザに標準で備わっている方法は、どれも一度に扱えるのがウィンドウ1つ、再起動1回分、閉じたタブ1つまでです。Chrome、Edge、Firefox 向けの無料拡張機能 [TabMerger](/features) なら、開いているウィンドウがすべて **現在開いているタブ** に表示され、それらをまとめて一つのグループに保存できます。

<ScreenshotThemeToggle />

1. **グループを追加** をクリックし、「開いているタブ 11/19」のような名前を付けます（スクリーンショットでは「Open tabs, Nov 19」）。
2. グループの **⋯** メニューを開き、**現在の内容と統合** を選びます。開いているブラウザのウィンドウがこのグループに追加されます（「現在の内容で置き換え」を選ぶと、グループのウィンドウが入れ替わります）。
3. あとはいつウィンドウを閉じてもかまいません。グループには2つのウィンドウと10個のタブがすべて残ります。

### スナップショットと自動保存
