<QuickAnswer>

要保存所有打开的标签页，请按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>（Mac 上按 <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>），当前窗口中的每个标签页都会存入一个新的书签文件夹。这在 Chrome、Edge 和 Firefox 中都适用。如果想让标签页自动重新打开，请开启 Chrome 的“继续浏览上次打开的网页”（Continue where you left off）、Edge 的“Open tabs from the previous session”或 Firefox 的“打开先前的窗口和标签页”（Open previous windows and tabs）。如果想 **一次保存所有窗口**，并在以后搜索其中的标签页，请使用 [TabMerger](/features)：点一下，就能把所有打开的窗口保存到一个命名分组中。

</QuickAnswer>

<Section id="bookmark" title="1. 一个快捷键为所有标签页添加书签">

各大浏览器都能把一个窗口的标签页保存为一个书签文件夹。文件夹会一直保留，直到你删除它；如果你在浏览器中登录了账号，它还会同步。

<BrowserPanels section="bookmark">
<BrowserPanel browser="chrome">

1. 在想保留的窗口中点击任意一个标签页。
2. 按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>（Mac 上按 <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>）。
3. 为文件夹命名，选择保存位置，然后点击“保存”。
4. 以后要重新打开时，按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>，找到该文件夹并打开其中的全部书签。

<AnnotatedFigure src="/blog/save-all-open-tabs/chrome-bookmarks-folder.webp" alt="Chrome 书签管理器，选中了文件夹 Tab manager research，其中列出六个已保存的网页" width={1600} height={524} eager boxes={[{ id: 'folder' }]} source="chrome://bookmarks · Chrome 157.0.8103.79">按下 Ctrl+Shift+D 后的 Chrome 书签管理器（Bookmark Manager）：新文件夹中，窗口里的每个标签页各对应一个书签。本文的浏览器截图均为英文界面。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="edge">

1. 在想保留的窗口中点击任意一个标签页。
2. 按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>（Mac 上按 <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>）。Edge 会把这些标签页作为收藏（Favorites）存入一个新文件夹。
3. 为文件夹命名并保存。
4. 以后要重新打开时，按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> 打开收藏夹，找到该文件夹并全部打开。

<AnnotatedFigure src="/blog/save-all-open-tabs/edge-bookmarks-folder.webp" alt="Edge 收藏夹（Favorites），打开了文件夹 Tab manager research，列出六个网页及其地址" width={1600} height={553} boxes={[{ id: 'folder' }]} source="edge://favorites · Edge 157.0.4341.60">按下同一快捷键后的 Edge 收藏夹：标签页已作为收藏存入新文件夹。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="firefox">

1. 在想保留的窗口中点击任意一个标签页。
2. 按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>（Mac 上按 <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>），为所有标签页添加书签。
3. 为文件夹命名，然后点击“保存”。
4. 以后要重新打开时，按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> 打开“我的足迹”（Library）窗口，再打开该文件夹中的全部书签。

<Catch>它**只保存当前窗口**。三个窗口就是三个文件夹。书签也只保留网址，滚动位置和表单中填写的内容都会丢失。</Catch>

<Section id="startup" title="2. 让浏览器在启动时重新打开所有内容">

如果重启和更新总让你丢失标签页，就让浏览器恢复上次的会话。

<BrowserPanel browser="chrome">

<Section id="closed" title="3. 找回已经关闭的标签页">

<Section id="groups" title="4. 标签页分组：适合专注，不适合保存">

- **Chrome** 可以保存分组并重新打开，但扩展程序看不到已关闭的已保存分组（[tabGroups API](https://developer.chrome.com/docs/extensions/reference/api/tabGroups)）。
- **Firefox** 的分组只留在本机，不会随 Firefox Sync 同步。
- **Edge** 从 149 版起不再提供集锦（[替代方案](/blog/edge-collections-replacement)）。

分组如何保存、重新打开和同步，我们的 [Chrome 标签页分组指南](/blog/chrome-tab-groups)有分步说明。

<Section id="tabmerger" title="5. 用 TabMerger 一次保存所有窗口">

浏览器自带的方法，每次只能处理一个窗口、一次重启或一个已关闭的标签页。[TabMerger](/features) 是我们为 Chrome、Edge 和 Firefox 开发的免费扩展程序，它会在 **当前打开** 中列出所有打开的窗口，并把它们全部保存到一个分组中。

<ScreenshotThemeToggle />

1. 点击 **添加分组**，并为它命名，例如“打开的标签页 11 月 19 日”（截图中为 Open tabs, Nov 19）。
2. 打开该分组的 **⋯** 菜单，选择 **与当前合并**，即可把打开的浏览器窗口添加到这个分组。（“替换为当前”则会用打开的窗口替换分组中原有的窗口。）
3. 之后随时可以关闭这些窗口。分组会保留两个窗口和全部十个标签页。
