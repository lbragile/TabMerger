<QuickAnswer>

**会话** 是某一时刻打开的全部窗口和标签页。浏览器会记住当前会话，以便重启后重新打开。**会话管理器** 是一种扩展，它按名称保存会话（通常是自动保存），之后再以窗口的形式重新打开。书签保存的是网页，会话管理器保存的是整个工作区。[TabMerger](/features) 两件事都能做：一键把所有打开的窗口保存到命名分组中，命名会话可以一起恢复，按计划自动保存，Pro 版还提供端到端加密同步。

</QuickAnswer>

<InstallCta>把每个窗口保存为命名分组，一键保存整个会话。Chrome、Edge 和 Firefox 均可免费使用。</InstallCta>

<Section id="session" title="什么是标签页会话？">

就是此刻打开的一切：每个窗口、窗口里按顺序排列的标签页，以及哪个标签页处于活动状态。浏览器一直在记录这些，用于两件事：

- **启动时恢复**：如果开启了恢复上次会话的启动选项，浏览器启动时会重新打开上一次的会话。各浏览器中这个选项的位置，见[浏览器崩溃后如何恢复标签页](/blog/restore-tabs-after-crash#prevent)。
- **最近关闭**：<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> 会逐个找回你关闭的标签页和窗口。

两者都只保留*最新的*状态。上周二的那些窗口已经不是浏览器能还给你的会话，只是历史记录里的几行而已。会话管理器填补的正是这个空缺。如果你已经丢了标签页，先看[浏览器崩溃后如何恢复标签页](/blog/restore-tabs-after-crash)。

</Section>

<Section id="need" title="你需要吗？">

如果你只在一个窗口里工作、标签页不超过二十几个，而且开启了启动设置，那多半不需要。[标签页太多时的整理习惯](/blog/manage-too-many-tabs)，再偶尔建个书签文件夹，就够用了。

如果下面任何一条听起来很熟悉，那多半需要：

- 你在多个项目之间切换，希望每个项目的窗口都能原样找回。
- 崩溃、更新或强制重启曾让你丢过标签页。
- 你想在一天结束时关掉所有内容，又不丢失任何东西。
- 你需要几天前的标签页，而不只是上一次会话里的。

</Section>

<Section id="look-for" title="好的会话管理器应该做到什么？">

- **自动保存**，而不只是在你想起来的时候：定时保存、关闭窗口时保存，或两者兼有。
- **保留结构**：窗口、标签页顺序，最好还有标签页分组。
- **灵活恢复**：整个会话、单个窗口或单个标签页都可以。
- 在所有已保存的会话中**搜索**，上周的标签页也能找到。
- **导出** 为能在别处读取的文件，让你永远不被锁定。（TabMerger 一键导出 JSON：[看看里面有什么](/blog/export-open-tabs)。）
- **清楚说明数据存放在哪里**。只存在本地很私密，但会随浏览器配置文件一起消失；同步更能防止数据丢失，但应当端到端加密。

一个技术细节：浏览器为扩展提供的已关闭标签页 API 很有限。`chrome.sessions` 最多只返回 25 个最近关闭的条目（`MAX_SESSION_RESULTS`）。能追溯得更远的会话管理器，都会自己留存记录。

</Section>

<Section id="examples" title="有哪些会话管理器？">

下面是几款成熟的工具，介绍依据它们自己的商店页面和网站（核对于 2026 年 11 月 20 日）：

- **Session Buddy**（Chrome）保存并恢复会话，还会保留过往会话的历史，用于崩溃后恢复。数据留在设备上；其商店页面写明没有同步功能。免费。
- **Tab Session Manager**（Chrome、Firefox、Edge）可以为会话设置名称和标签，在关闭窗口时以及按定时自动保存，并提供云同步。免费。
- **Tabs Outliner**（Chrome）把打开的和已保存的窗口放在同一棵树里，支持备注和崩溃恢复。免费，另有一次性付费的 Pro 升级。

想按价格、同步和加密横向对比九款工具，请看[最佳标签页管理扩展对比](/blog/best-tab-manager-extensions)或我们的[对比页面](/compare)。

</Section>

<Section id="tabmerger" title="TabMerger 中的会话如何运作">

[TabMerger](/features) 是我们为 Chrome、Edge 和 Firefox 打造的免费扩展，一款内置会话功能的标签页管理器。你打开的标签页会保存到命名的**分组**中；然后，**保存当前会话**（Save current session）会为这些已保存的分组拍一个带名称的快照，之后可以一起恢复。免费版在浏览器中保留 3 个会话；Pro 版不限会话数量，并在设备之间以端到端加密方式同步。

自动保存方面，**设置 → 数据 → 自动保存已打开的标签页**（Settings → Data → Auto-save open tabs）会按计划，或在标签页数量超过设定值时，把打开的标签页保存为一个新分组。导出的文件是纯 JSON。想让会话成为每天早上的固定流程，请看[用已保存的标签页开始一天的工作](/blog/start-your-workday-with-saved-tabs)。
