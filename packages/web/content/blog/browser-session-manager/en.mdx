<QuickAnswer>

A **session** is the set of windows and tabs you have open at one moment. Your browser keeps the current one so it can reopen it after a restart. A **session manager** is an extension that saves sessions under names, often automatically, and reopens them as windows later. Bookmarks save pages; a session manager saves the whole workspace. [TabMerger](/features) does both jobs in one: every open window saved into named groups in one click, named sessions you can restore together, auto-save on a schedule, and end-to-end encrypted sync on Pro.

<Section id="session" title="What is a tab session?">

Everything that’s open right now: each window, its tabs in order, and which tab is active. Browsers track this all the time, for two jobs:

- **Startup restore.** With the browser’s “previous session” startup option turned on, it reopens the last session when it starts. Where that option lives in each browser is in [how to restore tabs after a crash](/blog/restore-tabs-after-crash#prevent).
- **Recently closed.** <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> walks back through tabs and windows you closed.

Both keep only the *latest* state. Last Tuesday’s windows aren’t a session the browser can give you back; they’re just lines in History. That gap is what session managers fill. If you’ve already lost tabs, start with [how to restore tabs after a crash](/blog/restore-tabs-after-crash).

</Section>

Bookmarks win for pages you’ll keep for years. A session manager wins for work in progress: the twelve tabs of a half-finished task that you want back exactly as a window, not filed one by one. More in [tabs vs bookmarks](/blog/tabs-vs-bookmarks).

<Section id="need" title="Do you need one?">

Probably not if you work in one window, keep under a couple of dozen tabs and have the startup setting on. The [too-many-tabs routine](/blog/manage-too-many-tabs) and a bookmark folder now and then cover you.

You probably do if any of these sound familiar:

- You switch between projects and want each one’s windows back intact.
- A crash, update or forced restart has cost you tabs before.
- You want to close everything at the end of the day without losing it.
- You need tabs from days ago, not just from the last session.

</Section>

<Section id="look-for" title="What should a good session manager do?">

- **Save automatically**, not only when you remember to: on a timer, when a window closes, or both.
- **Keep the structure**: windows, tab order, and ideally tab groups.
- **Restore flexibly**: the whole session, one window, or one tab.
- **Search** across saved sessions, so a tab from last week is findable.
- **Export** to a file you can read elsewhere, so you’re never locked in. (TabMerger exports JSON in one click: [here’s what’s in it](/blog/export-open-tabs).)
- **Be clear about where data lives.** Local-only is private but dies with the profile; synced is safer from data loss, and should be end-to-end encrypted.

One technical note: the extension API browsers provide for closed tabs is small. `chrome.sessions` returns at most 25 recently closed entries (`MAX_SESSION_RESULTS`). Session managers that go further keep their own records.

</Section>

<Section id="examples" title="Which session managers are there?">

A few established ones, described from their own store listings and sites (checked Nov 20, 2026):

- **Session Buddy** (Chrome) saves and restores sessions and keeps a history of past sessions for crash recovery. Data stays on the device; its listing says there’s no sync. Free.
- **Tab Session Manager** (Chrome, Firefox, Edge) saves sessions with names and tags, auto-saves when a window closes and on a timer, and offers cloud sync. Free.
- **Tabs Outliner** (Chrome) keeps open and saved windows in one tree with notes and crash recovery. Free, with a one-time Pro upgrade.

For a side-by-side of nine tools on price, sync and encryption, see [the best tab manager extensions compared](/blog/best-tab-manager-extensions) or our [comparison page](/compare).

</Section>
