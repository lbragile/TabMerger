<QuickAnswer>

**セッション**とは、ある時点で開いているウィンドウとタブのまとまりです。ブラウザは再起動後に開き直せるよう、現在のセッションを覚えています。**セッションマネージャー**は、セッションに名前を付けて（多くは自動で）保存し、あとでウィンドウとして開き直せる拡張機能です。ブックマークが保存するのはページ、セッションマネージャーが保存するのは作業環境まるごとです。[TabMerger](/features) はその両方をこなします。開いているウィンドウをワンクリックで名前付きのグループに保存し、名前付きのセッションをまとめて復元でき、スケジュールで自動保存し、Pro ではエンドツーエンド暗号化で同期します。

</QuickAnswer>

<InstallCta>ウィンドウごとに名前付きのグループとして、セッションはまるごとワンクリックで保存。Chrome、Edge、Firefox に無料で追加できます。</InstallCta>

<Section id="session" title="タブのセッションとは？">

いま開いているものすべてです。各ウィンドウ、その中のタブの並び順、どのタブがアクティブか。ブラウザはこれを常に記録していて、用途は 2 つあります。

- **起動時の復元**：前回のセッションを開く起動時のオプションをオンにしていると、ブラウザは起動時に直前のセッションを開き直します。このオプションが各ブラウザのどこにあるかは、[クラッシュ後にタブを復元する方法](/blog/restore-tabs-after-crash#prevent)で説明しています。
- **最近閉じたタブ**：<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> を押すと、閉じたタブやウィンドウを新しい順にさかのぼって開き直せます。

どちらも残るのは*最新の*状態だけです。先週火曜日のウィンドウは、ブラウザが返してくれるセッションではなく、履歴に並ぶ行にすぎません。この隙間を埋めるのがセッションマネージャーです。すでにタブを失ってしまった場合は、まず[クラッシュ後にタブを復元する方法](/blog/restore-tabs-after-crash)をご覧ください。

</Section>

<Section id="need" title="必要かどうか">

1 つのウィンドウで作業し、タブは 20 数個まで、起動時の設定もオンにしているなら、おそらく不要です。[タブが多すぎるときの整理術](/blog/manage-too-many-tabs)と、ときどきブックマークフォルダを作るくらいで十分です。

次のどれかに心当たりがあるなら、おそらく必要です。

- プロジェクトを切り替えるたびに、それぞれのウィンドウをそのまま取り戻したい。
- クラッシュやアップデート、強制再起動でタブを失ったことがある。
- 1 日の終わりに、何も失わずにすべてを閉じたい。
- 直前のセッションだけでなく、数日前のタブも必要になる。

</Section>

<Section id="look-for" title="良いセッションマネージャーに必要なことは？">

- **自動で保存する**こと。思い出したときだけでなく、一定間隔で、ウィンドウを閉じたときに、またはその両方で。
- **構成を保つ**こと。ウィンドウ、タブの順序、できればタブグループも。
- **柔軟に復元できる**こと。セッション全体、1 つのウィンドウ、1 つのタブのどれでも。
- 保存したセッションを横断して**検索できる**こと。先週のタブも見つけられます。
- ほかの場所でも読めるファイルに**エクスポートできる**こと。特定のツールに縛られません（TabMerger はワンクリックで JSON をエクスポートできます。[中身はこちら](/blog/export-open-tabs)）。
- **データの保存場所が明確である**こと。ローカルのみならプライバシーは守られますが、プロファイルと一緒に消えます。同期すればデータ消失に強くなりますが、エンドツーエンド暗号化は必須です。

技術的な補足：閉じたタブについてブラウザが拡張機能に提供している API はごく限られています。`chrome.sessions` が返すのは、最近閉じた項目のうち最大 25 件です（`MAX_SESSION_RESULTS`）。それより前までさかのぼれるセッションマネージャーは、独自に記録を残しています。

</Section>

<Section id="examples" title="どんなセッションマネージャーがある？">

定番のものをいくつか、各ツールのストア掲載ページとサイトの記載に基づいて紹介します（2026年11月20日時点）。

- **Session Buddy**（Chrome）：セッションを保存・復元し、クラッシュからの復旧用に過去のセッションの履歴も残します。データはデバイス内にとどまり、掲載ページによると同期機能はありません。無料。
- **Tab Session Manager**（Chrome、Firefox、Edge）：セッションを名前とタグ付きで保存し、ウィンドウを閉じたときと一定間隔で自動保存し、クラウド同期にも対応しています。無料。
- **Tabs Outliner**（Chrome）：開いているウィンドウと保存したウィンドウを 1 つのツリーにまとめ、メモやクラッシュからの復旧にも対応しています。無料で、買い切りの Pro アップグレードがあります。

9 つのツールを価格、同期、暗号化で並べて比べるなら、[おすすめのタブ管理拡張機能の比較](/blog/best-tab-manager-extensions)または[比較ページ](/compare)をご覧ください。

</Section>

<Section id="tabmerger" title="TabMerger のセッションの仕組み">

[TabMerger](/features) は、Chrome、Edge、Firefox 向けの無料拡張機能で、セッション機能を内蔵したタブマネージャーです。開いているタブは名前付きの**グループ**に保存され、さらに**現在のセッションを保存**（Save current session）で、保存済みのグループに名前を付けてスナップショットとして残し、あとでまとめて復元できます。無料プランではブラウザに 3 つのセッションを保存でき、Pro ではセッション数が無制限になり、デバイス間でエンドツーエンド暗号化して同期します。

自動保存は、**設定 → データ → 開いているタブを自動保存**（Settings → Data → Auto-save open tabs）で設定できます。スケジュールに沿って、またはタブ数が一定を超えたときに、開いているタブを新しいグループとして保存します。エクスポートはプレーンな JSON です。セッションを毎朝の習慣にするには、[保存したタブで 1 日の仕事を始める](/blog/start-your-workday-with-saved-tabs)をご覧ください。

<InstallCta>Chrome、Edge、Firefox に無料で追加できます。使い始めるのにアカウントは不要です。</InstallCta>
