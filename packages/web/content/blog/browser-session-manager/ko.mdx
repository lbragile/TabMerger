<QuickAnswer>

**세션**은 어느 한 시점에 열려 있는 창과 탭 전체를 말합니다. 브라우저는 다시 시작한 뒤 열 수 있도록 현재 세션을 기억합니다. **세션 관리자**는 세션을 이름을 붙여, 대개는 자동으로 저장하고 나중에 창 그대로 다시 열어 주는 확장 프로그램입니다. 북마크는 페이지를 저장하고, 세션 관리자는 작업 공간 전체를 저장합니다. [TabMerger](/features)는 두 가지를 모두 해냅니다. 열린 창을 클릭 한 번으로 이름 있는 그룹에 모두 저장하고, 이름 있는 세션을 한꺼번에 복원하며, 일정에 따라 자동 저장하고, Pro에서는 엔드투엔드 암호화로 동기화합니다.

</QuickAnswer>

<InstallCta>창마다 이름 있는 그룹으로, 세션은 통째로 클릭 한 번에 저장하세요. Chrome, Edge, Firefox에서 무료입니다.</InstallCta>

<Section id="session" title="탭 세션이란?">

지금 열려 있는 모든 것입니다. 각 창, 그 안의 탭 순서, 어떤 탭이 활성 상태인지까지요. 브라우저는 이를 항상 추적하며, 두 가지 용도로 씁니다.

- **시작 시 복원.** 이전 세션을 다시 여는 시작 옵션을 켜 두면, 브라우저가 시작할 때 마지막 세션을 다시 엽니다. 브라우저별로 이 옵션이 어디 있는지는 [비정상 종료 후 탭 복원하는 방법](/blog/restore-tabs-after-crash#prevent)에서 설명합니다.
- **최근에 닫은 탭.** <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>를 누르면 닫은 탭과 창을 하나씩 거슬러 올라가며 다시 엽니다.

둘 다 *가장 최근* 상태만 남깁니다. 지난 화요일의 창들은 브라우저가 되돌려 줄 수 있는 세션이 아니라, 방문 기록 속 몇 줄일 뿐입니다. 바로 이 빈틈을 세션 관리자가 채웁니다. 이미 탭을 잃었다면 [비정상 종료 후 탭 복원하는 방법](/blog/restore-tabs-after-crash)부터 보세요.

</Section>

<Section id="need" title="꼭 필요할까?">

창 하나에서 작업하고, 탭을 스무 개 남짓 이하로 유지하며, 시작 설정을 켜 두었다면 아마 필요 없을 겁니다. [탭이 너무 많을 때의 정리 습관](/blog/manage-too-many-tabs)과 가끔 만드는 북마크 폴더면 충분합니다.

다음 중 하나라도 익숙하다면 아마 필요할 겁니다.

- 프로젝트를 오가며 프로젝트마다 창을 그대로 되찾고 싶다.
- 비정상 종료, 업데이트, 강제 재시작으로 탭을 잃은 적이 있다.
- 하루를 마칠 때 아무것도 잃지 않고 전부 닫고 싶다.
- 마지막 세션뿐 아니라 며칠 전 탭이 필요할 때가 있다.

</Section>

<Section id="look-for" title="좋은 세션 관리자라면 무엇을 해야 할까?">

- **자동으로 저장**해야 합니다. 생각났을 때만이 아니라, 일정 간격으로, 창을 닫을 때, 또는 둘 다요.
- **구성을 유지**해야 합니다. 창, 탭 순서, 가능하면 탭 그룹까지요.
- **유연하게 복원**할 수 있어야 합니다. 세션 전체, 창 하나, 탭 하나 모두요.
- 저장한 세션 전체를 **검색**할 수 있어야 지난주 탭도 찾을 수 있습니다.
- 다른 곳에서도 읽을 수 있는 파일로 **내보내기**가 돼야 특정 도구에 묶이지 않습니다. (TabMerger는 클릭 한 번으로 JSON을 내보냅니다. [파일에 담기는 내용](/blog/export-open-tabs)을 확인하세요.)
- **데이터가 어디에 저장되는지 분명**해야 합니다. 로컬에만 두면 사적이지만 프로필과 함께 사라지고, 동기화하면 데이터 손실에는 더 안전하지만 엔드투엔드 암호화가 돼야 합니다.

기술적인 참고 사항: 브라우저가 닫은 탭과 관련해 확장 프로그램에 제공하는 API는 작습니다. `chrome.sessions`는 최근에 닫은 항목을 최대 25개까지만 돌려줍니다(`MAX_SESSION_RESULTS`). 그보다 더 거슬러 올라가는 세션 관리자는 자체 기록을 남깁니다.

</Section>

<Section id="examples" title="어떤 세션 관리자가 있을까?">

자리 잡은 도구 몇 가지를 각자의 스토어 페이지와 사이트 내용을 바탕으로 소개합니다(2026년 11월 20일 확인).

- **Session Buddy**(Chrome)는 세션을 저장하고 복원하며, 비정상 종료에 대비해 지난 세션 기록을 남깁니다. 데이터는 기기에 남고, 스토어 페이지에 따르면 동기화는 없습니다. 무료.
- **Tab Session Manager**(Chrome, Firefox, Edge)는 세션을 이름과 태그로 저장하고, 창을 닫을 때와 일정 간격으로 자동 저장하며, 클라우드 동기화를 제공합니다. 무료.
- **Tabs Outliner**(Chrome)는 열린 창과 저장된 창을 메모, 비정상 종료 복구 기능과 함께 하나의 트리로 관리합니다. 무료이며, 한 번 결제하는 Pro 업그레이드가 있습니다.

아홉 가지 도구를 가격, 동기화, 암호화 기준으로 나란히 비교하려면 [최고의 탭 관리 확장 프로그램 비교](/blog/best-tab-manager-extensions)나 [비교 페이지](/compare)를 보세요.

</Section>

<Section id="tabmerger" title="TabMerger에서 세션이 작동하는 방식">

[TabMerger](/features)는 Chrome, Edge, Firefox용 무료 확장 프로그램으로, 세션 기능이 들어 있는 탭 관리자입니다. 열린 탭은 이름 있는 **그룹**에 저장되고, **현재 세션 저장**(Save current session)을 누르면 저장된 그룹들을 이름 있는 스냅샷으로 남겨 나중에 한꺼번에 복원할 수 있습니다. 무료에서는 브라우저에 세션 3개를 보관하고, Pro에서는 세션을 무제한으로 보관하며 기기 간에 엔드투엔드 암호화로 동기화합니다.
