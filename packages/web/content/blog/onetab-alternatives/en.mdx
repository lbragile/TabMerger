<QuickAnswer>

First, export: in OneTab choose **Export / Import URLs**, copy the text and save it as a `.txt` file, because uninstalling OneTab deletes its list. Then import it into **TabMerger**, which turns each list into a named group and adds what a single list can’t: windows kept apart, one search over open, saved and recently closed tabs, automatic saving, and end-to-end encrypted sync on Chrome, Edge and Firefox. Other options: **Tab Session Manager** for auto-saved sessions, **Session Buddy** for local crash recovery, **Toby** for a visual board.

<Section id="today" title="What does OneTab do today?">

Plenty of articles about OneTab are out of date, so here is what its own site says (checked Nov 20, 2026):

- One click turns your tabs into a list, to save memory. Restore them one by one or all at once.
- Lists survive closing OneTab, restarting the browser or computer, and browser crashes.
- It runs on Chrome, Firefox, Edge and Safari, with folders, notes and import and export.
- **It has sync now.** Backup & Sync is a paid yearly subscription: changes appear in your other browsers, with an automatic cloud backup that is end-to-end encrypted. One license covers up to 100 browsers or profiles, and stopping the subscription keeps your tabs; only syncing stops.
- **Uninstalling deletes your tabs.** OneTab’s troubleshooting note warns not to reinstall to fix a problem for exactly this reason.

So sync alone no longer sets the two apart. What TabMerger adds is structure: groups that keep windows apart, one search across open, saved and recently closed tabs, automatic saving of open tabs, and the same tool on Chrome, Edge and Firefox.

<Section id="export" title="How do I export my lists from OneTab?">

1. Open OneTab (its toolbar icon, or the OneTab page if it’s pinned).
2. Choose **Export / Import URLs**.
3. Copy the text in the export box (OneTab has a **Copy to clipboard** button).
4. Paste it into a plain-text editor (Notepad, or TextEdit set to plain text) and save it as `onetab.txt`.

The format is simple: one tab per line as `address | title`, and a blank line between lists. A line looks like `https://nodejs.org/en/docs | Documentation | Node.js`.

<Catch>the export holds addresses and titles. List names, notes and folders don’t come along, so jot down which list was which before you move.</Catch>

<Section id="import" title="How do I import a OneTab export into TabMerger?">

[TabMerger](/features), our free extension for Chrome, Edge and Firefox, reads the OneTab file directly. Nothing is uploaded: the file is read in your browser.

1. Open TabMerger, then **Settings → Data**.
2. Under **Import & export**, press **Import file** and choose your `.txt` file.
3. Confirm. Each OneTab list becomes its own group, named “Imported 1”, “Imported 2” and so on, with the tab titles kept.

Every format TabMerger imports is covered in [import tabs into TabMerger](/blog/import-tabs-into-tabmerger). A few details worth knowing:

- Lines that aren’t a full web address (or that would run a script) are skipped, and TabMerger tells you how many when the import finishes.
- On Free, an import that would take you past 5 groups or 50 tabs is stopped before anything is added. Pro has no limit.
- Keep OneTab installed until you’ve checked the groups. Then you can remove it.
