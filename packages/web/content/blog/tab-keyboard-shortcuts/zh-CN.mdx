<QuickAnswer>

<Kbd>Ctrl</Kbd>+<Kbd>Tab</Kbd> 和 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>Tab</Kbd> 切换到下一个和上一个标签页，<Kbd>Ctrl</Kbd>+<Kbd>1</Kbd>…<Kbd>8</Kbd> 按位置跳到某个标签页，<Kbd>Ctrl</Kbd>+<Kbd>W</Kbd> 关闭它，<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> 把它找回来。在 Windows 和 Linux 上，这些在 Chrome、Edge 和 Firefox 中都一样；在 Mac 上，用 <Kbd>⌘</Kbd> 代替 <Kbd>Ctrl</Kbd>。加上 [TabMerger](/features)，再用两个按键就能完成最费力的部分：直接用键盘保存标签页，以及用 <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> 找到任何标签页，无论是打开的、保存的还是关闭的。

</QuickAnswer>

<InstallCta>双手不离键盘就能保存标签页。Chrome、Edge 和 Firefox 均可免费使用。</InstallCta>

<Section id="reopen" title="误关了标签页，怎么重新打开？">

按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>（Mac 上为 <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>）。每按一次就再往前找回一步。能找回什么取决于浏览器：

<BrowserPanels section="reopen">
<BrowserPanel browser="chrome">

Chrome 会按关闭的顺序重新打开标签页*和*窗口，所以一直按，直到丢失的窗口回来。

</BrowserPanel>
<BrowserPanel browser="edge">

Edge 的文档说明 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> 用于重新打开最后关闭的标签页。要找回关闭的窗口，请打开历史记录（<Kbd>Ctrl</Kbd>+<Kbd>H</Kbd>），在 **Recently closed**（最近关闭）下查找。

</BrowserPanel>
<BrowserPanel browser="firefox">

Firefox 分开记录：<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> 用于标签页，<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>N</Kbd> 用于窗口。在 Firefox 159 中，<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> 绑定的命令会恢复最后关闭的标签页、窗口或会话，因此它也能找回上一次会话。

</BrowserPanel>
</BrowserPanels>

这个列表能追溯的范围有限。如果整个会话都丢了，请看[如何在崩溃后恢复标签页](/blog/restore-tabs-after-crash)。想从一开始就不丢失，在关闭大批内容之前先[保存所有打开的标签页](/blog/save-all-open-tabs)。

</Section>

<Section id="extensions" title="如何为扩展设置快捷键？">

扩展可以建议快捷键，但最终由浏览器决定：与浏览器自身快捷键冲突的建议按键会保持为 **Not set**（未设置），而且不会有任何提示。打开浏览器的快捷键页面，点击命令旁边的铅笔图标，然后按下你想要的按键。

<BrowserPanels section="extensions">
<BrowserPanel browser="chrome">

把 `chrome://extensions/shortcuts` 粘贴到地址栏。每个命令还有一个范围菜单：选择 **In Chrome**（仅在 Chrome 中），或选择 **Global**（全局），让它在 Chrome 不在前台时也能使用。

</BrowserPanel>
<BrowserPanel browser="edge">

把 `edge://extensions/shortcuts` 粘贴到地址栏。

Edge 把 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>K</Kbd>（复制标签页）、<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>U</Kbd>（Read Aloud，大声朗读）和 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>P</Kbd>（使用系统对话框打印）留给自己，所以建议其中任何一个的扩展命令在 Edge 158 中一开始就是 **Not set**。Edge 158 还会拒绝一些 Microsoft 列表中没有提到的 <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd> 按键，例如 <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd> 和 <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd>+<Kbd>Z</Kbd>。TabMerger 的保存命令避开了所有这些按键，因此新安装时四个命令都已设置：

<AnnotatedFigure src="/blog/tab-keyboard-shortcuts/edge-extension-shortcuts.webp" alt="Edge 扩展键盘快捷键页面中的 TabMerger：四个保存命令全部已设置，分别为 Alt+Shift+S、Alt+Shift+O、Alt+Shift+Comma 和 Alt+Shift+Period" width={852} height={460} boxes={[{ id: 'save-shortcuts' }]} source="edge://extensions/shortcuts · Edge 158.0.4370.33">在 Edge 158 中新安装的 TabMerger：四个保存命令都有各自的按键，无需修改。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="firefox">

打开 `about:addons`，点击齿轮菜单，选择 **管理扩展快捷键**（Manage Extension Shortcuts）。注意，在 Firefox 中 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>P</Kbd> 会打开隐私窗口，所以凡是建议这个按键的，都请另选一个。

</BrowserPanel>
</BrowserPanels>

<Section id="tabmerger" title="TabMerger 的按键">

[TabMerger](/features) 是我们为 Chrome、Edge 和 Firefox 打造的免费扩展，无需打开它就能直接用键盘保存标签页。它为四个保存命令各建议了一个按键，选择时避开了 Chrome、Edge 和 Firefox 自己使用的快捷键；你可以在浏览器的快捷键页面（见上文）中更改其中任何一个：

<ComparisonTable
  head={['建议按键', '保存内容']}
  keysColumn={0}
  rows={[
    ['Alt+Shift+S', '当前标签页'],
    ['Alt+Shift+O', '窗口中的其他所有标签页'],
    ['Alt+Shift+Comma', '左侧的标签页'],
    ['Alt+Shift+Period', '右侧的标签页'],
  ]}
/>

在 Mac 上，它们用 <Kbd>Control</Kbd>+<Kbd>Shift</Kbd> 代替 <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd>：<Kbd>Control</Kbd>+<Kbd>Shift</Kbd>+<Kbd>S</Kbd> 保存当前标签页。这些是新安装时的按键。更新不会改变快捷键，所以如果你在这些按键推出之前就安装了 TabMerger，它会保留原来的按键，包括处于 **Not set** 的那些：请在快捷键页面中设置它们。

在弹出窗口中，<Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>（<Kbd>⌘</Kbd>+<Kbd>K</Kbd>）可在一个列表中搜索已打开、已保存和最近关闭的标签页。
