<QuickAnswer>

<Kbd>Ctrl</Kbd>+<Kbd>Tab</Kbd> と <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>Tab</Kbd> で次と前のタブに切り替え、<Kbd>Ctrl</Kbd>+<Kbd>1</Kbd>…<Kbd>8</Kbd> で位置を指定してタブに移動、<Kbd>Ctrl</Kbd>+<Kbd>W</Kbd> で閉じて、<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> で元に戻せます。これは Windows と Linux の Chrome、Edge、Firefox で共通です。Mac では <Kbd>Ctrl</Kbd> の代わりに <Kbd>⌘</Kbd> を使います。[TabMerger](/features) を入れると、さらに 2 つのキーが大きな仕事をします。キーボードから直接タブを保存するキーと、開いている・保存した・閉じたタブを問わず見つけ出す <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> です。

</QuickAnswer>

<InstallCta>キーボードから手を離さずにタブを保存。Chrome、Edge、Firefox 向けに無料。</InstallCta>

<Section id="reopen" title="うっかり閉じたタブを開き直すには？">

<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>（Mac では <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>）を押します。押すたびに 1 つ前に戻ります。何が戻るかはブラウザによって違います。

<BrowserPanels section="reopen">
<BrowserPanel browser="chrome">

Chrome はタブ*と*ウィンドウを閉じた順に開き直すので、なくしたウィンドウが戻るまで押し続けてください。

</BrowserPanel>
<BrowserPanel browser="edge">

Edge のドキュメントでは、<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> は最後に閉じたタブを開き直すキーです。閉じたウィンドウは、履歴（<Kbd>Ctrl</Kbd>+<Kbd>H</Kbd>）を開いて「**Recently closed**」（最近閉じたもの）を確認してください。

</BrowserPanel>
<BrowserPanel browser="firefox">

Firefox はリストを分けています。タブは <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>、ウィンドウは <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>N</Kbd> です。Firefox 159 では <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd> が、最後に閉じたタブ、ウィンドウ、セッションのいずれかを復元するコマンドに割り当てられているので、前回のセッションを戻すこともあります。

</BrowserPanel>
</BrowserPanels>

このリストがさかのぼれる範囲には限りがあります。セッションをまるごと失ったときは、[クラッシュ後にタブを復元する方法](/blog/restore-tabs-after-crash)をご覧ください。そもそも失わないためには、大きなものを閉じる前に[開いているタブをすべて保存](/blog/save-all-open-tabs)しておきましょう。

</Section>

<Section id="extensions" title="拡張機能のショートカットを設定するには？">

拡張機能はショートカットを提案できますが、最終的に決めるのはブラウザです。ブラウザ自身のキーと重なる提案キーは、警告なしに「**Not set**」（未設定）のままになります。ブラウザのショートカット ページを開き、コマンドの横の鉛筆をクリックして、使いたいキーを押してください。

<BrowserPanels section="extensions">
<BrowserPanel browser="chrome">

アドレスバーに `chrome://extensions/shortcuts` を貼り付けます。各コマンドには範囲のメニューもあり、「**In Chrome**」（Chrome 内のみ）か、Chrome が前面にないときも動かすなら「**Global**」（どこでも）を選べます。

</BrowserPanel>
<BrowserPanel browser="edge">

アドレスバーに `edge://extensions/shortcuts` を貼り付けます。

Edge は <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>K</Kbd>（タブの複製）、<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>U</Kbd>（Read Aloud、音声読み上げ）、<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>P</Kbd>（システムのダイアログで印刷）を自分用に確保しているため、これらを提案する拡張機能のコマンドは Edge 158 では「**Not set**」で始まります。Edge 158 は、Microsoft の一覧に載っていない <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd> のキーもいくつか受け付けません。たとえば <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd> や <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd>+<Kbd>Z</Kbd> です。TabMerger の保存コマンドはこれらをすべて避けているので、新しくインストールすると 4 つとも設定済みになります。

<AnnotatedFigure src="/blog/tab-keyboard-shortcuts/edge-extension-shortcuts.webp" alt="Edge の拡張機能のキーボード ショートカット ページの TabMerger。4 つの保存コマンドすべてに Alt+Shift+S、Alt+Shift+O、Alt+Shift+Comma、Alt+Shift+Period が設定済み" width={852} height={460} boxes={[{ id: 'save-shortcuts' }]} source="edge://extensions/shortcuts · Edge 158.0.4370.33">Edge 158 に TabMerger を新しくインストールした状態。4 つの保存コマンドすべてにキーが設定され、直すところはありません。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="firefox">

`about:addons` を開き、歯車メニューをクリックして「**拡張機能のショートカットキーの管理**」（Manage Extension Shortcuts）を選びます。Firefox では <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>P</Kbd> がプライベートウィンドウを開くキーなので、これを提案するものには別のキーを選んでください。

</BrowserPanel>
</BrowserPanels>

<Catch>ショートカット ページは警告を出しません。ショートカットが「何もしない」ときは、まずここを確認しましょう。</Catch>

</Section>

<Section id="tabmerger" title="TabMerger のキー">

私たちの無料拡張機能 [TabMerger](/features) は、Chrome、Edge、Firefox で、開かずにキーボードから直接タブを保存できます。4 つの保存コマンドそれぞれにキーを提案しており、どれも Chrome、Edge、Firefox 自身のショートカットと重ならないように選んでいます。どのキーも、ブラウザのショートカット ページ（上記）で変更できます。

<ComparisonTable
  head={['提案キー', '保存する対象']}
  keysColumn={0}
  rows={[
    ['Alt+Shift+S', '現在のタブ'],
    ['Alt+Shift+O', 'ウィンドウ内のほかのタブすべて'],
    ['Alt+Shift+Comma', '左側のタブ'],
    ['Alt+Shift+Period', '右側のタブ'],
  ]}
/>

Mac では <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd> の代わりに <Kbd>Control</Kbd>+<Kbd>Shift</Kbd> を使います。たとえば <Kbd>Control</Kbd>+<Kbd>Shift</Kbd>+<Kbd>S</Kbd> で現在のタブを保存します。これは新しくインストールしたときのキーです。アップデートではショートカットは変わらないので、これらのキーより前に TabMerger をインストールしていた場合は、「**Not set**」も含めて元のキーのままです。ショートカット ページで設定してください。

ポップアップ内では、<Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>（<Kbd>⌘</Kbd>+<Kbd>K</Kbd>）で、開いているタブ、保存したタブ、最近閉じたタブをひとつのリストで検索できます。
