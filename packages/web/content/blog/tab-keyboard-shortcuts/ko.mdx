<QuickAnswer>

<Kbd>Ctrl</Kbd>+<Kbd>Tab</Kbd>과 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>Tab</Kbd>은 다음 탭과 이전 탭으로 전환하고, <Kbd>Ctrl</Kbd>+<Kbd>1</Kbd>…<Kbd>8</Kbd>은 위치로 탭에 이동하며, <Kbd>Ctrl</Kbd>+<Kbd>W</Kbd>는 탭을 닫고 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>는 다시 엽니다. Windows와 Linux의 Chrome, Edge, Firefox에서 똑같이 작동하며, Mac에서는 <Kbd>Ctrl</Kbd> 대신 <Kbd>⌘</Kbd>를 쓰면 됩니다. [TabMerger](/features)를 추가하면 키 두 개가 더 큰일을 맡습니다. 키보드에서 바로 탭을 저장하는 키와, 열린 탭이든 저장한 탭이든 닫은 탭이든 찾아 주는 <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>입니다.

</QuickAnswer>

<InstallCta>키보드에서 손을 떼지 않고 탭을 저장하세요. Chrome, Edge, Firefox용 무료.</InstallCta>

<Section id="reopen" title="실수로 닫은 탭을 다시 열려면 어떻게 하나요?">

<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>(Mac에서는 <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>)를 누르세요. 누를 때마다 한 단계씩 더 이전으로 돌아갑니다. 무엇이 돌아오는지는 브라우저마다 다릅니다.

<BrowserPanels section="reopen">
<BrowserPanel browser="chrome">

Chrome은 탭*과* 창을 닫은 순서대로 다시 열므로, 잃어버린 창이 돌아올 때까지 계속 누르세요.

</BrowserPanel>
<BrowserPanel browser="edge">

Edge 문서에 따르면 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>는 마지막으로 닫은 탭을 다시 엽니다. 닫은 창은 방문 기록(<Kbd>Ctrl</Kbd>+<Kbd>H</Kbd>)을 열고 **Recently closed**(최근에 닫은 항목)에서 찾으세요.

</BrowserPanel>
<BrowserPanel browser="firefox">

Firefox는 목록을 따로 관리합니다. 탭은 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>, 창은 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>N</Kbd>입니다. Firefox 159에서 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>는 마지막으로 닫은 탭, 창 또는 세션을 복원하는 명령에 연결되어 있어서 이전 세션을 되살릴 수도 있습니다.

</BrowserPanel>
</BrowserPanels>

이 목록은 어느 정도까지만 거슬러 올라갑니다. 세션 전체를 잃었다면 [충돌 후 탭을 복원하는 방법](/blog/restore-tabs-after-crash)을 참고하세요. 처음부터 잃지 않으려면 큰 작업을 닫기 전에 [열린 탭을 모두 저장](/blog/save-all-open-tabs)하세요.

<Section id="extensions" title="확장 프로그램 단축키는 어떻게 설정하나요?">

확장 프로그램은 단축키를 제안할 수 있지만 최종 결정은 브라우저가 합니다. 브라우저 자체 단축키와 겹치는 제안 키는 아무 경고 없이 **Not set**(설정 안 됨) 상태로 남습니다. 브라우저의 단축키 페이지를 열고 명령 옆의 연필을 클릭한 다음 원하는 키를 누르세요.

<BrowserPanels section="extensions">
<BrowserPanel browser="chrome">

주소창에 `chrome://extensions/shortcuts`를 붙여 넣으세요. 각 명령에는 범위 메뉴도 있어서 **In Chrome**(Chrome 안에서만)을 고르거나, Chrome이 앞에 있지 않을 때도 작동하게 하려면 **Global**(전체)을 고르면 됩니다.

</BrowserPanel>
<BrowserPanel browser="edge">

주소창에 `edge://extensions/shortcuts`를 붙여 넣으세요.

Edge는 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>K</Kbd>(탭 복제), <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>U</Kbd>(Read Aloud, 소리 내어 읽기), <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>P</Kbd>(시스템 대화 상자로 인쇄)를 직접 쓰기 때문에, 이 중 하나를 제안하는 확장 프로그램 명령은 Edge 158에서 **Not set** 상태로 시작합니다. Edge 158은 Microsoft 목록에 없는 일부 <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd> 키도 거부합니다. 예를 들면 <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd>와 <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd>+<Kbd>Z</Kbd>입니다. TabMerger의 저장 명령은 이런 키를 모두 피하므로, 새로 설치하면 네 개 모두 지정되어 있습니다.

<AnnotatedFigure src="/blog/tab-keyboard-shortcuts/edge-extension-shortcuts.webp" alt="Edge 확장 프로그램 키보드 단축키 페이지의 TabMerger: 저장 명령 네 개 모두 Alt+Shift+S, Alt+Shift+O, Alt+Shift+Comma, Alt+Shift+Period로 지정됨" width={852} height={460} boxes={[{ id: 'save-shortcuts' }]} source="edge://extensions/shortcuts · Edge 158.0.4370.33">Edge 158에 TabMerger를 새로 설치한 모습: 저장 명령 네 개 모두 키가 지정되어 있어 고칠 것이 없습니다.</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="firefox">

`about:addons`를 열고 톱니바퀴 메뉴를 클릭한 다음 **확장 기능 단축키 관리**(Manage Extension Shortcuts)를 선택하세요. Firefox에서는 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>P</Kbd>가 사생활 보호 창을 여는 키이므로, 이 키를 제안하는 항목에는 다른 키를 고르세요.

</BrowserPanel>
</BrowserPanels>

<Catch>단축키 페이지는 경고해 주지 않습니다. 단축키가 "아무 반응이 없다"면 먼저 여기를 확인하세요.</Catch>

</Section>

<Section id="tabmerger" title="TabMerger 단축키">

Chrome, Edge, Firefox용 무료 확장 프로그램인 [TabMerger](/features)는 열지 않고도 키보드에서 바로 탭을 저장합니다. 저장 명령 네 개마다 키를 제안하는데, Chrome, Edge, Firefox가 직접 쓰는 단축키와 겹치지 않도록 골랐습니다. 어느 키든 브라우저의 단축키 페이지(위 참고)에서 바꿀 수 있습니다.

<ComparisonTable
  head={['제안 키', '저장 대상']}
  keysColumn={0}
  rows={[
    ['Alt+Shift+S', '현재 탭'],
    ['Alt+Shift+O', '창의 다른 탭 전부'],
    ['Alt+Shift+Comma', '왼쪽 탭'],
    ['Alt+Shift+Period', '오른쪽 탭'],
  ]}
/>

Mac에서는 <Kbd>Alt</Kbd>+<Kbd>Shift</Kbd> 대신 <Kbd>Control</Kbd>+<Kbd>Shift</Kbd>를 씁니다. 예를 들어 <Kbd>Control</Kbd>+<Kbd>Shift</Kbd>+<Kbd>S</Kbd>는 현재 탭을 저장합니다. 이 키들은 새로 설치할 때 지정됩니다. 업데이트는 단축키를 바꾸지 않으므로, 이 키들이 나오기 전에 TabMerger를 설치했다면 **Not set** 상태까지 포함해 기존 키가 그대로 유지됩니다. 단축키 페이지에서 지정하세요.

팝업 안에서는 <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>(<Kbd>⌘</Kbd>+<Kbd>K</Kbd>)로 열린 탭, 저장한 탭, 최근에 닫은 탭을 한 목록에서 검색합니다.
