<QuickAnswer>

Les trois navigateurs ont désormais **des groupes d’onglets, une recherche d’onglets, des onglets verticaux et une vue partagée**. Chrome est en tête pour enregistrer et synchroniser les groupes, Edge met en veille les onglets inactifs par défaut, et Firefox est le seul à fermer lui-même les onglets en double. Aucun ne cherche dans vos onglets enregistrés et fermés, n’enregistre automatiquement vos fenêtres ni ne fonctionne d’un navigateur à l’autre : c’est la couche qu’ajoute [TabMerger](/features), à l’identique, à Chrome, Edge et Firefox.

</QuickAnswer>

<Section id="turn-on" title="Quels réglages intégrés valent la peine d’être activés ?">

<BrowserPanels section="turn-on">
<BrowserPanel browser="chrome">

1. **Économiseur de mémoire** (« Memory Saver ») : Paramètres → Performances (« Settings → Performance », `chrome://settings/performance`). Il est désactivé dans un nouveau profil.
2. **Onglets verticaux**, si vous en gardez beaucoup ouverts : faites un clic droit sur la barre d’onglets et choisissez **Afficher les onglets verticalement** (« Show Tabs Vertically »), ou Paramètres → Apparence → Position de l'onglet (« Settings → Appearance → Tab position »).
3. **Recherche dans les onglets** (« Tab Search ») : <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd>, ou tapez `@tabs` dans la barre d’adresse.

<BrowserPanel browser="edge">

1. Les **onglets en veille** (« Sleeping tabs ») sont déjà activés : réglez le délai dans Paramètres → System and performance → Performance.
2. Edge 158 a aussi des **onglets verticaux** et **Search tabs** (les deux figurent dans les textes de son interface) ; la liste des raccourcis de Microsoft n’attribue aucune touche à Search tabs.

<BrowserPanel browser="firefox">

1. **Onglets verticaux** : faites un clic droit sur la barre latérale et choisissez **Activer les onglets verticaux** (« Turn on Vertical Tabs »).
2. **Fermer les onglets en double** (« Close Duplicate Tabs ») et **Décharger l’onglet** (« Unload Tab ») figurent dans le menu contextuel de chaque onglet.
3. **Lister tous les onglets** (« List all tabs ») : <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd>.

<Section id="tabmerger" title="La couche manquante, dans chaque navigateur">

Le tableau a une ligne vide pour chaque navigateur : aucun ne garde vos onglets organisés **au-delà** de sa propre fenêtre, ni d’un navigateur à l’autre. [TabMerger](/features), si, et de la même façon dans Chrome, Edge et Firefox :

1. **Ouverts maintenant** affiche toutes les fenêtres ouvertes ; **Fusionner avec l’actuel** les enregistre toutes dans un groupe nommé en un clic.
2. <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> cherche à la fois dans les onglets ouverts, enregistrés et récemment fermés, avec les filtres `group:`, `window:`, `tag:` et `closed:`.
3. L’**enregistrement automatique** garde une copie récente de vos onglets selon un planning ; **Dédupliquer les onglets** supprime les doublons de toutes les fenêtres.
4. Avec [Pro](/pricing), vos groupes se synchronisent entre tous vos navigateurs, chiffrés de bout en bout.
