<QuickAnswer>

이제 세 브라우저 모두 **탭 그룹, 탭 검색, 세로 탭, 분할 화면**을 갖추고 있습니다. 그룹 저장과 동기화는 Chrome이 앞서고, Edge는 기본으로 쓰지 않는 탭을 절전 상태로 만들며, 중복 탭을 스스로 닫는 브라우저는 Firefox뿐입니다. 하지만 저장하거나 닫은 탭까지 검색하거나, 창을 자동 저장하거나, 브라우저를 넘나들며 작동하는 브라우저는 없습니다. 바로 이 레이어를 [TabMerger](/features)가 Chrome, Edge, Firefox에 똑같이 더합니다.

<Section id="turn-on" title="켜 둘 만한 기본 설정은 무엇인가요?">

<BrowserPanels section="turn-on">
<BrowserPanel browser="chrome">

1. **메모리 절약 모드**(Memory Saver): 설정 → 성능(Settings → Performance, `chrome://settings/performance`). 새 프로필에서는 꺼져 있습니다.
2. 탭을 많이 열어 둔다면 **세로 탭**: 탭 표시줄을 우클릭하고 **세로로 탭 표시**(Show Tabs Vertically)를 선택하거나, 설정 → 모양 → 탭 위치(Settings → Appearance → Tab position)에서 바꿉니다.
3. **탭 검색**(Tab Search): <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd>를 누르거나 주소창에 `@tabs`를 입력합니다.

</BrowserPanel>
<BrowserPanel browser="edge">

1. **절전 탭**(Sleeping tabs)은 이미 켜져 있습니다. 대기 시간은 설정 → System and performance → Performance에서 조정합니다.
2. Edge 158에는 **세로 탭**과 **Search tabs**도 있습니다(둘 다 UI 텍스트에 있음). 다만 Microsoft의 단축키 목록에는 Search tabs에 지정된 키가 없습니다.

<BrowserPanel browser="firefox">

1. **세로 탭**: 사이드바를 우클릭하고 **세로 탭 켜기**(Turn on Vertical Tabs)를 선택합니다.
2. **중복 탭 닫기**(Close Duplicate Tabs)와 **탭 언로드**(Unload Tab)는 모든 탭의 우클릭 메뉴에 있습니다.
3. **탭 전체 목록**(List all tabs): <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd>.

<Section id="tabmerger" title="모든 브라우저에 빠진 레이어를 더하세요">

비교표에는 브라우저마다 빈 행이 하나 있습니다. 어떤 브라우저도 자기 창을 **넘어서** 탭을 정리해 두거나 브라우저를 넘나들지 못합니다. [TabMerger](/features)는 Chrome, Edge, Firefox에서 똑같은 방식으로 이를 해냅니다.

1. **현재 열린 탭**에는 열려 있는 모든 창이 표시되고, **현재 상태와 합치기**로 클릭 한 번에 모두 이름 있는 그룹에 저장합니다.
2. <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>로 열린 탭, 저장한 탭, 최근에 닫은 탭을 한 번에 검색하고, `group:`, `window:`, `tag:`, `closed:` 필터도 쓸 수 있습니다.
3. **자동 저장**은 일정에 따라 탭의 최신 사본을 남기고, **중복 탭 제거**는 모든 창에서 반복된 탭을 정리합니다.
4. [Pro](/pricing)에서는 그룹이 모든 브라우저 사이에서 엔드투엔드 암호화로 동기화됩니다.
