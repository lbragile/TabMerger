<QuickAnswer>

如今三个浏览器都有 **标签页分组、标签页搜索、垂直标签页和分屏**。Chrome 在保存和同步分组方面领先，Edge 默认让闲置标签页进入睡眠，Firefox 则是唯一能自己关闭重复标签页的浏览器。但它们都无法搜索你保存过和关闭过的标签页，不会自动保存窗口，也不能跨浏览器使用，而这正是 [TabMerger](/features) 为 Chrome、Edge 和 Firefox 一模一样加上的一层。

</QuickAnswer>

<BrowserPanels section="turn-on">
<BrowserPanel browser="chrome">

1. **省内存模式**（Memory Saver）：设置 → 性能（Settings → Performance，`chrome://settings/performance`）。新的个人资料中它是关闭的。
2. 如果你常开很多标签页，可以用 **垂直标签页**：右键点击标签栏并选择 **垂直显示标签页**（Show Tabs Vertically），或前往 设置 → 外观 → 标签页位置（Settings → Appearance → Tab position）。
3. **标签页搜索**（Tab Search）：按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd>，或在地址栏中输入 `@tabs`。

<Section id="tabmerger" title="为每个浏览器补上缺少的一层">

对比表里，每个浏览器都有一行空着：没有一个能在浏览器自身窗口 **之外** 整理你的标签页，也不能跨浏览器。[TabMerger](/features) 可以，而且在 Chrome、Edge 和 Firefox 中用法相同：

1. **当前打开** 显示你打开的每个窗口；**与当前合并** 一键把它们全部保存到一个命名分组。
2. <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> 可同时搜索已打开、已保存和最近关闭的标签页，并支持 `group:`、`window:`、`tag:` 和 `closed:` 筛选器。
3. **自动保存** 按计划保留标签页的最新副本；**去除重复标签页** 清除每个窗口中的重复项。
4. 使用 [Pro](/pricing)，你的分组会在你所有的浏览器之间同步，并采用端到端加密。
