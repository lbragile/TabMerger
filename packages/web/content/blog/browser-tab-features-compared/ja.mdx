<QuickAnswer>

いまでは 3 つのブラウザすべてに **タブグループ、タブ検索、垂直タブ、分割表示** があります。グループの保存と同期では Chrome がリードし、Edge は使っていないタブを初期設定でスリープさせ、重複タブを自分で閉じられるのは Firefox だけです。ただし、保存したタブや閉じたタブまで検索できるもの、ウィンドウを自動保存するもの、ブラウザをまたいで使えるものはありません。この部分を Chrome、Edge、Firefox にまったく同じ形で追加するのが [TabMerger](/features) です。

</QuickAnswer>

<BrowserPanel browser="chrome">

1. **メモリセーバー**（Memory Saver）：設定 → パフォーマンス（Settings → Performance、`chrome://settings/performance`）。新しいプロファイルではオフになっています。
2. タブをたくさん開いているなら **垂直タブ**：タブバーを右クリックして **タブを縦方向に表示**（Show Tabs Vertically）を選ぶか、設定 → デザイン → タブの位置（Settings → Appearance → Tab position）で切り替えます。

<Section id="tabmerger" title="足りないレイヤーをすべてのブラウザに">

比較表では、どのブラウザにも空いている行があります。ブラウザ自身のウィンドウを **超えて** タブを整理しておく機能も、ブラウザをまたぐ機能もありません。[TabMerger](/features) なら、Chrome、Edge、Firefox で同じようにそれができます。

1. **現在開いているタブ** には開いているウィンドウがすべて表示されます。**現在の内容と統合** で、それらをワンクリックで名前付きのグループに保存できます。
2. <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> で、開いているタブ、保存したタブ、最近閉じたタブをまとめて検索できます。`group:`、`window:`、`tag:`、`closed:` のフィルタも使えます。
3. **自動保存** はスケジュールに沿ってタブの最新のコピーを残します。**重複タブを削除** はすべてのウィンドウから重複を取り除きます。
4. [Pro](/pricing) なら、グループはすべてのブラウザ間でエンドツーエンド暗号化して同期されます。
