<QuickAnswer>

Во всех трёх браузерах теперь есть **группы вкладок, поиск по вкладкам, вертикальные вкладки и разделённый экран**. Chrome впереди в сохранении и синхронизации групп, Edge по умолчанию усыпляет неактивные вкладки, а Firefox единственный сам закрывает дубликаты вкладок. Ни один не ищет по сохранённым и закрытым вкладкам, не сохраняет окна автоматически и не работает между браузерами. Этот слой и добавляет [TabMerger](/features), одинаково в Chrome, Edge и Firefox.

</QuickAnswer>

<Section id="turn-on" title="Какие встроенные настройки стоит включить?">

<BrowserPanels section="turn-on">
<BrowserPanel browser="chrome">

1. **Экономия памяти** (Memory Saver): Настройки → Производительность (Settings → Performance, `chrome://settings/performance`). В новом профиле она выключена.
2. **Вертикальные вкладки**, если вы держите много открытых: нажмите правой кнопкой мыши на панель вкладок и выберите **Показать вкладки вертикально** (Show Tabs Vertically) или Настройки → Внешний вид → Положение вкладки (Settings → Appearance → Tab position).
3. **Поиск по вкладкам** (Tab Search): <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd> или введите `@вкладки` в адресной строке (в английском интерфейсе Chrome это `@tabs`).

<Section id="tabmerger" title="Недостающий слой в каждом браузере">

В таблице у каждого браузера есть пустая строка: ни один не держит ваши вкладки в порядке **за пределами** собственного окна или между браузерами. [TabMerger](/features) держит, одинаково в Chrome, Edge и Firefox:

1. **Сейчас открыто** показывает все открытые окна; **Объединить с текущими** сохраняет их все в группу с названием одним щелчком.
2. <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> ищет сразу по открытым, сохранённым и недавно закрытым вкладкам, с фильтрами `group:`, `window:`, `tag:` и `closed:`.
3. **Автосохранение** по расписанию хранит свежую копию ваших вкладок; **Удалить дубликаты вкладок** убирает повторы из всех окон.
4. В [Pro](/pricing) ваши группы синхронизируются между всеми вашими браузерами со сквозным шифрованием.
