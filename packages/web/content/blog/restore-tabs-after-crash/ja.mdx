<QuickAnswer>

ブラウザを開き直して、ウィンドウが戻るまで <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>（Mac では <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>）を何度も押します。うまくいかなければ、履歴（<Kbd>Ctrl</Kbd>+<Kbd>H</Kbd>）を開いて **最近閉じた** タブから開き直します。Firefox では **履歴 → 以前のセッションを復元**（History → Restore Previous Session）を使います。それでも足りないときは **ほかの端末のタブ** を確認し、最後に履歴でページそのものを検索しましょう。次からは [TabMerger](/features) に開いているタブをスケジュールどおり自動保存させておけば、クラッシュで失うのはせいぜい数分ぶんで済みます。

</QuickAnswer>

<InstallCta>もうウィンドウをなくさない。開いているタブをスケジュールどおりに自動保存。Chrome、Edge、Firefox で無料。</InstallCta>

<Section id="first" title="1. ブラウザを開き直して、Ctrl+Shift+T を押す">

先に新しいタブを開かないでください。まっさらなウィンドウから始めれば、ブラウザの「最後に閉じた」一覧がそのまま戻ってきます。

<BrowserPanels section="first">
<BrowserPanel browser="chrome">

1. Chrome を起動します。ページの復元を提案されたら、受け入れます。
2. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>（Mac では <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>）を押します。Chrome のクラッシュに関するヘルプでも案内されている方法で、それまで開いていたタブが開き直します。
3. なくしたウィンドウの数だけ、もう一度押します。Chrome は閉じた順にタブとウィンドウを開き直します。

</BrowserPanel>
<BrowserPanel browser="edge">

1. Edge を起動します。ページの復元を提案されたら、受け入れます。
2. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>（Mac では <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>）を押すと、最後に閉じたタブが開き直します。続けて押すと、さらに前にさかのぼります。
3. ウィンドウが丸ごと見つからない場合は、手順 2 の履歴に進みましょう。

</BrowserPanel>
<BrowserPanel browser="firefox">

1. Firefox を起動します。ページの復元を提案されたら、受け入れます。
2. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>（Mac では <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>T</Kbd>）を押します。Firefox 159 では、このショートカットが「最後に閉じたタブ、ウィンドウ、またはセッションを復元する」コマンドに割り当てられているため、再起動のあとなら前回のセッション全体を戻せます。
3. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>N</Kbd> を押すと、閉じたウィンドウが開き直します。ウィンドウ1つにつき1回押します。

</BrowserPanel>
</BrowserPanels>

ショートカットの一覧は [タブのキーボード ショートカット早見表](/blog/tab-keyboard-shortcuts) にまとめています。

</Section>

<Section id="recover" title="2. 履歴から開き直す">

ショートカットで何も戻らなくても、ブラウザの履歴は何が開いていたかを覚えています。

<BrowserPanels section="recover">
<BrowserPanel browser="chrome">

1. **⋮ → 履歴**（History）をクリックします。サブメニューに、最近閉じたタブとウィンドウが表示されます。
2. ウィンドウをクリックすると、そのタブがすべて開き直します。
3. 見つからない場合は、<Kbd>Ctrl</Kbd>+<Kbd>H</Kbd> を押して、覚えているページを検索します。

</BrowserPanel>
<BrowserPanel browser="edge">

1. <Kbd>Ctrl</Kbd>+<Kbd>H</Kbd> を押して **履歴** を開きます。
2. **Recently closed**（最近閉じた項目）を選び、なくしたウィンドウやタブを開き直します。

<AnnotatedFigure src="/blog/save-all-open-tabs/edge-history.webp" alt="Edge の履歴ページ。サイドバーに「All」「Recently closed」「Tabs from other devices」" width={1600} height={611} boxes={[{ id: 'recently-closed' }]} source="edge://history · Edge 157.0.4341.60">Edge の履歴ページ。サイドバーに「Recently closed」があります。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="firefox">

1. **履歴**（History）メニューを開くか（<Kbd>Alt</Kbd> キーでメニューバーを表示）、**☰ → 履歴** を開きます。
2. **以前のセッションを復元**（Restore Previous Session）を選ぶと、前回のウィンドウがすべて戻ります。
3. または **最近閉じたウィンドウ** と **最近閉じたタブ** から選びます。

Firefox 自体がクラッシュした場合は、**セッションの復元**（Restore Session）ページが開くことがあります（「ご迷惑をおかけして申し訳ありません。」）。**前回のタブを表示**（View Previous Tabs）を使えば、**セッションを復元** を押す前に、クラッシュの原因になっていそうなタブのチェックを外せます。

</BrowserPanel>
</BrowserPanels>

<Section id="devices" title="3. ほかの端末で探す">

ログインして同期していたなら、なくしたタブがほかの端末にまだ表示されているかもしれません。

<BrowserPanels section="devices">
<BrowserPanel browser="chrome">

Chrome はほかの端末のタブを履歴に表示しますが、**履歴とタブ**（History and tabs）の同期がオンの場合に限ります。**設定 → Google の設定**（Settings → You and Google）でアカウント名を選び、**履歴とタブ** をオンにします。

</BrowserPanel>
<BrowserPanel browser="edge">

履歴（<Kbd>Ctrl</Kbd>+<Kbd>H</Kbd>）を開き、サイドバーで **Tabs from other devices**（ほかのデバイスのタブ）を選びます。

</BrowserPanel>
<BrowserPanel browser="firefox">

**Firefox View** を開き、**他の端末のタブ**（Tabs from other devices）を確認します。Firefox Sync で開いているタブの同期をオンにしておく必要があります。

</BrowserPanel>

<Section id="why" title="タブが復元されなかったのはなぜ？">

- **起動時の設定が新しいタブページを開くようになっている。** 起動のたびにタブを開き直すのは、「前回のセッション」を開く起動オプションだけです。ブラウザごとの場所は次のセクションで説明します。
- **タブがプライベート ウィンドウにあった。** Incognito と InPrivate のウィンドウは復元されません。
- **ウィンドウを一つずつ閉じた。** 起動時の復元で戻るのは、ブラウザを *終了* した時点で開いていたものです。それより前に閉じたウィンドウは履歴にしか残りません。
- **別のプロファイルを開いた。** セッションはプロファイルごとに別々です。プロファイルのアイコンを確認しましょう。

</Section>

<Section id="prevent" title="次に同じことが起きないようにする">

今のうちに起動時の設定をオンにしておきましょう。アップデートにも再起動にも、この一つの変更で備えられます。

<BrowserPanels section="prevent">
<BrowserPanel browser="chrome">

**設定 → 起動時 → 前回開いていたページを開く**（Settings → On startup → Continue where you left off）を選びます。アドレスバーに `chrome://settings/onStartup` を貼り付けても開けます。

<AnnotatedFigure src="/blog/save-all-open-tabs/chrome-startup-setting.webp" alt="Chrome の設定の「On startup」（起動時）で「Continue where you left off」（前回開いていたページを開く）が選択されている" width={1600} height={655} boxes={[{ id: 'startup-option' }]} source="chrome://settings/onStartup · Chrome 157.0.8103.79">前回のセッションを開き直すように設定した、Chrome の「起動時」。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="edge">

**設定 →「Start, home, and new tab page」→「On startup」→「Open tabs from the previous session」** を選びます。アドレスバーに `edge://settings/startHomeNTP` を貼り付けても開けます。

<AnnotatedFigure src="/blog/save-all-open-tabs/edge-startup-setting.webp" alt="Edge の設定の「Start, home, and new tab page」で「Open tabs from the previous session」が選択されている" width={1600} height={636} boxes={[{ id: 'startup-option' }]} source="edge://settings/startHomeNTP · Edge 157.0.4341.60">前回のセッションを開き直すように設定した、Edge の「Start, home, and new tab page」。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="firefox">

**設定 → ホームと起動 → 起動 → 前回のウィンドウとタブを開く**（Settings → Home and startup → Startup → Open previous windows and tabs）を選びます。アドレスバーに `about:preferences#home` を貼り付けても開けます。

<AnnotatedFigure src="/blog/save-all-open-tabs/firefox-startup.webp" alt="Firefox の設定の「Home and startup」（ホームと起動）で「Open previous windows and tabs」（前回のウィンドウとタブを開く）にチェックが入っている" width={940} height={760} boxes={[{ id: 'startup-option' }]} source="about:preferences#home · Firefox 159.0.1">Firefox の設定の「ホームと起動」。「前回のウィンドウとタブを開く」にチェックが入っています。</AnnotatedFigure>

</BrowserPanel>
</BrowserPanels>

起動時の復元でも、先週うっかり閉じたウィンドウは戻せません。そのためには保存したコピーが必要です。ウィンドウをブックマークするか、[セッション マネージャー](/blog/browser-session-manager) を使いましょう。方法の比較は [開いているタブをすべて保存する方法](/blog/save-all-open-tabs) のガイドにまとめています。

Chrome、Edge、Firefox 向けの無料拡張機能 [TabMerger](/features) なら、保存を任せられます。**設定 → データ → 開いているタブを自動保存** は、開いているタブをスケジュールどおりにグループとして保存します（15 分ごとから毎日まで）。**最近閉じたタブ** は、閉じたタブとウィンドウをすべて日ごとに残します。無料プランでは2日分、Pro では30日分です。どちらの仕組みも、調整のしかたも、[もうタブをなくさない](/blog/never-lose-a-tab-again) で詳しく説明しています。
