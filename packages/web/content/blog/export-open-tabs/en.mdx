<QuickAnswer>

Open [TabMerger](/features), go to **Settings → Data** and press **Export JSON**. One click saves a file with the title and address of **every open tab in every window**, plus every group you’ve saved. Built in, you can bookmark a window’s tabs with <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> and export your bookmarks as an HTML file, one window at a time.

</QuickAnswer>

<Section id="tabmerger" title="How do I export all my open tabs in one click?">

1. Open TabMerger and click the account icon → **Settings**.
2. Open the **Data** tab.
3. Under **Import & export**, press **Export JSON**. The file downloads straight away, named like `tabmerger-backup-2026-11-21.json`.

<Section id="builtin" title="How do I export tabs without an extension?">

Browsers don’t export open tabs directly, but they do export bookmarks. So bookmark the tabs first, then export:

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

1. In each window, press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> on a Mac) and save the tabs into a new folder.
2. Open **⋮ → Bookmarks and lists → Bookmark Manager**.
3. At the top, open **⋮ (More) → Export bookmarks**. Chrome saves every bookmark as an HTML file.

</BrowserPanel>
<BrowserPanel browser="edge">

1. In each window, press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> to add all tabs to favorites, in a new folder.
2. Press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> to open Favorites.
3. Choose **Export favorites** from the page’s menu and save the HTML file.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. In each window, press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> to bookmark all tabs into a new folder.
2. Press <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> to open the Library.
3. Choose **Export Bookmarks to HTML…** and save the file.

</BrowserPanel>
</BrowserPanels>

<Catch>it’s one window at a time, it exports *all* your bookmarks rather than just those tabs, and the file has no idea which tabs were open together.</Catch>

</Section>

<Section id="import" title="How do I bring the tabs back?">

In TabMerger, **Settings → Data → Import file** reads all three kinds of file and adds them as groups next to the ones you have:

- **TabMerger JSON**, from Export JSON, with your groups and windows as they were.
- **Bookmarks HTML**, from any browser: each top-level folder becomes a group.
- **OneTab text**: each OneTab list becomes a group. See our [OneTab alternatives guide](/blog/onetab-alternatives).

That makes an export the simplest way to [move tabs to another computer](/blog/move-tabs-between-computers) without an account. Want it automatic?
