<QuickAnswer>

打开 [TabMerger](/features)，进入 **设置 → 数据**（Settings → Data），点击 **导出 JSON**（Export JSON）。点一下就会保存一个文件，里面有**所有窗口中每个已打开标签页**的标题和网址，以及你保存过的每个分组。如果不用扩展，可以用 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> 把一个窗口的标签页加入书签，再把书签导出为 HTML 文件，但每次只能处理一个窗口。

<Section id="builtin" title="不用扩展，如何导出标签页？">

浏览器不能直接导出已打开的标签页，但可以导出书签。所以先把标签页加入书签，再导出：

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

1. 在每个窗口中按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>（Mac 上为 <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>），把标签页保存到一个新文件夹。
2. 打开 **⋮ → 书签和清单 → 书签管理器**（Bookmarks and lists → Bookmark Manager）。
3. 在顶部打开 **⋮ → 导出书签**（Export bookmarks）。Chrome 会把所有书签保存为一个 HTML 文件。

</BrowserPanel>
<BrowserPanel browser="edge">

1. 在每个窗口中按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>，把所有标签页添加到收藏夹中的一个新文件夹。
2. 按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> 打开收藏夹（Favorites）。
3. 从页面的菜单中选择 **Export favorites**，然后保存 HTML 文件。

</BrowserPanel>
<BrowserPanel browser="firefox">

1. 在每个窗口中按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>，把所有标签页加入书签，放进一个新文件夹。
2. 按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> 打开“我的足迹”（Library）窗口。
3. 选择 **导出书签为 HTML 文件…**（Export Bookmarks to HTML…），然后保存文件。

</BrowserPanel>
</BrowserPanels>

<Catch>每次只能处理一个窗口，导出的是你的*全部*书签而不只是这些标签页，而且文件不知道哪些标签页是一起打开的。</Catch>

</Section>

<Section id="import" title="如何把标签页找回来？">

在 TabMerger 中，**设置 → 数据 → 导入文件**（Settings → Data → Import file）能读取全部三种文件，并把它们作为分组添加到你现有分组的旁边：

- **TabMerger JSON**：由“导出 JSON”生成，已保存的分组和窗口都保持原样。文件中的“当前打开”不会被添加（那是导出时那个浏览器中打开的标签页），所以如果想找回当时打开的窗口，请在导出前把它们保存为分组。
- **书签 HTML**：来自任何浏览器均可，每个顶层文件夹会成为一个分组。
- **OneTab 文本**：每个 OneTab 列表会成为一个分组。请参阅我们的 [OneTab 替代工具指南](/blog/onetab-alternatives)。
