<QuickAnswer>

[TabMerger](/features)를 열고 **설정 → 데이터**(Settings → Data)로 이동해 **JSON 내보내기**(Export JSON)를 누르세요. 한 번의 클릭으로 **모든 창에 열린 모든 탭**의 제목과 주소, 그리고 저장해 둔 모든 그룹이 담긴 파일이 저장됩니다. 확장 프로그램 없이도 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>로 창의 탭을 북마크에 추가하고 북마크를 HTML 파일로 내보낼 수 있지만, 한 번에 창 하나씩입니다.

</QuickAnswer>

<InstallCta>모든 창의 열린 탭을 한 번의 클릭으로 내보내세요. Chrome, Edge, Firefox에서 무료입니다.</InstallCta>

<Section id="tabmerger" title="열린 탭을 한 번의 클릭으로 모두 내보내려면?">

1. TabMerger를 열고 계정 아이콘 → **설정**을 클릭합니다.
2. **데이터** 탭을 엽니다.
3. **가져오기 및 내보내기** 아래에서 **JSON 내보내기**를 누릅니다. 파일은 `tabmerger-backup-2026-11-21.json` 같은 이름으로 바로 다운로드됩니다.

<Section id="builtin" title="확장 프로그램 없이 탭을 내보내려면?">

브라우저는 열린 탭을 바로 내보내지 못하지만 북마크는 내보낼 수 있습니다. 그러니 먼저 탭을 북마크에 추가한 다음 내보내세요.

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

1. 창마다 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>(Mac에서는 <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>)를 누르고 탭을 새 폴더에 저장합니다.
2. **⋮ → 북마크 및 목록 → 북마크 관리자**(Bookmarks and lists → Bookmark Manager)를 엽니다.
3. 상단에서 **⋮ → 북마크 내보내기**(Export bookmarks)를 엽니다. Chrome이 모든 북마크를 HTML 파일로 저장합니다.

</BrowserPanel>
<BrowserPanel browser="edge">

1. 창마다 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>를 눌러 모든 탭을 새 폴더의 즐겨찾기에 추가합니다.
2. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>를 눌러 즐겨찾기(Favorites)를 엽니다.
3. 페이지 메뉴에서 **Export favorites**를 선택하고 HTML 파일을 저장합니다.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. 창마다 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>를 눌러 모든 탭을 새 폴더에 북마크합니다.
2. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>를 눌러 ‘라이브러리’(Library) 창을 엽니다.
3. **북마크를 HTML로 내보내기…**(Export Bookmarks to HTML…)를 선택하고 파일을 저장합니다.

</BrowserPanel>
</BrowserPanels>

<Catch>한 번에 창 하나씩만 되고, 그 탭들만이 아니라 *모든* 북마크를 내보내며, 어떤 탭이 함께 열려 있었는지는 파일에 남지 않습니다.</Catch>

</Section>

<Section id="import" title="탭을 다시 가져오려면?">

TabMerger의 **설정 → 데이터 → 파일 가져오기**(Settings → Data → Import file)는 세 종류의 파일을 모두 읽어, 기존 그룹 옆에 그룹으로 추가합니다.

- **TabMerger JSON**: ‘JSON 내보내기’로 만든 파일로, 저장한 그룹과 창이 그대로 들어 있습니다. 파일의 ‘현재 열린 탭’은 추가되지 않으므로(내보낸 브라우저에서 열려 있던 탭이기 때문), 열린 창도 되살리고 싶다면 내보내기 전에 그룹으로 저장해 두세요.
- **북마크 HTML**: 어느 브라우저의 것이든 되며, 최상위 폴더마다 그룹 하나가 됩니다.
- **OneTab 텍스트**: OneTab 목록마다 그룹 하나가 됩니다. [OneTab 대안 가이드](/blog/onetab-alternatives)를 참고하세요.

그래서 계정 없이 [다른 컴퓨터로 탭을 옮기는](/blog/move-tabs-between-computers) 가장 간단한 방법이 내보내기입니다. 자동으로 하고 싶다면 [Pro](/pricing)가 최신 자동 백업 10개를 보관하고, 그룹을 기기 간에 엔드투엔드 암호화로 동기화합니다. 파일 없이 탭을 나중을 위해 저장하려면 [열린 탭을 모두 저장하는 방법](/blog/save-all-open-tabs)을, 탭 묶음을 다른 사람에게 보내려면 [탭 묶음을 공유하는 방법](/blog/share-a-set-of-tabs)을 참고하세요.

<InstallCta>Chrome, Edge, Firefox에서 무료입니다. 계정 없이 바로 시작할 수 있습니다.</InstallCta>
