<QuickAnswer>

Apri [TabMerger](/features), vai in **Impostazioni → Dati** (Settings → Data) e premi **Esporta JSON** (Export JSON). Un clic salva un file con titolo e indirizzo di **ogni scheda aperta in ogni finestra**, più ogni gruppo che hai salvato. Senza estensioni puoi salvare tra i preferiti le schede di una finestra con <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> ed esportare i preferiti in un file HTML, una finestra alla volta.

</QuickAnswer>

<InstallCta>Esporta ogni scheda aperta, da ogni finestra, con un clic. Gratis per Chrome, Edge e Firefox.</InstallCta>

<Section id="tabmerger" title="Come esporto tutte le schede aperte con un clic?">

1. Apri TabMerger e fai clic sull’icona dell’account → **Impostazioni**.
2. Apri la scheda **Dati**.
3. In **Importa ed esporta**, premi **Esporta JSON**. Il file si scarica subito, con un nome come `tabmerger-backup-2026-11-21.json`.

<Section id="builtin" title="Come esporto le schede senza un’estensione?">

I browser non esportano direttamente le schede aperte, ma esportano i preferiti. Quindi prima salva le schede tra i preferiti, poi esporta:

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

1. In ogni finestra, premi <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> su Mac) e salva le schede in una nuova cartella.
2. Apri **⋮ → Preferiti ed elenchi → Gestione preferiti** (Bookmarks and lists → Bookmark Manager).
3. In alto, apri **⋮ → Esporta preferiti** (Export bookmarks). Chrome salva tutti i preferiti in un file HTML.

</BrowserPanel>
<BrowserPanel browser="edge">

1. In ogni finestra, premi <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> per aggiungere tutte le schede ai preferiti, in una nuova cartella.
2. Premi <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> per aprire i preferiti (Favorites).
3. Scegli **Export favorites** dal menu della pagina e salva il file HTML.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. In ogni finestra, premi <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> per salvare tutte le schede come segnalibri in una nuova cartella.
2. Premi <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> per aprire la Libreria (Library).
3. Scegli **Esporta segnalibri in HTML…** (Export Bookmarks to HTML…) e salva il file.

</BrowserPanel>
</BrowserPanels>

<Catch>si va una finestra alla volta, esporta *tutti* i tuoi preferiti invece delle sole schede, e il file non sa quali schede erano aperte insieme.</Catch>

</Section>

<Section id="import" title="Come riporto indietro le schede?">

In TabMerger, **Impostazioni → Dati → Importa file** (Settings → Data → Import file) legge tutti e tre i tipi di file e li aggiunge come gruppi accanto a quelli che hai già:

- **JSON di TabMerger**, da «Esporta JSON», con i gruppi e le finestre salvati così com’erano. «Aperte ora» del file non viene aggiunto (erano le schede aperte del browser che ha esportato), quindi salva le finestre aperte in un gruppo prima di esportare se vuoi riaverle.
- **HTML dei preferiti**, da qualsiasi browser: ogni cartella di primo livello diventa un gruppo.
- **Testo di OneTab**: ogni elenco di OneTab diventa un gruppo. Vedi la nostra [guida alle alternative a OneTab](/blog/onetab-alternatives).

Per questo l’esportazione è il modo più semplice per [spostare le schede su un altro computer](/blog/move-tabs-between-computers) senza un account. Lo vuoi automatico? [Pro](/pricing) conserva i 10 backup automatici più recenti e sincronizza i tuoi gruppi tra i dispositivi, con crittografia end-to-end. Per salvare le schede per dopo senza alcun file, vedi [come salvare tutte le schede aperte](/blog/save-all-open-tabs); per inviare un insieme a qualcun altro, vedi [come condividere un insieme di schede](/blog/share-a-set-of-tabs).
