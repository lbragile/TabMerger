<QuickAnswer>

Откройте [TabMerger](/features), перейдите в **Настройки → Данные** (Settings → Data) и нажмите **Экспорт в JSON** (Export JSON). Один щелчок сохраняет файл с названием и адресом **каждой открытой вкладки в каждом окне**, а также все сохранённые вами группы. Без расширений можно добавить вкладки окна в закладки сочетанием <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> и экспортировать закладки в HTML-файл, по одному окну за раз.

</QuickAnswer>

<Section id="tabmerger" title="Как экспортировать все открытые вкладки одним щелчком?">

1. Откройте TabMerger и нажмите значок аккаунта → **Настройки**.
2. Откройте вкладку **Данные**.
3. В разделе **Импорт и экспорт** нажмите **Экспорт в JSON**. Файл сразу скачается под именем вроде `tabmerger-backup-2026-11-21.json`.

<Section id="inside" title="Что внутри экспортированного файла?">

Список ваших групп в формате JSON. Первой идёт группа **Сейчас открыто** (Now Open), то есть открытые сейчас окна и вкладки, за ней каждая сохранённая группа. Пример из настоящего экспорта:

<Section id="builtin" title="Как экспортировать вкладки без расширения?">

Браузеры не умеют экспортировать открытые вкладки напрямую, зато экспортируют закладки. Поэтому сначала добавьте вкладки в закладки, а затем экспортируйте:

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

1. В каждом окне нажмите <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> на Mac) и сохраните вкладки в новую папку.
2. Откройте **⋮ → Закладки и списки → Диспетчер закладок** (Bookmarks and lists → Bookmark Manager).
3. Вверху откройте **⋮ → Экспортировать закладки** (Export bookmarks). Chrome сохранит все закладки в HTML-файл.

</BrowserPanel>
<BrowserPanel browser="edge">

1. В каждом окне нажмите <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>, чтобы добавить все вкладки в избранное, в новую папку.
2. Нажмите <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>, чтобы открыть избранное (Favorites).
3. Выберите **Export favorites** в меню страницы и сохраните HTML-файл.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. В каждом окне нажмите <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>, чтобы добавить все вкладки в закладки, в новую папку.
2. Нажмите <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>, чтобы открыть окно «Библиотека» (Library).
3. Выберите **Экспорт закладок в HTML-файл…** (Export Bookmarks to HTML…) и сохраните файл.

</BrowserPanel>
</BrowserPanels>

<Catch>только по одному окну, экспортируются *все* ваши закладки, а не только эти вкладки, и файл не знает, какие вкладки были открыты вместе.</Catch>

</Section>

<Section id="import" title="Как вернуть вкладки?">

В TabMerger **Настройки → Данные → Импорт файла** (Settings → Data → Import file) читает все три вида файлов и добавляет их как группы рядом с уже имеющимися:

- **JSON из TabMerger**, созданный кнопкой «Экспорт в JSON», с сохранёнными группами и окнами в прежнем виде. Группа «Сейчас открыто» из файла не добавляется (это были открытые вкладки браузера, где делали экспорт), поэтому перед экспортом сохраните открытые окна в группу, если хотите их вернуть.
- **HTML-файл закладок** из любого браузера: каждая папка верхнего уровня становится группой.
- **Текст OneTab**: каждый список OneTab становится группой. См. наше [руководство по альтернативам OneTab](/blog/onetab-alternatives).

Поэтому экспорт — самый простой способ [перенести вкладки на другой компьютер](/blog/move-tabs-between-computers) без аккаунта. Хотите, чтобы всё происходило само?
