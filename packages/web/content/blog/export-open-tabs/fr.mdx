<QuickAnswer>

Ouvrez [TabMerger](/features), allez dans **Paramètres → Données** (Settings → Data) et cliquez sur **Exporter en JSON** (Export JSON). Un clic enregistre un fichier avec le titre et l’adresse de **chaque onglet ouvert dans chaque fenêtre**, plus chaque groupe que vous avez enregistré. Sans extension, vous pouvez ajouter les onglets d’une fenêtre aux favoris avec <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> et exporter vos favoris dans un fichier HTML, une fenêtre à la fois.

</QuickAnswer>

<Section id="tabmerger" title="Comment exporter tous mes onglets ouverts en un clic ?">

1. Ouvrez TabMerger et cliquez sur l’icône du compte → **Paramètres**.
2. Ouvrez l’onglet **Données**.
3. Sous **Import et export**, cliquez sur **Exporter en JSON**. Le fichier se télécharge aussitôt, avec un nom du type `tabmerger-backup-2026-11-21.json`.

<Section id="builtin" title="Comment exporter des onglets sans extension ?">

Les navigateurs n’exportent pas directement les onglets ouverts, mais ils exportent les favoris. Ajoutez donc d’abord les onglets aux favoris, puis exportez :

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

1. Dans chaque fenêtre, appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> sur Mac) et enregistrez les onglets dans un nouveau dossier.
2. Ouvrez **⋮ → Favoris et listes → Gestionnaire de favoris** (Bookmarks and lists → Bookmark Manager).
3. En haut, ouvrez **⋮ → Exporter les favoris** (Export bookmarks). Chrome enregistre tous les favoris dans un fichier HTML.

</BrowserPanel>
<BrowserPanel browser="edge">

1. Dans chaque fenêtre, appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> pour ajouter tous les onglets aux favoris, dans un nouveau dossier.
2. Appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> pour ouvrir les favoris (Favorites).
3. Choisissez **Export favorites** dans le menu de la page et enregistrez le fichier HTML.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. Dans chaque fenêtre, appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> pour marquer tous les onglets dans un nouveau dossier.
2. Appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> pour ouvrir la Bibliothèque (Library).
3. Choisissez **Exporter des marque-pages au format HTML…** (Export Bookmarks to HTML…) et enregistrez le fichier.

</BrowserPanel>
</BrowserPanels>

<Catch>c’est une fenêtre à la fois, cela exporte *tous* vos favoris et pas seulement ces onglets, et le fichier ne sait pas quels onglets étaient ouverts ensemble.</Catch>

</Section>

<Section id="import" title="Comment récupérer les onglets ?">

Dans TabMerger, **Paramètres → Données → Importer un fichier** (Settings → Data → Import file) lit les trois types de fichiers et les ajoute comme groupes à côté de ceux que vous avez déjà :

- **JSON de TabMerger**, issu de « Exporter en JSON », avec vos groupes et fenêtres enregistrés tels qu’ils étaient. « Ouverts maintenant » du fichier n’est pas ajouté (c’étaient les onglets ouverts du navigateur qui a exporté) ; enregistrez donc vos fenêtres ouvertes dans un groupe avant l’export si vous voulez les retrouver.
- **Favoris HTML**, de n’importe quel navigateur : chaque dossier de premier niveau devient un groupe.
- **Texte OneTab** : chaque liste OneTab devient un groupe. Voir notre [guide des alternatives à OneTab](/blog/onetab-alternatives).

C’est donc le moyen le plus simple de [transférer des onglets vers un autre ordinateur](/blog/move-tabs-between-computers) sans compte. Vous préférez l’automatique ? [Pro](/pricing) conserve les 10 sauvegardes automatiques les plus récentes et synchronise vos groupes entre vos appareils, avec un chiffrement de bout en bout. Pour garder des onglets pour plus tard sans aucun fichier, voir [comment enregistrer tous les onglets ouverts](/blog/save-all-open-tabs) ; pour envoyer une sélection à quelqu’un, voir [comment partager un ensemble d’onglets](/blog/share-a-set-of-tabs).
