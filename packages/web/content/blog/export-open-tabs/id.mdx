<QuickAnswer>

Buka [TabMerger](/features), masuk ke **Pengaturan → Data** (Settings → Data), lalu tekan **Ekspor JSON** (Export JSON). Sekali klik menyimpan file berisi judul dan alamat **setiap tab yang terbuka di setiap jendela**, plus setiap grup yang sudah Anda simpan. Tanpa ekstensi, Anda bisa mem-bookmark tab di satu jendela dengan <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> lalu mengekspor bookmark sebagai file HTML, satu jendela per kali.

</QuickAnswer>

<Section id="tabmerger" title="Bagaimana cara mengekspor semua tab yang terbuka dalam sekali klik?">

1. Buka TabMerger dan klik ikon akun → **Pengaturan**.
2. Buka tab **Data**.
3. Di bawah **Impor & ekspor**, tekan **Ekspor JSON**. File langsung terunduh dengan nama seperti `tabmerger-backup-2026-11-21.json`.

<Section id="builtin" title="Bagaimana cara mengekspor tab tanpa ekstensi?">

Browser tidak bisa mengekspor tab yang terbuka secara langsung, tetapi bisa mengekspor bookmark. Jadi, bookmark dulu tab-tabnya, lalu ekspor:

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

1. Di setiap jendela, tekan <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> (<Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> di Mac) dan simpan tab ke folder baru.
2. Buka **⋮ → Bookmark dan daftar → Pengelola Bookmark** (Bookmarks and lists → Bookmark Manager).
3. Di bagian atas, buka **⋮ → Ekspor Bookmark** (Export bookmarks). Chrome menyimpan semua bookmark sebagai file HTML.

</BrowserPanel>
<BrowserPanel browser="edge">

1. Di setiap jendela, tekan <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> untuk menambahkan semua tab ke favorit, di folder baru.
2. Tekan <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> untuk membuka Favorit (Favorites).
3. Pilih **Export favorites** dari menu halaman itu dan simpan file HTML-nya.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. Di setiap jendela, tekan <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> untuk mem-bookmark semua tab ke folder baru.
2. Tekan <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> untuk membuka Pustaka (Library).
3. Pilih **Ekspor Markah ke HTML…** (Export Bookmarks to HTML…) dan simpan filenya.

</BrowserPanel>
</BrowserPanels>

<Catch>hanya satu jendela per kali, yang diekspor *semua* bookmark Anda, bukan hanya tab-tab itu, dan file tersebut tidak tahu tab mana yang terbuka bersamaan.</Catch>

</Section>

<Section id="import" title="Bagaimana cara mengembalikan tab-tab itu?">

Di TabMerger, **Pengaturan → Data → Impor file** (Settings → Data → Import file) membaca ketiga jenis file dan menambahkannya sebagai grup di samping grup yang sudah ada:

- **JSON TabMerger**, dari “Ekspor JSON”, dengan grup dan jendela tersimpan persis seperti semula. “Sedang Terbuka” dari file tidak ditambahkan (itu tab terbuka di browser yang mengekspor), jadi simpan jendela yang terbuka ke sebuah grup sebelum mengekspor jika Anda ingin mendapatkannya kembali.
- **HTML bookmark**, dari browser apa pun: setiap folder tingkat atas menjadi satu grup.
- **Teks OneTab**: setiap daftar OneTab menjadi satu grup. Lihat [panduan alternatif OneTab](/blog/onetab-alternatives) kami.

Karena itu, ekspor adalah cara paling sederhana untuk [memindahkan tab ke komputer lain](/blog/move-tabs-between-computers) tanpa akun. Mau otomatis? [Pro](/pricing) menyimpan 10 cadangan otomatis terbaru dan menyinkronkan grup Anda antarperangkat dengan enkripsi end-to-end. Untuk menyimpan tab buat nanti tanpa file sama sekali, lihat [cara menyimpan semua tab yang terbuka](/blog/save-all-open-tabs); untuk mengirim sekumpulan tab ke orang lain, lihat [cara membagikan sekumpulan tab](/blog/share-a-set-of-tabs).
