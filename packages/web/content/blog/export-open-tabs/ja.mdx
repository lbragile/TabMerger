<QuickAnswer>

[TabMerger](/features) を開き、**設定 → データ**（Settings → Data）で **JSON をエクスポート**（Export JSON）を押します。ワンクリックで、**すべてのウィンドウの開いているタブすべて**のタイトルとアドレスに加え、保存したすべてのグループを含むファイルが保存されます。拡張機能なしでも、<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> でウィンドウのタブをブックマークし、ブックマークを HTML ファイルとしてエクスポートできます。ただし 1 ウィンドウずつです。

</QuickAnswer>

<InstallCta>すべてのウィンドウの開いているタブを、ワンクリックでエクスポート。Chrome、Edge、Firefox に無料で対応。</InstallCta>

<Section id="tabmerger" title="開いているタブをワンクリックですべてエクスポートするには？">

1. TabMerger を開き、アカウントアイコン → **設定** をクリックします。
2. **データ** タブを開きます。

JSON はプレーンテキストなので、どんなスクリプトやテキストエディタでも読めます。アドレスだけを取り出す、Markdown のリストに変換する、バックアップとして保管する、といった使い方ができます。

<Section id="builtin" title="拡張機能なしでタブをエクスポートするには？">

ブラウザは開いているタブを直接エクスポートできませんが、ブックマークならエクスポートできます。そこで、まずタブをブックマークしてからエクスポートします。

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

1. 各ウィンドウで <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>（Mac では <Kbd>⌘</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>）を押し、タブを新しいフォルダに保存します。
2. 「**⋮ → ブックマークとリスト → ブックマーク マネージャ**」（Bookmarks and lists → Bookmark Manager）を開きます。
3. 上部の「**⋮ → ブックマークをエクスポート**」（Export bookmarks）を選びます。Chrome はすべてのブックマークを HTML ファイルに保存します。

</BrowserPanel>
<BrowserPanel browser="edge">

1. 各ウィンドウで <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> を押し、すべてのタブを新しいフォルダのお気に入りに追加します。
2. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> を押してお気に入り（Favorites）を開きます。
3. ページのメニューから **Export favorites** を選び、HTML ファイルを保存します。

</BrowserPanel>
<BrowserPanel browser="firefox">

1. 各ウィンドウで <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> を押し、すべてのタブを新しいフォルダにブックマークします。
2. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd> を押して「ブラウジングライブラリー」（Library）ウィンドウを開きます。
3. **HTML としてエクスポート...**（Export Bookmarks to HTML…）を選び、ファイルを保存します。

</BrowserPanel>
</BrowserPanels>

<Catch>1 ウィンドウずつしかできず、そのタブだけでなくブックマークを*すべて*エクスポートしてしまい、どのタブが一緒に開いていたかはファイルに残りません。</Catch>

</Section>

<Section id="import" title="タブを元に戻すには？">

TabMerger の **設定 → データ → ファイルをインポート**（Settings → Data → Import file）は 3 種類のファイルをすべて読み込み、既存のグループの隣にグループとして追加します。

- **TabMerger の JSON**：「JSON をエクスポート」で作ったファイルで、保存済みのグループとウィンドウがそのまま入っています。ファイル内の「現在開いているタブ」は追加されません（エクスポートしたブラウザで開いていたタブのため）。開いているウィンドウも戻したい場合は、エクスポートの前にグループとして保存してください。
- **ブックマークの HTML**：どのブラウザのものでも使え、最上位のフォルダごとに 1 つのグループになります。
- **OneTab のテキスト**：OneTab のリストごとに 1 つのグループになります。詳しくは [OneTab の代替ツールのガイド](/blog/onetab-alternatives)をご覧ください。

つまりエクスポートは、アカウントなしで[タブを別のパソコンに移す](/blog/move-tabs-between-computers)いちばん簡単な方法です。自動にしたいなら、[Pro](/pricing) が最新 10 件の自動バックアップを保管し、グループをデバイス間でエンドツーエンド暗号化して同期します。ファイルを使わずにタブを後で使うために取っておくなら[開いているタブをすべて保存する方法](/blog/save-all-open-tabs)を、タブのセットを誰かに送るなら[タブのセットを共有する方法](/blog/share-a-set-of-tabs)をご覧ください。
