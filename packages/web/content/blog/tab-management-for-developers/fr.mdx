<QuickAnswer>

Donnez à chaque projet son propre groupe [TabMerger](/features), puis laissez les **Règles d’URL** (URL rules) faire le rangement : un motif comme `github.com/your-org/*` ou `localhost:3000/*` envoie automatiquement chaque nouvel onglet correspondant dans le bon groupe. Trouvez n’importe quelle page de doc avec <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> et, quand vous changez de tâche, enregistrez les fenêtres du projet puis fermez-les. Rien de perdu, rien à fouiller.

</QuickAnswer>

<InstallCta>Un groupe par projet, rangé pour vous par les règles d’URL. Gratuit pour Chrome, Edge et Firefox.</InstallCta>

<Section id="rules" title="Comment ranger automatiquement les onglets dans le bon groupe ?">

Les **Règles d’URL** de TabMerger surveillent vos onglets. Quand un onglet s’ouvre ou finit de charger une adresse qui correspond à une règle, une copie est enregistrée dans le groupe de cette règle ; l’onglet lui-même reste ouvert.

1. Ouvrez **Paramètres → Général** (Settings → General), repérez **Règles d’URL** et cliquez sur **Gérer** (Manage).
2. Cliquez sur **Ajouter une règle** (Add rule), saisissez un motif et choisissez le groupe. `*` est un joker ; la première règle qui correspond l’emporte.
3. Cliquez sur **Enregistrer** (Save).

Des motifs qui fonctionnent bien :

- `github.com/your-org/*` pour tous les dépôts, PR et issues d’un projet
- `localhost:3000/*` pour votre serveur de développement (les règles ignorent `http://` et `https://`)
- `docs.your-framework.dev/*` pour la doc que vous rouvrez sans cesse

L’offre gratuite comprend 3 règles ; [Pro](/pricing) n’a aucune limite. Toutes les options des motifs, et l’ordre des règles, sont détaillés dans [trier automatiquement les onglets avec des règles d’URL](/blog/auto-sort-tabs-with-url-rules).

</Section>

<Section id="find" title="Comment trouver une page de doc d’une seule touche ?">

Appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> dans TabMerger et tapez quelques lettres du titre ou de l’adresse. Les résultats couvrent les onglets ouverts, enregistrés et récemment fermés. Affinez avec des filtres : `group:"Docs" fetch`, `window:"Local"`, ou `closed:` pour la page fermée il y a une heure. Plus de détails dans [comment retrouver un onglet parmi des centaines](/blog/find-a-tab-among-hundreds).

Les menus de groupe proposent aussi **Trier par URL** (Sort by URL), pratique pour une longue fenêtre de doc, et **Dédupliquer les onglets** (Deduplicate tabs) pour les cinq copies de la même issue.

</Section>

<Section id="switch" title="Comment changer de projet sans perdre le contexte ?">

1. Dans le groupe du projet, choisissez **Fusionner avec l’actuel** (Merge with current) pour enregistrer ses fenêtres ouvertes. **Remplacer par l’actuel** (Replace with current) écrase plutôt la copie enregistrée.
2. Fermez les fenêtres.
3. Quand vous y revenez, rouvrez le groupe : chaque PR, chaque doc et chaque tableau de bord, là où vous les aviez laissés.
