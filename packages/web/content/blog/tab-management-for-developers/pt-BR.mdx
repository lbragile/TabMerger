<QuickAnswer>

Dê a cada projeto seu próprio grupo no [TabMerger](/features) e deixe as **Regras de URL** (URL rules) arquivarem por você: um padrão como `github.com/your-org/*` ou `localhost:3000/*` envia automaticamente cada nova aba correspondente para o grupo certo. Encontre qualquer página de documentação com <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> e, quando trocar de tarefa, salve as janelas do projeto e feche-as. Nada se perde, nada para garimpar.

</QuickAnswer>

<InstallCta>Um grupo por projeto, preenchido pelas regras de URL. Grátis para Chrome, Edge e Firefox.</InstallCta>

<Section id="setup" title="Como um desenvolvedor deve organizar as abas?">

Do mesmo jeito que organiza o código: por projeto. Um projeto típico tem quatro tipos de abas:

No TabMerger, um grupo pode ter várias janelas, então um mesmo grupo de projeto mantém “PRs”, “Docs” e “Local” separadas. Renomeie uma janela pelo menu **⋯** dela e adicione ao grupo uma nota com a branch ou o número do ticket.

</Section>

<Section id="rules" title="Como arquivo as abas no grupo certo automaticamente?">

As **Regras de URL** do TabMerger ficam de olho nas suas abas. Quando uma aba abre ou termina de carregar um endereço que corresponde a uma regra, uma cópia é salva no grupo dessa regra; a aba em si continua aberta.

1. Abra **Configurações → Geral** (Settings → General), encontre **Regras de URL** e clique em **Gerenciar** (Manage).
2. Clique em **Adicionar regra** (Add rule), digite um padrão e escolha o grupo. `*` é um curinga; vale a primeira regra que corresponder.
3. Clique em **Salvar** (Save).

Padrões que funcionam bem:

- `github.com/your-org/*` para todos os repositórios, PRs e issues de um projeto
- `localhost:3000/*` para o seu servidor de desenvolvimento (as regras ignoram `http://` e `https://`)
- `docs.your-framework.dev/*` para a documentação que você vive reabrindo

O plano gratuito inclui 3 regras; o [Pro](/pricing) não tem limite. Todas as opções de padrão, e a ordem das regras, estão em [organizar abas automaticamente com regras de URL](/blog/auto-sort-tabs-with-url-rules).

</Section>

<Section id="find" title="Como acho uma página de documentação com um atalho?">

Pressione <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> no TabMerger e digite algumas letras do título ou do endereço. Os resultados incluem abas abertas, salvas e fechadas recentemente. Refine com filtros: `group:"Docs" fetch`, `window:"Local"` ou `closed:` para a página que você fechou uma hora atrás. Mais em [como encontrar uma aba entre centenas](/blog/find-a-tab-among-hundreds).

Os menus de grupo também têm **Ordenar por URL** (Sort by URL), útil para uma janela comprida de documentação, e **Remover abas duplicadas** (Deduplicate tabs) para as cinco cópias da mesma issue.

</Section>

<Section id="switch" title="Como troco de projeto sem perder o contexto?">

1. No grupo do projeto, escolha **Mesclar com as atuais** (Merge with current) para salvar as janelas abertas. Já **Substituir pelas atuais** (Replace with current) sobrescreve a cópia salva.
2. Feche as janelas.
3. Quando voltar ao projeto, reabra o grupo: cada PR, cada doc e cada dashboard, onde você deixou.
