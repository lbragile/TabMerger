<QuickAnswer>

Give every project its own [TabMerger](/features) group, then let **URL rules** do the filing: a pattern such as `github.com/your-org/*` or `localhost:3000/*` sends each matching new tab to the right group automatically. Find any docs page with <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>, and when you switch tasks, save the project’s windows and close them. Nothing lost, nothing to dig through.

</QuickAnswer>

<Section id="rules" title="How do I file tabs into the right group automatically?">

TabMerger’s **URL rules** watch your tabs. When a tab opens or finishes loading an address that matches a rule, a copy is saved into that rule’s group; the tab itself stays open.

1. Open **Settings → General**, find **URL rules** and press **Manage**.
2. Press **Add rule**, type a pattern and pick the group. `*` is a wildcard; the first matching rule wins.
3. Press **Save**.

Patterns that work well:

- `github.com/your-org/*` for every repo, PR and issue of a project
- `localhost:3000/*` for your dev server (rules ignore `http://` and `https://`)
- `docs.your-framework.dev/*` for the docs you keep reopening

Free includes 3 rules; [Pro](/pricing) has no limit. Every pattern option, and rule order, is in [auto-sort tabs with URL rules](/blog/auto-sort-tabs-with-url-rules).

</Section>

<Section id="find" title="How do I find a docs page in a keystroke?">

Press <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> in TabMerger and type a few letters of the title or address. Results cover open, saved and recently closed tabs. Narrow it down with filters: `group:"Docs" fetch`, `window:"Local"`, or `closed:` for the page you closed an hour ago. More in [how to find one tab among hundreds](/blog/find-a-tab-among-hundreds).

Group menus also have **Sort by URL**, handy for a long docs window, and **Deduplicate tabs** for the five copies of the same issue.

</Section>

<Section id="switch" title="How do I switch projects without losing context?">

1. In the project’s group, choose **Merge with current** to save its open windows (or **Replace with current** to overwrite the saved copy).
2. Close the windows.
3. When you’re back on it, reopen the group: every PR, doc and dashboard, where you left them.
