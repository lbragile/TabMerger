<QuickAnswer>

一度だけ移すなら、[TabMerger](/features) の **設定 → データ → JSON をエクスポート**（Settings → Data → Export JSON）を古いパソコンで、**ファイルをインポート**（Import file）を新しいパソコンで使います。保存したグループがすべて移ります（先に開いているウィンドウをグループに保存しておきます）。無料で、アカウントも不要で、Chrome、Edge、Firefox のどれでも使えます。2 台のパソコンを常に同じ状態にしたいなら、**TabMerger Pro** がグループとセッションをエンドツーエンド暗号化して自動で同期します。同じブラウザしか使わないなら、両方でログインしてそのブラウザの同期を使いましょう。

</QuickAnswer>

<InstallCta>新しいパソコンへ、すべてのタブを 2 クリックで。Chrome、Edge、Firefox で無料。</InstallCta>

<Section id="tabmerger" title="TabMerger でタブを移すには？">

**一度だけ、ファイルで（無料）：**

1. 古いパソコンで、移したい開いているウィンドウをグループに保存します（グループの **⋯** メニューで **現在の内容と統合**（Merge with current）を選びます）。インポートで追加されるのは保存済みのグループで、ファイル内の「現在開いているタブ」（Now Open）は含まれません。それは古いブラウザで開いていたタブだからです。
2. TabMerger を開き → **設定 → データ** → **JSON をエクスポート** を選びます。
3. ファイルを新しいパソコンにコピーします（USB メモリ、自分宛てのメール、クラウドドライブなど）。
4. 新しいパソコンに TabMerger をインストールし、**設定 → データ** → **ファイルをインポート** を選びます。グループは、すでにあるグループの横に追加されます。

**いつでも、同期で（[Pro](/pricing)）**：各パソコンで TabMerger にログインすれば、Chrome、Edge、Firefox のどれでもグループとセッションがついてきます。すべてはデバイス上で暗号化されてから同期されるので、サーバーはあなたのタブを読めません。Pro ではほかのデバイスで開いているタブを表示してこのパソコンで復元でき、自動バックアップも残ります。仕組みと、当社のサーバーに見えるもの・見えないものは [デバイス間でタブを同期する](/blog/sync-tabs-between-devices-with-tabmerger) で説明しています。

ファイルの中身については [開いているタブをエクスポートする方法](/blog/export-open-tabs) をご覧ください。

<Section id="browser" title="ブラウザ自体の同期でタブを移すには？">

両方のパソコンで同じブラウザを使い、どちらでもそのブラウザにログインしている場合に使える方法です。

<BrowserPanels section="browser">
<BrowserPanel browser="chrome">

1. 両方のパソコンで Chrome にログインします。
2. **履歴とタブ**（History and tabs）をオンにします。**設定 → Google の設定**（Settings → You and Google）でアカウント名を選び、オンにします。
3. もう一方のパソコンで履歴（<Kbd>Ctrl</Kbd>+<Kbd>H</Kbd>）を開き、**他のデバイスからのタブ**（Tabs from other devices）を選びます。

</BrowserPanel>
<BrowserPanel browser="edge">

1. 両方のパソコンで Edge にログインし、同期をオンにします。
2. もう一方のパソコンで履歴（<Kbd>Ctrl</Kbd>+<Kbd>H</Kbd>）を開き、**Tabs from other devices**（ほかのデバイスのタブ）を選びます。
3. Edge 158 には、1 ページだけを送る **Send tab to your devices**（タブをデバイスに送信）もあります。

</BrowserPanel>
<BrowserPanel browser="firefox">

1. 両方のパソコンで Firefox にログインし、開いているタブの同期をオンにしておきます。
2. タブを右クリックして **端末へ送信**（Send to Device）を選ぶと、もう一方のパソコンに送れます。
3. または、そちらで **Firefox View** を開き、**他の端末のタブ**（Tabs from other devices）を確認します。

</BrowserPanel>
</BrowserPanels>

<Catch>ブラウザの同期は同じブラウザの中でしか使えず、もう一方のデバイスで今開いているものしか表示されず、閉じたタブは残りません。すべてのタブを、ブラウザをまたいで移すなら TabMerger を使いましょう。</Catch>

古いパソコンのクラッシュでタブを失った場合は、まず [クラッシュ後にタブを復元する方法](/blog/restore-tabs-after-crash) をご覧ください。全体像は [セッションマネージャーでできること](/blog/browser-session-manager) で紹介しています。

<InstallCta>Chrome、Edge、Firefox に無料で追加できます。使い始めるのにアカウントは不要です。</InstallCta>
