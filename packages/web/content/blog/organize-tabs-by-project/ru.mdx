<QuickAnswer>

Заведите для каждого проекта отдельную группу [TabMerger](/features). Внутри держите по одному окну с названием на каждую часть работы («Дизайн», «Разработка», «Отзывы») и заметку группы с контекстом. Отметьте звёздочкой проекты этой недели, чтобы они оставались наверху, а когда проект завершён, **Архивировать группу** (Archive group) убирает его в режим только для чтения, не удаляя ни одной вкладки.

</QuickAnswer>

<InstallCta>Своё место для каждого проекта, в одном клике от открытия. Бесплатно для Chrome, Edge и Firefox.</InstallCta>

<Section id="problem" title="Когда три проекта делят одну панель вкладок">

Вы переделываете сайт, пишете отчёт и планируете поездку. К среде в браузере открыты все три: макеты рядом с поиском авиабилетов, pull request между двумя источниками для отчёта. Чтобы переключиться на другой проект, приходится просматривать всю панель, а закрывать что-либо страшно, потому что непонятно, к какому проекту это относится.

Встроенные группы вкладок браузера помогают внутри одного окна, но проект редко помещается в одно окно, а после закрытия окна уже не узнать, куда делись эти вкладки.

</Section>

<Section id="why" title="Почему группы TabMerger устроены именно так">

- **Группа — это проект, а не окно.** В каждой группе столько окон, сколько нужно для работы, и каждое окно открывается как отдельное окно браузера. Так проекты и выглядят на самом деле: вкладки по дизайну здесь, по разработке там.
- **Названия и заметки хранят контекст.** Окна можно переименовать и снабдить собственной заметкой, как и саму группу. Через несколько месяцев «Отзывы» и заметка о принятых решениях скажут больше, чем ряд значков сайтов.
- **Звёздочки сортируют за вас.** Группы со звёздочкой остаются вверху боковой панели, а окна со звёздочкой идут первыми в своей группе.
- **Архивировать значит убрать, а не удалить.** Архивная группа уходит из списка в раздел **Архив** (Archived) и становится доступна только для чтения, так что ничего не сдвинется случайно. Её вкладки по-прежнему открываются одним кликом, а **Восстановить** (Restore) возвращает её обратно.
- **Структура из браузера сохраняется.** Сохранённые вкладки помнят название и цвет своей группы вкладок Chrome, поэтому проект, который вы уже сгруппировали на панели вкладок, сохраняет свой вид.

<Section id="steps" title="Настройте проект за пять шагов">

1. Нажмите **Добавить группу** (Add Group) на боковой панели и назовите группу по проекту. Щёлкните цветную точку, чтобы выбрать цвет.
2. Откройте страницы проекта и выберите **Объединить с текущими** (Merge with current) в меню **⋯** группы, чтобы сохранить в неё открытые окна.
3. Переименуйте каждое окно через его меню **⋯** (**Переименовать окно**, Rename window) по той части работы, которая в нём лежит.
4. Добавьте заметку группы (**Добавить заметку**, Add note, в меню **⋯**) с контекстом: срок, задача, что значит «готово».
5. Отметьте группу звёздочкой (звёздочка рядом с названием), пока проект активен.

Чтобы потом перенести вкладки между проектами, перетащите их на группу в боковой панели или выберите **Переместить в группу** (Move to group) и **Копировать в группу** (Copy to group) в контекстном меню вкладки. **Объединить окна** (Unite windows) и **Разделить окна** (Split windows) перестраивают группу за один шаг.

</Section>

<Section id="archive" title="Отправьте завершённую работу в архив">

Когда проект завершён, щёлкните его группу на боковой панели правой кнопкой мыши и выберите **Архивировать группу**. Группа переходит в раздел **Архив** в режиме только для чтения: любую её вкладку по-прежнему можно открыть, а **Восстановить** возвращает всю группу в ваш список.

<Section id="benefit" title="Что вы получаете">

Переключиться на другой проект значит открыть группу, а не искать на панели вкладок. Можно закрыть все окна проекта, над которым вы сейчас не работаете, точно зная, где его вкладки, а боковая панель показывает только текущие дела.

</Section>

<Section id="habits" title="Полезные привычки">

- **Одна группа на проект, а не на тему.** «Редизайн сайта», а не «Ссылки по дизайну».
- **Называйте окна по этапам или ролям**, а не по сайтам: «Отзывы» проживут дольше, чем «GitHub».
- **Ставьте звёздочку лишь нескольким.** Звёздочка значит «на этой неделе».
- **Архивируйте в день сдачи.** Архивный проект по-прежнему в одном клике, так что держать его в списке незачем.
- **Пусть правила URL раскладывают новые вкладки** в проектах, где много всего происходит: см. [автосортировку вкладок с правилами URL](/blog/auto-sort-tabs-with-url-rules). Для проектов с большим объёмом исследований [организация вкладок для исследований](/blog/organize-tabs-for-research) добавляет заметки и напоминания.

</Section>
