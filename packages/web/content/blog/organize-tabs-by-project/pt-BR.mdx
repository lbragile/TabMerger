<QuickAnswer>

Dê a cada projeto o seu próprio grupo do [TabMerger](/features). Dentro dele, mantenha uma janela nomeada para cada parte do trabalho (“Design”, “Desenvolvimento”, “Feedback”) e uma nota do grupo com o contexto. Marque com estrela os projetos desta semana para que fiquem no topo e, quando um terminar, **Arquivar grupo** (Archive group) guarda o projeto em modo somente leitura, sem apagar nenhuma aba.

</QuickAnswer>

<InstallCta>Um lugar para cada projeto, a um clique de abrir. Grátis para Chrome, Edge e Firefox.</InstallCta>

<Section id="problem" title="Quando três projetos dividem a mesma barra de abas">

Você está redesenhando um site, escrevendo um relatório e planejando uma viagem. Lá pela quarta-feira, o navegador tem os três ao mesmo tempo: mockups ao lado de buscas de voos, um pull request entre duas fontes do relatório. Trocar de projeto significa percorrer a barra inteira, e fechar qualquer coisa parece arriscado, porque você não sabe a qual projeto ela pertence.

Os grupos de abas do próprio navegador ajudam dentro de uma janela, mas um projeto raramente cabe em uma janela só, e quando a janela é fechada, ninguém sabe mais para onde foram aquelas abas.

</Section>

<Section id="why" title="Por que os grupos do TabMerger funcionam do jeito que funcionam">

- **Um grupo é um projeto, não uma janela.** Cada grupo tem quantas janelas o trabalho precisar, e cada janela abre como uma janela separada do navegador. É assim que os projetos são de verdade: as abas de design aqui, as de desenvolvimento ali.
- **Nomes e notas guardam o contexto.** As janelas podem ser renomeadas e ter sua própria nota, assim como o grupo. Meses depois, “Feedback” e uma nota dizendo o que foi decidido valem mais que uma fileira de favicons.
- **As estrelas organizam por você.** Grupos com estrela ficam no topo da barra lateral, e janelas com estrela vêm primeiro dentro do grupo.
- **Arquivar é guardar, não apagar.** Um grupo arquivado sai da sua lista, vai para a seção **Arquivados** (Archived) e passa a ser somente leitura, para que nada mude de lugar por acidente. As abas ainda abrem com um clique, e **Restaurar** (Restore) traz o grupo de volta.
- **A estrutura do seu navegador é mantida.** As abas salvas mantêm o nome e a cor do grupo de abas do Chrome, então um projeto que você já agrupou na barra de abas mantém esse formato.

<Section id="steps" title="Configure um projeto em cinco passos">

1. Clique em **Adicionar grupo** (Add Group) na barra lateral e dê ao grupo o nome do projeto. Clique no ponto colorido para escolher uma cor.
2. Abra as páginas do projeto e escolha **Mesclar com as atuais** (Merge with current) no menu **⋯** do grupo para salvar nele as janelas abertas.
3. Renomeie cada janela pelo menu **⋯** dela (**Renomear janela**, Rename window) com a parte do trabalho que ela reúne.
4. Adicione uma nota ao grupo (**Adicionar nota**, Add note, no menu **⋯**) com o contexto: o prazo, o ticket, o que significa “pronto”.
5. Marque o grupo com estrela (a estrela ao lado do nome) enquanto o projeto estiver ativo.

Para mover abas entre projetos depois, arraste-as até um grupo na barra lateral ou use **Mover para o grupo** (Move to group) e **Copiar para o grupo** (Copy to group) no menu de clique com o botão direito da aba. **Unir janelas** (Unite windows) e **Dividir janelas** (Split windows) reorganizam um grupo em um só passo.

</Section>

<Section id="archive" title="Arquive o trabalho concluído">

Quando um projeto terminar, clique com o botão direito no grupo dele na barra lateral e escolha **Arquivar grupo**. Ele vai para a seção **Arquivados**, somente leitura: você ainda pode abrir qualquer uma das abas, e **Restaurar** traz o grupo inteiro de volta para a sua lista.

<Section id="benefit" title="O que você ganha">

Trocar de projeto passa a ser abrir um grupo em vez de procurar numa barra de abas. Você pode fechar todas as janelas de um projeto em que não está trabalhando sabendo exatamente onde estão as abas dele, e a barra lateral mostra só o que está em andamento.

</Section>

<Section id="habits" title="Bons hábitos">

- **Um grupo por projeto, não por assunto.** “Redesign do site”, não “Links de design”.
- **Dê às janelas nomes de etapas ou funções**, não de sites: “Feedback” dura mais que “GitHub”.
- **Use poucas estrelas.** Estrela significa “esta semana”.
- **Arquive no dia da entrega.** Um projeto arquivado continua a um clique, então não há motivo para mantê-lo na sua lista.
- **Deixe as regras de URL distribuírem as novas abas** nos projetos mais movimentados: veja [organizar abas automaticamente com regras de URL](/blog/auto-sort-tabs-with-url-rules). Para projetos com muita pesquisa, [organizar abas para pesquisa](/blog/organize-tabs-for-research) acrescenta notas e lembretes.

</Section>
