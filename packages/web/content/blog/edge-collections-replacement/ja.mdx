<QuickAnswer>

はい、廃止されました。Microsoft によると、**コレクション（Collections）は Edge 149 以降では使用できません**（2026 年 6 月 4 日リリース）。ただし、ページは削除されていません。**お気に入りに移動**（Move to Favorites）によって、各コレクションはお気に入りのフォルダーになりました。新しい置き場所として最適なのは [TabMerger](/features) です。お気に入りを HTML でエクスポートしてそのファイルをインポートすれば、「その他のお気に入り」内のフォルダーがそれぞれ名前付きで検索できるグループになり、メモ、リマインダー、暗号化された同期も使えます。Edge、Chrome、Firefox に対応しています。

</QuickAnswer>

<Section id="where" title="保存していたコレクションはどこへ行ったのですか？">

廃止の過程で、Edge はコレクションのウィンドウに 2 つの選択肢を表示していました。

- **お気に入りに移動**（Microsoft の推奨）：各コレクションがお気に入りのフォルダーになりました。移動したのは保存した Web ページだけで、画像やメモは移っていません。
- **データのエクスポート**（Export your data）：職場または学校のアカウントのみ。

個人の Microsoft アカウントなら、以前に保存したコレクションを `bing.com/saves` でも見つけられます。まずはお気に入り（<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>）を確認してください。コレクションはおそらくフォルダーとしてそこにあります。

</Section>

<Section id="move" title="コレクションを TabMerger に移すには？">

数分で、以前のコレクションがそれぞれグループになります。

1. Edge でお気に入りを開きます（<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>）。以前のコレクションが **お気に入りバー**（Favorites bar）の中にある場合は、それらのフォルダーを **その他のお気に入り**（Other favorites）に移します。エクスポートではお気に入りバー全体が 1 つのフォルダーとして書き出されるため、中に残ったフォルダーは 1 つのグループにまとめられてしまいます。
2. **Export favorites** を選び、HTML ファイルを保存します。
3. TabMerger を開き → **設定 → データ** → **ファイルをインポート**（Settings → Data → Import file）から、そのファイルを選びます。
4. 確認します。「その他のお気に入り」内の各フォルダーがフォルダー名のグループになり、その中のサブフォルダーは同じグループにまとめられます。お気に入りバーはそれだけで 1 つのグループとして取り込まれます。

<Section id="why" title="TabMerger がコレクションよりも良い置き場所である理由は？">

- **タブ一式をワンクリックで**。**現在の内容と統合**（Merge with current）で、開いているすべてのウィンドウを名前付きグループに保存できます。
- **どのタブにもメモとリマインダー**。コレクションでは移せなかったメモの代わりになります。タブを右クリックして **メモを追加**（Add note）または **後で通知…**（Remind me…）を選びます。
- **1 つの検索**で、開いているタブ、保存したタブ、最近閉じたタブをまとめて探せます：<Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>。
- **ブラウザーをまたいで使える**。Edge、Chrome、Firefox で同じグループを使え、Pro ではエンドツーエンド暗号化で同期されます。
- **データは自分のもの**。いつでもすべてを JSON にエクスポートできます。1 つの会社が機能を残すかどうかに左右されません。

タブ管理ツールは初めてですか？[ブラウザーのセッションマネージャーでできること](/blog/browser-session-manager)と[おすすめのタブ管理拡張機能](/blog/best-tab-manager-extensions)で全体像がつかめます。
