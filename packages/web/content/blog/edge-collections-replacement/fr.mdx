<QuickAnswer>

Oui, c’est fini : selon Microsoft, **les Collections ne sont plus disponibles à partir d’Edge 149** (publié le 4 juin 2026). Vos pages n’ont pas été effacées : **Déplacer vers les favoris** (Move to Favorites) a transformé chaque collection en dossier de favoris. Le meilleur nouveau foyer, c’est [TabMerger](/features) : exportez vos favoris en HTML, importez le fichier, et chaque dossier de « Autres favoris » devient un groupe nommé et consultable, avec notes, rappels et synchronisation chiffrée, dans Edge, Chrome et Firefox.

</QuickAnswer>

<Section id="where" title="Où sont passées mes collections ?">

Pendant le retrait, Edge affichait deux options dans le volet Collections :

- **Déplacer vers les favoris** (recommandé par Microsoft) : chaque collection est devenue un dossier de vos favoris. Seules les pages web enregistrées ont été déplacées, pas les images ni les notes.
- **Exporter vos données** (Export your data) : uniquement pour les comptes professionnels ou scolaires.

Avec un compte Microsoft personnel, vous retrouvez aussi vos collections enregistrées sur `bing.com/saves`. Commencez donc par vérifier vos favoris (<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>) : vos collections y sont très probablement, sous forme de dossiers.

</Section>

<Section id="move" title="Comment transférer mes collections dans TabMerger ?">

Quelques minutes suffisent, et chaque ancienne collection devient un groupe :

1. Dans Edge, ouvrez les Favoris (<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>). Si vos anciennes collections se trouvent dans **Barre des favoris** (Favorites bar), déplacez ces dossiers dans **Autres favoris** (Other favorites). L’export écrit toute la Barre des favoris comme un seul dossier : les dossiers restés à l’intérieur arriveraient fusionnés en un seul groupe.
2. Choisissez **Export favorites** et enregistrez le fichier HTML.
3. Ouvrez TabMerger → **Paramètres → Données** → **Importer un fichier** (Settings → Data → Import file), puis choisissez ce fichier.
4. Confirmez. Chaque dossier de « Autres favoris » devient un groupe portant le nom du dossier, et ses sous-dossiers sont regroupés dans ce groupe. La Barre des favoris arrive comme un groupe à part.

Vos autres dossiers de « Autres favoris » sont importés aussi ; supprimez les groupes dont vous n’avez pas besoin. Tous les formats d’import sont détaillés dans [importer des onglets dans TabMerger](/blog/import-tabs-into-tabmerger). La version gratuite contient 5 groupes et 50 onglets, et un import qui dépasserait cette limite est arrêté avant que quoi que ce soit ne soit ajouté ; [Pro](/pricing) n’a pas de limite.

<Section id="why" title="Pourquoi TabMerger est-il un meilleur foyer que ne l’étaient les Collections ?">

- **Des ensembles d’onglets entiers, en un clic.** **Fusionner avec l’actuel** (Merge with current) enregistre toutes les fenêtres ouvertes dans un groupe nommé.
- **Des notes et des rappels sur n’importe quel onglet,** pour remplacer les notes que les Collections n’ont pas pu déplacer : faites un clic droit sur un onglet et choisissez **Ajouter une note** (Add note) ou **Me le rappeler…** (Remind me…).
- **Une seule recherche** pour les onglets ouverts, enregistrés et récemment fermés : <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>.
- **Multinavigateur.** Les mêmes groupes dans Edge, Chrome et Firefox, synchronisés avec un chiffrement de bout en bout avec Pro.
- **Vos données vous appartiennent.** Exportez tout en JSON à tout moment ; rien ne dépend d’une entreprise qui maintiendrait une fonctionnalité en vie.
