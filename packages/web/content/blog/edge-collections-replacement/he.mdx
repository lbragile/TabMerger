<QuickAnswer>

כן, הם נעלמו: לפי Microsoft, **האוספים (<bdi dir="ltr">Collections</bdi>) אינם זמינים עוד החל מ-Edge 149** (שיצאה ב-4 ביוני 2026). אבל הדפים שלכם לא נמחקו: <bdi dir="ltr">**Move to Favorites**</bdi> (העברה למועדפים) הפכה כל אוסף לתיקייה במועדפים. הבית החדש הטוב ביותר הוא [TabMerger](/features): מייצאים את המועדפים כ-HTML, מייבאים את הקובץ, וכל תיקייה ב"מועדפים אחרים" הופכת לקבוצה עם שם שאפשר לחפש בה, עם הערות, תזכורות וסנכרון מוצפן, ב-Edge, ב-Chrome וב-Firefox.

</QuickAnswer>

<Section id="where" title="לאן נעלמו האוספים שלי?">

במהלך ההוצאה משימוש, Edge הציג שתי אפשרויות בחלונית האוספים:

- <bdi dir="ltr">**Move to Favorites**</bdi> (ההמלצה של Microsoft): כל אוסף הפך לתיקייה במועדפים. רק דפי האינטרנט השמורים הועברו; תמונות והערות לא.
- **ייצוא הנתונים שלך** (<bdi dir="ltr">Export your data</bdi>): לחשבונות עבודה או בית ספר בלבד.

בחשבון Microsoft אישי אפשר למצוא את האוספים שנשמרו בעבר גם ב-<bdi dir="ltr">`bing.com/saves`</bdi>. אז קודם כול בודקים את המועדפים (<bdi dir="ltr"><Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd></bdi>): סביר שהאוספים שלכם נמצאים שם כתיקיות.

</Section>

<Section id="move" title="איך מעבירים את האוספים ל-TabMerger?">

כמה דקות, וכל אוסף לשעבר הופך לקבוצה:

1. ב-Edge פותחים את המועדפים (<bdi dir="ltr"><Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd></bdi>). אם האוספים לשעבר נמצאים בתוך **סרגל המועדפים** (<bdi dir="ltr">Favorites bar</bdi>), מעבירים את התיקיות האלה אל **מועדפים אחרים** (<bdi dir="ltr">Other favorites</bdi>). הייצוא כותב את כל סרגל המועדפים כתיקייה אחת, כך שתיקיות שיישארו בתוכו יגיעו ממוזגות לקבוצה אחת.
2. בוחרים <bdi dir="ltr">**Export favorites**</bdi> ושומרים את קובץ ה-HTML.
3. פותחים את TabMerger ← **הגדרות ← נתונים** ← **ייבוא קובץ** (<bdi dir="ltr">Settings → Data → Import file</bdi>), ובוחרים את הקובץ הזה.
4. מאשרים. כל תיקייה ב"מועדפים אחרים" הופכת לקבוצה עם שם התיקייה, ותיקיות שבתוכה מצורפות לאותה קבוצה. סרגל המועדפים מגיע כקבוצה נפרדת משלו.

<Section id="why" title="למה TabMerger הוא בית טוב יותר ממה שהיו האוספים?">

- **סטים שלמים של כרטיסיות, בלחיצה אחת.** **מיזוג עם הנוכחיים** (<bdi dir="ltr">Merge with current</bdi>) שומר את כל החלונות הפתוחים בקבוצה עם שם.
- **הערות ותזכורות על כל כרטיסייה,** במקום ההערות שהאוספים לא הצליחו להעביר: לוחצים לחיצה ימנית על כרטיסייה ובוחרים **הוספת הערה** (<bdi dir="ltr">Add note</bdi>) או **תזכורת…** (<bdi dir="ltr">Remind me…</bdi>).
- **חיפוש אחד** בכרטיסיות פתוחות, שמורות ושנסגרו לאחרונה: <bdi dir="ltr"><Kbd>Ctrl</Kbd>+<Kbd>K</Kbd></bdi>.
- **בכל הדפדפנים.** אותן קבוצות ב-Edge, ב-Chrome וב-Firefox, בסנכרון מוצפן מקצה לקצה ב-Pro.
- **שלכם לתמיד.** מייצאים הכול ל-JSON מתי שרוצים; שום דבר לא תלוי בכך שחברה אחת תשאיר תכונה בחיים.

חדשים בעולם מנהלי הכרטיסיות? [מה עושה מנהל סשנים לדפדפן](/blog/browser-session-manager) ו[תוספי ניהול הכרטיסיות הטובים ביותר](/blog/best-tab-manager-extensions) נותנים את התמונה המלאה.

<InstallCta>חינם ל-Edge, ל-Chrome ול-Firefox. לא צריך חשבון כדי להתחיל.</InstallCta>

</Section>
