<QuickAnswer>

是的，已经下线：Microsoft 表示，**从 Edge 149 开始，集合（Collections）不再可用**（2026 年 6 月 4 日发布）。不过你的网页并没有被删除：**移动到收藏夹**（Move to Favorites）已把每个集合变成了一个收藏夹文件夹。最好的新去处是 [TabMerger](/features)：把收藏夹导出为 HTML，导入该文件后，“其他收藏夹”中的每个文件夹都会成为可搜索的命名分组，并支持备注、提醒和加密同步，适用于 Edge、Chrome 和 Firefox。

</QuickAnswer>

<Section id="where" title="我的集合去哪儿了？">

在停用期间，Edge 在集合窗格中提供了两个选项：

- **移动到收藏夹**（Microsoft 推荐）：每个集合都变成了收藏夹中的一个文件夹。只移动了保存的网页，图片和笔记没有移动。
- **导出数据**（Export your data）：仅限工作或学校帐户。

个人 Microsoft 帐户还可以在 `bing.com/saves` 找到以前保存的集合。所以请先查看收藏夹（<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>）：你的集合很可能就以文件夹的形式在那里。

</Section>

<Section id="move" title="如何把集合迁移到 TabMerger？">

只需几分钟，每个旧集合都会变成一个分组：

1. 在 Edge 中打开收藏夹（<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>）。如果旧集合在 **收藏夹栏**（Favorites bar）里，请把这些文件夹移到 **其他收藏夹**（Other favorites）。导出时整个收藏夹栏会被写成一个文件夹，留在里面的文件夹会被合并成一个分组。
2. 选择 **Export favorites**，保存 HTML 文件。
3. 打开 TabMerger → **设置 → 数据** → **导入文件**（Settings → Data → Import file），选择该文件。
4. 确认。“其他收藏夹”中的每个文件夹都会成为与文件夹同名的分组，其中的子文件夹会并入该分组。收藏夹栏会单独成为一个分组。

<Section id="why" title="为什么 TabMerger 比当年的集合更适合安放网页？">

- **整组标签页，一键保存**。**与当前合并**（Merge with current）会把所有打开的窗口保存到一个命名分组中。
- **任何标签页都能加备注和提醒**，弥补集合没能迁移的笔记：右键单击标签页，选择 **添加备注**（Add note）或 **提醒我…**（Remind me…）。
- **一次搜索**，覆盖打开的、已保存的和最近关闭的标签页：<Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>。
- **跨浏览器**。在 Edge、Chrome 和 Firefox 中使用相同的分组，Pro 版端到端加密同步。
- **数据归你所有**。随时把所有内容导出为 JSON；一切都不取决于某家公司是否保留某项功能。
