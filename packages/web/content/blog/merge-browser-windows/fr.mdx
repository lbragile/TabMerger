<QuickAnswer>

Pour fusionner **toutes** les fenêtres d’un coup, utilisez [TabMerger](/features) : cliquez sur **Ajouter un groupe**, choisissez **Fusionner avec l’actuel** dans son menu **⋯** pour y enregistrer toutes vos fenêtres ouvertes, puis faites un clic droit sur le groupe et choisissez **Tout ouvrir dans une nouvelle fenêtre**. Fermez les anciennes fenêtres : il n’en reste qu’une, et chaque onglet est enregistré au cas où vous voudriez le retrouver. Pour déplacer quelques onglets à la main, sélectionnez-les, faites un clic droit et choisissez **Déplacer les onglets vers une autre fenêtre** (Move tabs to another window ; Chrome, Edge).

</QuickAnswer>

<Section id="tabmerger" title="Comment fusionner toutes les fenêtres d’un coup ?">

Les navigateurs déplacent les onglets une fenêtre à la fois. TabMerger voit toutes vos fenêtres ensemble dans **Ouverts maintenant**, il peut donc les rassembler d’un seul coup :

1. Cliquez sur **Ajouter un groupe** et donnez-lui un nom, par exemple « Tout en un » (« All in one » sur les captures).
2. Ouvrez le menu **⋯** du groupe et choisissez **Fusionner avec l’actuel** : toutes les fenêtres ouvertes et leurs onglets sont enregistrés dans le groupe.
3. Faites un clic droit sur le groupe dans la barre latérale et choisissez **Tout ouvrir dans une nouvelle fenêtre** : une nouvelle fenêtre s’ouvre avec tous les onglets.
4. Fermez les anciennes fenêtres. Rien n’est perdu : le groupe les contient toujours.

<Section id="builtin" title="Comment déplacer des onglets d’une fenêtre à l’autre à la main ?">

Pratique pour deux fenêtres et une poignée d’onglets :

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

1. Sélectionnez les onglets : <Kbd>Ctrl</Kbd> + clic sur chacun, ou cliquez sur le premier puis <Kbd>Shift</Kbd> + clic sur le dernier.
2. Faites un clic droit sur un onglet sélectionné, choisissez **Déplacer les onglets vers une autre fenêtre** (Move tabs to another window), puis la fenêtre.
3. Ou faites glisser un onglet dans la barre d’onglets de l’autre fenêtre.

</BrowserPanel>
<BrowserPanel browser="edge">

1. Sélectionnez les onglets avec <Kbd>Ctrl</Kbd> + clic ou <Kbd>Shift</Kbd> + clic.
2. Faites un clic droit sur un onglet sélectionné, choisissez **Move tab to another window** (ou **Move tabs…** s’il y en a plusieurs), puis la fenêtre.

</BrowserPanel>
<BrowserPanel browser="firefox">

Faites un clic droit sur un onglet (ou sur plusieurs onglets sélectionnés) et ouvrez **Déplacer l’onglet** (Move Tab) : Firefox 159 propose **Déplacer vers le début**, **Déplacer vers la fin** et **Déplacer vers une nouvelle fenêtre**, mais aucune option pour une autre fenêtre déjà ouverte. Pour fusionner plusieurs fenêtres en une dans Firefox, suivez les étapes TabMerger ci-dessus.

</BrowserPanel>
</BrowserPanels>

<Catch>chaque déplacement ne concerne qu’une fenêtre. Avec cinq fenêtres, cela fait beaucoup de clics droits, et il faut encore fermer vous-même les fenêtres vidées.</Catch>

</Section>

<Section id="after" title="Comment s’en tenir à une seule fenêtre ?">

- **Enregistrez avant de fermer.** « Fusionner avec l’actuel » prend une seconde, et vous pouvez ensuite fermer n’importe quelle fenêtre sans arrière-pensée.
- **Un groupe par projet.** Si la fenêtre fusionnée est encore trop longue, répartissez-la à nouveau en groupes nommés ; notre [routine contre l’excès d’onglets](/blog/manage-too-many-tabs) montre comment.
- **Supprimez les doublons.** Les fenêtres fusionnées contiennent souvent la même page deux fois ; [fermer les onglets en double](/blog/close-duplicate-tabs) ne demande qu’un clic de plus dans TabMerger.
- **Gardez tout.** Pour mettre l’ensemble en pause et y revenir plus tard, voyez [comment enregistrer tous les onglets ouverts](/blog/save-all-open-tabs).

<InstallCta>Gratuit pour Chrome, Edge et Firefox. Aucun compte nécessaire pour commencer.</InstallCta>
