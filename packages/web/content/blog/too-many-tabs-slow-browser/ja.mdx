<QuickAnswer>

はい。開いているタブはそれぞれメモリを使い、数が増えればパソコン全体が重くなります。いちばん効くのは、**使っていないタブを失わずに閉じる**ことです。[TabMerger](/features) で **現在の内容と統合** を選んで開いているウィンドウをすべてグループに保存し、続けて **すべてのウィンドウを閉じる** を選びます。メモリが解放され、どのタブも1クリックで戻せます。開いたままにするタブには、**メモリセーバー**（Memory Saver、Chrome）か**スリープタブ**（Edge）をオンにしましょう。

</QuickAnswer>

<InstallCta>すべてのウィンドウを保存して閉じ、メモリを取り戻しましょう。Chrome、Edge、Firefox に無料で対応。</InstallCta>

<Section id="why" title="開いているタブでパソコンが重くなるのはなぜ？">

開いているタブは、どれも動いている Web ページです。テキストや画像、スクリプトがメモリに残り、動きの多いページ（動画、ライブフィード、Web アプリ）はプロセッサも使い続けます。ブラウザとほかのアプリがパソコンの搭載量より多くのメモリを必要とすると、すべてが遅くなります。Chrome のクラッシュに関するヘルプ自体が、メモリ不足をクラッシュの原因に挙げ、最初の対処法としてタブを閉じることを勧めています。

タブ1つの負荷はサイト次第なので、これなら安全という数はありません。目安はこうです。今日一度も見ていないタブなら、開いておく必要はありません。

</Section>

<Section id="tabmerger" title="タブを失わずに閉じるには？">

ここで [TabMerger](/features) の出番です。2ステップで、すべてのウィンドウを一度に処理できます。

1. **グループを追加** をクリックし、そのグループの **⋯** メニューで **現在の内容と統合** を選びます。開いているウィンドウとタブがすべてグループに保存されます。
2. サイドバーの **現在開いているタブ** を右クリックし、**すべてのウィンドウを閉じる** を選びます。ブラウザのウィンドウは閉じ、グループにはすべてのタブが残ります。

また必要になったら、グループを開いてタブを1つ、ウィンドウを1つ、またはすべてを開き直します。<Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> を押せば保存したタブをすぐに見つけられ、自動保存を使えばスケジュールに合わせて保存も任せられます。ほかの習慣は[タブが多すぎるときの整理術](/blog/manage-too-many-tabs)をご覧ください。

</Section>

<Section id="browser" title="使っていないタブをブラウザにスリープさせるには？">

開いたままのタブは、使っていない間にブラウザがメモリを解放できます。クリックすると再読み込みされます。

<BrowserPanels section="browser">
<BrowserPanel browser="chrome">

**メモリセーバー**（Memory Saver）をオンにします。**設定 → パフォーマンス**（Settings → Performance）を開くか、アドレスバーに `chrome://settings/performance` を貼り付けます。タブが非アクティブになるまでの早さは、適度（Moderate）、バランス重視（Balanced）、最大（Maximum）から選べます。

<AnnotatedFigure src="/blog/manage-too-many-tabs/chrome-memory-saver.webp" alt="Chrome の設定の「Performance」（パフォーマンス）。「Memory Saver」（メモリセーバー）のスイッチがある" width={1600} height={524} boxes={[{ id: 'memory-saver' }]} source="chrome://settings/performance · Chrome 157.0.8103.80">Chrome の「Memory Saver」（メモリセーバー）。新しい Chrome 157 プロファイルではオフでした。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="edge">

**設定 → System and performance → Performance** で **Automatically put tabs to sleep** をオンにし、タブがスリープするまでの時間を選びます。

<AnnotatedFigure src="/blog/manage-too-many-tabs/edge-sleeping-tabs.webp" alt="Edge の設定の「Performance」。「Automatically put tabs to sleep」がオンで、15分に設定されている" width={1600} height={855} boxes={[{ id: 'sleeping-tabs' }]} source="edge://settings · Edge 158.0.4370.33">Edge のスリープタブは初期設定でオン。使っていないタブは15分後にスリープします。</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="firefox">

タブを右クリックして **タブを解放**（Unload Tab）を選ぶと、そのタブのメモリをすぐに解放できます。複数のタブを先に選択しておけば、まとめて解放できます。

</BrowserPanel>
</BrowserPanels>

<Catch>スリープ中のタブも、タブバーを埋め尽くすことに変わりはありません。助かるのはパソコンで、あなたの集中力ではありません。</Catch>

</Section>

<Section id="which" title="動作を重くしているタブを見つけるには？">

Chrome で <Kbd>Shift</Kbd>+<Kbd>Esc</Kbd> を押して **Chrome タスク マネージャー**（Chrome Task Manager）を開き、メモリ使用量の多いタブを探します。重いタブは TabMerger のグループに保存して閉じましょう。
