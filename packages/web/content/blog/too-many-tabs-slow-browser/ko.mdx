<QuickAnswer>

네. 열린 탭은 하나하나 메모리를 쓰고, 탭이 충분히 많아지면 컴퓨터 전체가 느려집니다. 가장 효과가 큰 방법은 **쓰지 않는 탭을 잃지 않고 닫는 것**입니다. [TabMerger](/features)에서 **현재 상태와 합치기** 를 선택해 열린 창을 모두 그룹에 저장한 다음, **모든 창 닫기** 를 선택하세요. 메모리가 비워지고, 모든 탭은 클릭 한 번이면 돌아옵니다. 열어 둘 탭에는 **메모리 절약 모드**(Memory Saver, Chrome)나 **절전 탭**(Edge)을 켜세요.

</QuickAnswer>

<InstallCta>모든 창을 저장하고, 모두 닫고, 메모리를 되찾으세요. Chrome, Edge, Firefox에서 무료입니다.</InstallCta>

<Section id="why" title="열린 탭은 왜 컴퓨터를 느리게 할까?">

열린 탭은 하나하나가 살아 있는 웹페이지입니다. 텍스트, 이미지, 스크립트가 메모리에 남아 있고, 활발한 페이지(동영상, 실시간 피드, 웹 앱)는 프로세서도 계속 씁니다. 브라우저와 다른 앱이 컴퓨터에 있는 것보다 많은 메모리를 필요로 하면 모든 것이 느려집니다. Chrome의 비정상 종료 도움말에서도 메모리 부족을 비정상 종료의 원인으로 들고, 첫 번째 해결책으로 탭 닫기를 제시합니다.

탭 하나의 부담은 전적으로 사이트에 달려 있어서, 안전한 개수란 없습니다. 실용적인 기준은 이렇습니다. 오늘 한 번도 보지 않은 탭이라면 열어 둘 필요가 없습니다.

</Section>

<Section id="tabmerger" title="탭을 잃지 않고 닫으려면 어떻게 하나요?">

바로 여기서 [TabMerger](/features)가 빛을 발합니다. 두 단계로 모든 창을 한 번에 처리합니다.

1. **그룹 추가** 를 클릭한 다음 그룹의 **⋯** 메뉴에서 **현재 상태와 합치기** 를 선택합니다. 열린 창과 탭이 모두 그룹에 저장됩니다.
2. 사이드바의 **현재 열린 탭** 을 마우스 오른쪽 버튼으로 클릭하고 **모든 창 닫기** 를 선택합니다. 브라우저 창은 닫히고, 그룹에는 모든 탭이 남습니다.

다시 필요할 때는 그룹을 열고 탭 하나, 창 하나 또는 전부를 다시 엽니다. <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>로 저장한 탭을 바로 찾을 수 있고, 자동 저장을 쓰면 일정에 맞춰 저장도 맡길 수 있습니다. 더 많은 습관은 [탭이 너무 많을 때의 정리 루틴](/blog/manage-too-many-tabs)에서 확인하세요.

</Section>

<Section id="browser" title="브라우저가 쉬고 있는 탭을 재우게 하려면?">

열어 두는 탭은 쓰지 않는 동안 브라우저가 메모리를 비울 수 있습니다. 탭을 클릭하면 다시 불러옵니다.

<BrowserPanels section="browser">
<BrowserPanel browser="chrome">

**메모리 절약 모드**(Memory Saver)를 켜세요. **설정 → 성능**(Settings → Performance)으로 가거나 주소창에 `chrome://settings/performance`를 붙여 넣으면 됩니다. 탭이 얼마나 빨리 비활성 상태가 될지는 보통(Moderate), 균형(Balanced), 최대(Maximum) 중에서 고를 수 있습니다.

<AnnotatedFigure src="/blog/manage-too-many-tabs/chrome-memory-saver.webp" alt="Chrome 설정의 Performance(성능) 화면과 Memory Saver(메모리 절약 모드) 스위치" width={1600} height={524} boxes={[{ id: 'memory-saver' }]} source="chrome://settings/performance · Chrome 157.0.8103.80">새 Chrome 157 프로필에서 꺼져 있던 Chrome의 Memory Saver(메모리 절약 모드).</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="edge">

**설정 → System and performance → Performance**에서 **Automatically put tabs to sleep**을 켜고, 탭이 절전 모드로 들어가기까지 기다릴 시간을 고르세요.

<AnnotatedFigure src="/blog/manage-too-many-tabs/edge-sleeping-tabs.webp" alt="Edge 설정의 Performance 화면: Automatically put tabs to sleep이 켜져 있고 15분으로 설정됨" width={1600} height={855} boxes={[{ id: 'sleeping-tabs' }]} source="edge://settings · Edge 158.0.4370.33">기본으로 켜져 있는 Edge의 절전 탭: 비활성 탭은 15분 후 절전 모드로 들어갑니다.</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="firefox">

탭을 마우스 오른쪽 버튼으로 클릭하고 **탭 언로드**(Unload Tab)를 선택하면 그 탭의 메모리를 바로 비울 수 있습니다. 여러 탭을 먼저 선택하면 한꺼번에 언로드할 수 있습니다.

</BrowserPanel>
</BrowserPanels>

<Catch>절전 탭도 탭 표시줄을 가득 채우는 건 마찬가지입니다. 컴퓨터에는 도움이 되지만 여러분의 집중에는 도움이 되지 않습니다.</Catch>

</Section>

<Section id="which" title="모든 것을 느리게 만드는 탭은 어떻게 찾나요?">

Chrome에서 <Kbd>Shift</Kbd>+<Kbd>Esc</Kbd>를 눌러 **Chrome 작업 관리자**(Chrome Task Manager)를 열고 메모리를 가장 많이 쓰는 탭을 찾으세요. 무거운 탭은 TabMerger 그룹에 저장한 뒤 닫으세요.
