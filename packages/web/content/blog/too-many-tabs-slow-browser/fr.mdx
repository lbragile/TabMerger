<QuickAnswer>

Oui : chaque onglet ouvert utilise de la mémoire, et quand il y en a assez, tout l’ordinateur ralentit. Le plus efficace est de **fermer les onglets que vous n’utilisez pas, sans les perdre**. Dans [TabMerger](/features), choisissez **Fusionner avec l’actuel** pour enregistrer toutes les fenêtres ouvertes dans un groupe, puis **Fermer toutes les fenêtres** : la mémoire est libérée et chaque onglet reste à un clic. Pour les onglets que vous gardez ouverts, activez l’**économiseur de mémoire** (« Memory Saver », Chrome) ou les **onglets en veille** (Edge).

</QuickAnswer>

<InstallCta>Enregistrez toutes les fenêtres, fermez-les et récupérez la mémoire. Gratuit pour Chrome, Edge et Firefox.</InstallCta>

<Section id="why" title="Pourquoi les onglets ouverts ralentissent-ils l’ordinateur ?">

Chaque onglet ouvert est une page web vivante : son texte, ses images et ses scripts restent en mémoire, et les pages très actives (vidéo, flux en direct, applications web) sollicitent aussi le processeur en continu. Quand le navigateur et vos autres applications demandent plus de mémoire que l’ordinateur n’en a, tout ralentit. L’aide de Chrome sur les plantages cite elle-même le manque de mémoire comme cause de plantage, et sa première solution est de fermer des onglets.

Ce que coûte un onglet dépend entièrement du site : il n’existe donc pas de nombre sans risque. La règle pratique : si vous ne l’avez pas regardé aujourd’hui, il n’a pas à être ouvert.

</Section>

<Section id="tabmerger" title="Comment fermer des onglets sans les perdre ?">

C’est là que [TabMerger](/features) excelle. Deux étapes, toutes les fenêtres d’un coup :

1. Cliquez sur **Ajouter un groupe**, puis choisissez **Fusionner avec l’actuel** dans son menu **⋯** : toutes les fenêtres et tous les onglets ouverts sont enregistrés dans le groupe.
2. Faites un clic droit sur **Ouverts maintenant** dans la barre latérale et choisissez **Fermer toutes les fenêtres**. Les fenêtres du navigateur se ferment ; le groupe garde tous les onglets.

<Section id="browser" title="Comment faire mettre en veille les onglets inactifs par le navigateur ?">

Pour les onglets que vous gardez ouverts, le navigateur peut libérer leur mémoire tant que vous ne les utilisez pas. Ils se rechargent quand vous cliquez dessus.

<BrowserPanels section="browser">
<BrowserPanel browser="chrome">

Activez l’**économiseur de mémoire** (« Memory Saver ») : **Paramètres → Performances** (« Settings → Performance »), ou collez `chrome://settings/performance` dans la barre d’adresse. Choisissez au bout de combien de temps les onglets deviennent inactifs : Modéré (« Moderate »), Équilibré (« Balanced ») ou Maximal (« Maximum »).

</BrowserPanel>
<BrowserPanel browser="edge">

Activez **Automatically put tabs to sleep** dans **Paramètres → System and performance → Performance**, et choisissez combien de temps un onglet attend avant de se mettre en veille.

<AnnotatedFigure src="/blog/manage-too-many-tabs/edge-sleeping-tabs.webp" alt="Paramètres d’Edge, « Performance », avec « Automatically put tabs to sleep » activé et réglé sur 15 minutes" width={1600} height={855} boxes={[{ id: 'sleeping-tabs' }]} source="edge://settings · Edge 158.0.4370.33">Les onglets en veille d’Edge, activés par défaut : les onglets inactifs se mettent en veille au bout de 15 minutes.</AnnotatedFigure>

</BrowserPanel>
<BrowserPanel browser="firefox">

Faites un clic droit sur un onglet et choisissez **Décharger l’onglet** (« Unload Tab ») pour libérer sa mémoire tout de suite ; sélectionnez d’abord plusieurs onglets pour les décharger ensemble.

</BrowserPanel>
</BrowserPanels>

<Catch>les onglets en veille encombrent toujours la barre d’onglets. Ils aident l’ordinateur, pas votre concentration.</Catch>

</Section>

<Section id="which" title="Comment trouver l’onglet qui ralentit tout ?">

Dans Chrome, appuyez sur <Kbd>Shift</Kbd>+<Kbd>Esc</Kbd> pour ouvrir le **gestionnaire de tâches Chrome** (« Chrome Task Manager ») et repérez les onglets qui utilisent le plus de mémoire. Enregistrez les plus gourmands dans un groupe TabMerger et fermez-les.
