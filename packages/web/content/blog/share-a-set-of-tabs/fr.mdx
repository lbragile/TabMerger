<QuickAnswer>

La solution en un clic, c’est un lien de partage [TabMerger](/features) : sélectionnez vos groupes, appuyez sur **Partager** (Share) et collez le lien. La personne qui l’ouvre voit tous les onglets sur une page en lecture seule et peut ouvrir un onglet, une fenêtre ou tout à la fois, sans compte. Les onglets sont **chiffrés de bout en bout** : même TabMerger ne peut pas les lire. Sans extension, ajoutez les onglets aux favoris et envoyez le fichier de favoris exporté, ou, dans Firefox, copiez tous les liens d’un groupe d’onglets.

</QuickAnswer>

<InstallCta>Partagez tout un ensemble d’onglets avec un seul lien chiffré. Gratuit pour commencer ; le partage fait partie de Pro.</InstallCta>

<Section id="manual" title="Comment partager des onglets sans extension ?">

<BrowserPanels section="manual">
<BrowserPanel browser="chrome">

1. Appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> pour ajouter les onglets de la fenêtre aux favoris, dans un nouveau dossier.
2. Ouvrez **⋮ → Favoris et listes → Gestionnaire de favoris** (Bookmark Manager), puis **⋮ (Plus) → Exporter les favoris** (Export bookmarks).
3. Envoyez le fichier HTML. L’autre personne l’importe dans son navigateur (ou dans TabMerger).

</BrowserPanel>
<BrowserPanel browser="edge">

1. Appuyez sur <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> pour ajouter les onglets de la fenêtre aux favoris, dans un nouveau dossier.
2. Ouvrez les favoris (<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>) et choisissez **Export favorites**.
3. Envoyez le fichier HTML.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. Placez les onglets dans un groupe d’onglets (faites glisser un onglet sur un autre).
2. Faites un clic droit sur l’étiquette du groupe et choisissez **Copier les liens dans le groupe** (Copy links in group).
3. Collez les liens dans un message ou un document.

</BrowserPanel>
</BrowserPanels>

<Catch>un fichier de favoris exporte *tous* vos favoris, et les liens collés arrivent sous forme d’un mur d’adresses que l’autre personne doit ouvrir un par un.</Catch>

</Section>

<Section id="tabmerger" title="Comment partager des onglets avec un seul lien ?">

1. Dans TabMerger, enregistrez les onglets dans un groupe (**Fusionner avec l’actuel**, Merge with current, enregistre toutes les fenêtres ouvertes).
2. Faites un **Ctrl+clic** (<Kbd>⌘</Kbd>+clic sur Mac) dans la barre latérale sur chaque groupe à partager.
3. Appuyez sur **Partager** dans la barre de sélection. Le lien est copié dans le presse-papiers ; collez-le où vous voulez.

Comment le partage reste privé : TabMerger génère une nouvelle clé dans votre navigateur, chiffre les groupes avec elle et n’envoie que la copie chiffrée. La clé est placée dans le lien après le `#`, une partie de l’adresse que les navigateurs n’envoient jamais à un serveur : seules les personnes qui ont le lien complet peuvent lire les onglets. La création de liens fait partie de [Pro](/pricing).

</Section>

<Section id="what-they-see" title="Que voit l’autre personne ?">

Une page en lecture seule avec chaque groupe et chaque fenêtre, le nombre d’onglets et des boutons pour **Ouvrir tous les onglets** (Open all tabs) d’une fenêtre, **Ouvrir la fenêtre** (Open window) pour un groupe entier, ou ouvrir des onglets un par un. Pas besoin de compte, ni de TabMerger. Si la personne utilise TabMerger, elle peut ouvrir les onglets et les enregistrer dans son propre groupe avec **Fusionner avec l’actuel**.
