<QuickAnswer>

클릭 한 번으로 끝내려면 [TabMerger](/features) 공유 링크를 쓰세요. 그룹을 선택하고 **공유**(Share)를 누른 뒤 링크를 붙여 넣으면 됩니다. 링크를 연 사람은 모든 탭을 읽기 전용 페이지에서 보고, 계정 없이 탭 하나, 창 하나 또는 전부를 열 수 있습니다. 게다가 탭은 **엔드투엔드 암호화**되므로 TabMerger조차 내용을 읽을 수 없습니다. 확장 프로그램 없이 하려면 탭을 북마크하고 내보낸 북마크 파일을 보내거나, Firefox에서 탭 그룹의 모든 링크를 복사하세요.

</QuickAnswer>

<InstallCta>탭 묶음 전체를 암호화 링크 하나로 공유하세요. 무료로 시작하고, 공유는 Pro 기능입니다.</InstallCta>

<Section id="manual" title="확장 프로그램 없이 탭을 공유하려면?">

<BrowserPanels section="manual">
<BrowserPanel browser="chrome">

1. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>를 눌러 창의 탭을 새 폴더에 북마크합니다.
2. **⋮ → 북마크 및 목록 → 북마크 관리자**(Bookmark Manager)를 연 다음 **⋮(더보기) → 북마크 내보내기**(Export bookmarks)를 선택합니다.
3. HTML 파일을 보냅니다. 받는 사람은 이 파일을 자신의 브라우저(또는 TabMerger)로 가져옵니다.

</BrowserPanel>
<BrowserPanel browser="edge">

1. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>를 눌러 창의 탭을 새 폴더에 즐겨찾기로 추가합니다.
2. 즐겨찾기(<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>)를 열고 **Export favorites**를 선택합니다.
3. HTML 파일을 보냅니다.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. 탭을 탭 그룹에 넣습니다(탭 하나를 다른 탭 위로 끌어다 놓기).
2. 그룹 라벨을 마우스 오른쪽 버튼으로 클릭하고 **그룹의 링크 복사**(Copy links in group)를 선택합니다.
3. 링크를 메시지나 문서에 붙여 넣습니다.

</BrowserPanel>
</BrowserPanels>

<Section id="tabmerger" title="링크 하나로 탭을 공유하려면?">

1. TabMerger에서 탭을 그룹에 저장합니다(**현재 상태와 합치기**(Merge with current)로 열린 창을 모두 저장할 수 있습니다).
2. 사이드바에서 공유할 그룹을 각각 **Ctrl+클릭**(Mac에서는 <Kbd>⌘</Kbd>+클릭)합니다.
3. 선택 표시줄에서 **공유**를 누릅니다. 링크가 클립보드에 복사되니 원하는 곳에 붙여 넣으세요.

비공개가 유지되는 방식: TabMerger는 브라우저에서 새 키를 생성해 그 키로 그룹을 암호화하고, 암호화된 사본만 업로드합니다. 키는 링크의 `#` 뒤에 들어가는데, 이 부분은 브라우저가 서버로 보내지 않는 주소 영역이므로 전체 링크를 가진 사람만 탭을 읽을 수 있습니다. 링크 만들기는 [Pro](/pricing) 기능입니다.

<Section id="what-they-see" title="받는 사람에게는 무엇이 보이나요?">

각 그룹과 창, 탭 수가 표시되는 읽기 전용 페이지입니다. 창 하나의 탭을 여는 **모든 탭 열기**(Open all tabs), 그룹 전체를 여는 **창 열기**(Open window) 버튼이 있고, 탭을 하나씩 열 수도 있습니다. 계정도 TabMerger도 필요 없습니다. TabMerger를 쓰는 사람이라면 탭을 연 뒤 **현재 상태와 합치기**로 자신의 그룹으로 저장할 수 있습니다.

<ThemedScreenshot src="/blog/share-a-set-of-tabs/share-page" width={1600} height={1115} alt="읽기 전용인 TabMerger의 Shared Groups(공유 그룹) 페이지. 그룹 두 개와 Open window(창 열기), Open all tabs(모든 탭 열기) 버튼이 보임, 라이트 테마" darkAlt="읽기 전용인 TabMerger의 Shared Groups(공유 그룹) 페이지. 그룹 두 개와 Open window(창 열기), Open all tabs(모든 탭 열기) 버튼이 보임, 다크 테마" source="tabmerger.com/share/demo">TabMerger의 공개 데모 링크로 연 공유 페이지.</ThemedScreenshot>

파일이 더 편하다면 TabMerger의 [JSON 내보내기](/blog/export-open-tabs)(Export JSON)를 Free 요금제에서도 쓸 수 있고, 내 기기 사이에서 옮기는 방법은 [탭을 다른 컴퓨터로 옮기기](/blog/move-tabs-between-computers)에서 다룹니다.
