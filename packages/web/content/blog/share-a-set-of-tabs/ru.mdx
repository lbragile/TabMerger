<QuickAnswer>

Быстрее всего — ссылка для общего доступа из [TabMerger](/features): выберите группы, нажмите **Поделиться** (Share) и вставьте ссылку. Тот, кто её откроет, увидит все вкладки на странице только для чтения и сможет открыть одну вкладку, окно или всё сразу, без аккаунта. Вкладки защищены **сквозным шифрованием**, так что даже TabMerger не может их прочитать. Без расширения добавьте вкладки в закладки и отправьте экспортированный файл закладок или в Firefox скопируйте все ссылки из группы вкладок.

</QuickAnswer>

<InstallCta>Поделитесь целым набором вкладок одной зашифрованной ссылкой. Начать можно бесплатно; общий доступ входит в Pro.</InstallCta>

<Section id="manual" title="Как поделиться вкладками без расширения?">

<BrowserPanels section="manual">
<BrowserPanel browser="chrome">

1. Нажмите <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>, чтобы добавить вкладки окна в закладки, в новую папку.
2. Откройте **⋮ → Закладки и списки → Диспетчер закладок** (Bookmark Manager), а затем **⋮ (Ещё) → Экспортировать закладки** (Export bookmarks).
3. Отправьте HTML-файл. Получатель импортирует его в свой браузер (или в TabMerger).

</BrowserPanel>
<BrowserPanel browser="edge">

1. Нажмите <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>, чтобы добавить вкладки окна в избранное, в новую папку.
2. Откройте избранное (<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>) и выберите **Export favorites**.
3. Отправьте HTML-файл.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. Объедините вкладки в группу (перетащите одну вкладку на другую).
2. Нажмите правой кнопкой мыши на название группы и выберите **Копировать ссылки в группе** (Copy links in group).
3. Вставьте ссылки в сообщение или документ.

</BrowserPanel>
</BrowserPanels>

<Catch>файл закладок экспортирует *все* ваши закладки, а вставленные ссылки приходят стеной адресов, которые получателю придётся открывать по одной.</Catch>

</Section>

<Section id="tabmerger" title="Как поделиться вкладками одной ссылкой?">

1. В TabMerger сохраните вкладки в группу (**Объединить с текущими**, Merge with current, сохраняет все открытые окна).
2. **Ctrl+клик** (<Kbd>⌘</Kbd>+клик на Mac) на боковой панели по каждой группе, которой хотите поделиться.
3. Нажмите **Поделиться** на панели выбора. Ссылка скопируется в буфер обмена; вставьте её куда угодно.

Почему это приватно: TabMerger создаёт в вашем браузере новый ключ, шифрует им группы и загружает только зашифрованную копию. Ключ попадает в ссылку после `#` — в ту часть адреса, которую браузеры никогда не отправляют на сервер, поэтому прочитать вкладки может только тот, у кого есть полная ссылка. Создание ссылок входит в [Pro](/pricing).

</Section>

<Section id="what-they-see" title="Что увидит получатель?">

Страницу только для чтения с каждой группой и окном, числом вкладок и кнопками **Открыть все вкладки** (Open all tabs) для окна, **Открыть окно** (Open window) для всей группы или для открытия отдельных вкладок. Ни аккаунт, ни TabMerger не нужны. Если получатель пользуется TabMerger, он может открыть вкладки и сохранить их как свою группу через **Объединить с текущими**.
