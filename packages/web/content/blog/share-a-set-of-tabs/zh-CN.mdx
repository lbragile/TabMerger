<QuickAnswer>

一键分享的办法是 [TabMerger](/features) 分享链接：选中分组，点击**分享**（Share），然后粘贴链接即可。打开链接的人会在一个只读页面上看到所有标签页，无需账号就能打开一个标签页、一个窗口或全部。而且这些标签页是**端到端加密**的，连 TabMerger 也读不到。如果不用扩展程序，可以把标签页加入书签并发送导出的书签文件，或者在 Firefox 中复制一个标签页组里的所有链接。

</QuickAnswer>

<Section id="manual" title="不用扩展程序，如何分享标签页？">

<BrowserPanels section="manual">
<BrowserPanel browser="chrome">

1. 按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>，把当前窗口的标签页加入书签，存进一个新文件夹。
2. 打开 **⋮ → 书签和清单 → 书签管理器**（Bookmark Manager），然后选择 **⋮（更多）→ 导出书签**（Export bookmarks）。
3. 发送这个 HTML 文件。对方把它导入自己的浏览器（或导入 TabMerger）。

</BrowserPanel>
<BrowserPanel browser="edge">

1. 按 <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>，把当前窗口的标签页添加到收藏夹，存进一个新文件夹。
2. 打开收藏夹（<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>），选择 **Export favorites**。
3. 发送这个 HTML 文件。

</BrowserPanel>
<BrowserPanel browser="firefox">

1. 把标签页放进一个标签页组（把一个标签页拖到另一个上面）。
2. 右键点击分组的标签，选择**复制群组中的链接**（Copy links in group）。
3. 把链接粘贴到消息或文档里。

</BrowserPanel>
</BrowserPanels>

<Catch>书签文件会导出你*所有的*书签，而粘贴过去的链接到了对方那里就是一堵地址墙，只能一个一个地打开。</Catch>

</Section>

<Section id="tabmerger" title="如何用一个链接分享标签页？">

1. 在 TabMerger 中把标签页保存到一个分组（**与当前合并**（Merge with current）会保存所有打开的窗口）。
2. 在侧边栏中 **Ctrl+点击**（Mac 上为 <Kbd>⌘</Kbd>+点击）每个要分享的分组。
3. 点击选择栏中的**分享**。链接会复制到剪贴板，粘贴到任何地方都可以。

如何保证私密：TabMerger 在你的浏览器中生成一个新密钥，用它加密分组，只上传加密后的副本。密钥放在链接的 `#` 之后，这部分地址浏览器从不发送给服务器，所以只有拿到完整链接的人才能读取这些标签页。创建链接属于 [Pro](/pricing) 功能。
