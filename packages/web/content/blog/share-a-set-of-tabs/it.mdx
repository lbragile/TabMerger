<QuickAnswer>

Il modo più rapido è un link di condivisione di [TabMerger](/features): seleziona i gruppi, premi **Condividi** (Share) e incolla il link. Chi lo apre vede tutte le schede in una pagina di sola lettura e può aprire una scheda, una finestra o tutto, senza account. Le schede sono **crittografate end-to-end**, quindi nemmeno TabMerger può leggerle. Senza estensioni, salva le schede nei preferiti e invia il file dei preferiti esportato, oppure in Firefox copia tutti i link di un gruppo di schede.

</QuickAnswer>

<InstallCta>Condividi un intero gruppo di schede con un solo link crittografato. Si inizia gratis; la condivisione fa parte di Pro.</InstallCta>

<Section id="manual" title="Come condivido le schede senza un’estensione?">

<BrowserPanels section="manual">
<BrowserPanel browser="chrome">

1. Premi <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> per salvare le schede della finestra nei preferiti, in una nuova cartella.
2. Apri **⋮ → Preferiti ed elenchi → Gestione preferiti** (Bookmark Manager), poi **⋮ (Altro) → Esporta preferiti** (Export bookmarks).
3. Invia il file HTML. L’altra persona lo importa nel suo browser (o in TabMerger).

</BrowserPanel>
<BrowserPanel browser="edge">

1. Premi <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd> per aggiungere le schede della finestra ai preferiti, in una nuova cartella.
2. Apri i Preferiti (<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>O</Kbd>) e scegli **Export favorites**.
3. Invia il file HTML.

</BrowserPanel>
<BrowserPanel browser="firefox">

1. Metti le schede in un gruppo di schede (trascina una scheda su un’altra).
2. Fai clic destro sull’etichetta del gruppo e scegli **Copia link nel gruppo** (Copy links in group).
3. Incolla i link in un messaggio o in un documento.

</BrowserPanel>
</BrowserPanels>

<Catch>un file di preferiti esporta *tutti* i tuoi preferiti, e i link incollati arrivano come un muro di indirizzi che l’altra persona deve aprire uno per uno.</Catch>

</Section>

<Section id="tabmerger" title="Come condivido le schede con un solo link?">

1. In TabMerger, salva le schede in un gruppo (**Unisci con l'attuale**, Merge with current, salva tutte le finestre aperte).
2. Fai **Ctrl+clic** (<Kbd>⌘</Kbd>+clic su Mac) nella barra laterale su ogni gruppo che vuoi condividere.
3. Premi **Condividi** nella barra di selezione. Il link viene copiato negli appunti; incollalo dove vuoi.

Come resta privato: TabMerger genera una nuova chiave nel tuo browser, crittografa i gruppi con quella chiave e carica solo la copia crittografata. La chiave va nel link dopo il `#`, una parte dell’indirizzo che i browser non inviano mai a un server, quindi solo chi ha il link completo può leggere le schede. La creazione di link fa parte di [Pro](/pricing).

<Section id="what-they-see" title="Cosa vede l’altra persona?">

Non servono un account né TabMerger. Chi usa TabMerger può aprire le schede e salvarle come un proprio gruppo con **Unisci con l'attuale**.
