<QuickAnswer>

把每天要用的标签页放进 [TabMerger](/features) 分组，然后点击 **保存当前会话**（Save current session），也就是侧边栏 **会话**（Sessions）旁边的书签按钮，并把会话命名为“工作日”。每天早上恢复它：TabMerger 会先询问，再关闭已打开的窗口，并按原来的顺序重新打开每个已保存的窗口及其标签页。只需要一个项目？右键点击它的分组，选择 **在新窗口中全部打开**（Open all in new window）。

</QuickAnswer>

<Section id="problem" title="每天早上的重建">

大多数早上的开头都一样。邮件、日历、团队看板、正在评审的拉取请求、正在写的文档。你从书签里、从历史记录里、凭记忆把它们一个个打开。有些天浏览器反而恢复了昨天的窗口，于是你从四十个标签页开始，再关掉其中三十五个。

无论哪种情况，一天的头几分钟都花在了重建一个你本来就有的工作区上。而且浏览器自带的恢复只会带回碰巧开着的东西，而不是你打算处理的东西。

</Section>

<Section id="why" title="TabMerger 会话为什么这样设计">

会话背后的每个设计都对应着这个问题的一部分：

- **会话保存的是你的分组，而不是所有打开的东西**。分组是你决定留下的标签页，已经命名并整理好。会话用一个名称为它们全部拍下快照，所以恢复时你得到的是自己的计划，而不是昨天的杂乱。（实时的“当前打开”视图，即英文界面中的 Now Open，以及引导教程中的练习分组，都被有意排除在外。）
- **恢复是替换，而且会先询问**。为了让你从干净的状态开始，恢复会先关闭已打开的窗口，再重新打开已保存的窗口。这一步影响较大，所以无论在会话视图还是在侧边栏中，它都会先询问（**关闭所有窗口** 或 **取消**，英文界面中为 Close all windows / Cancel）。
- **你关闭的东西不会被丢掉**。恢复时关闭的窗口会进入 **最近关闭**（Recently closed，默认开启），所以还需要的标签页只需点一下就能找回。
- **每个窗口都会以窗口的形式回来**。已保存的窗口分别重新打开，标签页保持保存时的顺序。从隐私窗口保存的窗口，在扩展获准在隐私窗口中运行时，会重新以隐私窗口打开；否则会以普通窗口打开，TabMerger 也会告诉你原因。
- **先保存在你的浏览器中**。会话首先写入你的浏览器，所以离线也能保存。在 Pro 中，它随后会以端到端加密的方式上传，同步到你的其他设备。

</Section>

<Section id="steps" title="设置方法：保存一次，每天恢复">

1. 把当天要用的标签页放进分组。打开分组的 **⋯** 菜单，选择 **与当前合并**（Merge with current），把已打开的窗口加入该分组。
2. 在侧边栏中，点击 **会话** 旁边的书签按钮（**保存当前会话**）。填写名称、可选的描述并选择颜色，然后点击 **保存**（Save）。
3. 第二天早上，打开 TabMerger，点击 **会话** 下的会话，然后点击 **恢复会话**（Restore session），或者点击该行上的恢复按钮。
4. 点击 **关闭所有窗口** 确认。已保存的窗口会逐个打开，标签页保持原来的顺序。

<Section id="one-group" title="只打开一个分组">

有些早上你只需要一个项目。在侧边栏中右键点击它的分组，选择 **在新窗口中全部打开**：分组中的所有网页会一起在一个新窗口中打开，其他东西都不会被关闭。要打开单个已保存的窗口，使用该窗口 **⋯** 菜单中的 **在浏览器中打开**（Open in browser）；要打开一个标签页，直接点击它即可。

<Section id="benefit" title="你能得到什么">

重建变成一次点击加一次确认。你从计划要用的标签页开始，在自己安排好的窗口里，而不是从昨天残留下来的东西开始。而且恢复只会打开你保存过的内容，杂乱不会再回来。

</Section>

<Section id="habits" title="好习惯">

- **每个日常流程一个会话**：“工作日”“写作”“周一计划”。少而清晰的会话胜过一长串列表。
- **工作环境变化时更新会话**。会话是一份快照：之后对分组的修改不会改变它。保存一个新的，删除旧的。
- **用分组而不是窗口结束一天**。把今天新开的标签页加入各自的分组（参见[每日标签页工作流](/blog/tabmerger-daily-workflow)），然后关闭窗口。
- **切换整天的工作用会话，单个项目用分组**。恢复用于“开始我的一天”；**在新窗口中全部打开** 用于“在已打开的内容旁边打开这个项目”。

</Section>
