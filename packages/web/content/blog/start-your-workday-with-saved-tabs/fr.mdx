<QuickAnswer>

Rangez vos onglets quotidiens dans des groupes [TabMerger](/features), cliquez sur **Enregistrer la session actuelle** (Save current session), le bouton signet à côté de **Sessions** dans la barre latérale, et nommez-la « Journée ». Chaque matin, restaurez-la : TabMerger demande d’abord, ferme les fenêtres ouvertes et rouvre chaque fenêtre enregistrée avec ses onglets dans l’ordre. Besoin d’un seul projet ? Faites un clic droit sur son groupe et choisissez **Tout ouvrir dans une nouvelle fenêtre** (Open all in new window).

</QuickAnswer>

<InstallCta>Toute votre configuration du matin en un clic. Gratuit pour Chrome, Edge et Firefox.</InstallCta>

<Section id="problem" title="Tout reconstruire chaque matin">

La plupart des matins commencent de la même façon. Les mails, l’agenda, le tableau de l’équipe, la pull request que vous relisiez, le document que vous rédigiez. Vous les ouvrez un par un, depuis les favoris, depuis l’historique, de mémoire. Certains jours, le navigateur a plutôt restauré les fenêtres de la veille : vous démarrez avec quarante onglets et en fermez trente-cinq.

Dans les deux cas, les premières minutes de la journée passent à reconstruire un espace de travail que vous aviez déjà. Et la restauration intégrée du navigateur ramène ce qui se trouvait ouvert, pas ce sur quoi vous comptiez travailler.

</Section>

<Section id="why" title="Pourquoi les sessions TabMerger fonctionnent ainsi">

Chaque choix derrière les sessions répond à une partie de ce problème :

- **Une session enregistre vos groupes, pas ce qui se trouve ouvert.** Vos groupes, ce sont les onglets que vous avez choisi de garder, déjà nommés et triés. Une session les fige tous sous un seul nom : en la restaurant, vous retrouvez votre plan, pas le désordre de la veille. (La vue en direct « Ouverts maintenant », « Now Open » en anglais, et les groupes d’entraînement de la visite guidée sont volontairement exclus.)
- **Restaurer remplace, et demande d’abord.** Pour repartir de zéro, une restauration ferme les fenêtres ouvertes avant de rouvrir celles enregistrées. C’est une opération radicale, donc elle demande toujours (**Fermer toutes les fenêtres** ou **Annuler**, en anglais Close all windows / Cancel), depuis la vue de la session comme depuis la barre latérale.
- **Rien de ce que vous fermez n’est perdu.** Les fenêtres fermées par une restauration vont dans **Fermés récemment** (Recently closed, activé par défaut) : un onglet dont vous aviez encore besoin est à un clic.
- **Chaque fenêtre revient en tant que fenêtre.** Les fenêtres enregistrées se rouvrent séparément, avec leurs onglets dans l’ordre enregistré. Une fenêtre enregistrée depuis une fenêtre privée se rouvre en fenêtre privée si l’extension est autorisée en navigation privée ; sinon, elle s’ouvre en fenêtre normale et TabMerger vous explique pourquoi.
- **D’abord enregistrée dans votre navigateur.** Une session est écrite dans votre navigateur avant toute autre chose, donc l’enregistrement fonctionne hors ligne. Avec Pro, elle est ensuite envoyée, chiffrée de bout en bout, pour atteindre vos autres appareils.

</Section>

<Section id="steps" title="La mise en place : enregistrer une fois, restaurer chaque jour">

1. Rangez les onglets du jour dans des groupes. Ouvrez le menu **⋯** d’un groupe et choisissez **Fusionner avec l’actuel** (Merge with current) pour y ajouter vos fenêtres ouvertes.
2. Dans la barre latérale, cliquez sur le bouton signet à côté de **Sessions** (**Enregistrer la session actuelle**). Donnez-lui un nom, une description facultative et une couleur, puis cliquez sur **Enregistrer** (Save).
3. Le lendemain matin, ouvrez TabMerger, cliquez sur la session sous **Sessions** et cliquez sur **Restaurer la session** (Restore session), ou sur le bouton de restauration de sa ligne.
4. Confirmez avec **Fermer toutes les fenêtres**. Vos fenêtres enregistrées s’ouvrent l’une après l’autre, avec leurs onglets dans l’ordre.

<Section id="one-group" title="Ouvrir un seul groupe">

Certains matins, vous n’avez besoin que d’un projet. Faites un clic droit sur son groupe dans la barre latérale et choisissez **Tout ouvrir dans une nouvelle fenêtre** : toutes les pages web du groupe s’ouvrent ensemble dans une nouvelle fenêtre, et rien d’autre n’est fermé. Pour ouvrir une seule fenêtre enregistrée, utilisez **Ouvrir dans le navigateur** (Open in browser) dans le menu **⋯** de cette fenêtre ; pour ouvrir un onglet, cliquez dessus.

<Section id="benefit" title="Ce que vous y gagnez">

La reconstruction se résume à un clic et une confirmation. Vous partez des onglets que vous comptiez utiliser, dans les fenêtres que vous avez organisées, au lieu de ce qui a survécu à la veille. Et comme une restauration ne rouvre que ce que vous avez enregistré, le désordre ne revient pas.

</Section>

<Section id="habits" title="Bonnes habitudes">

- **Une session par routine :** « Journée », « Rédaction », « Planning du lundi ». Quelques sessions claires valent mieux qu’une longue liste.
- **Mettez à jour une session quand votre organisation change.** Une session est un instantané : les modifications ultérieures de vos groupes ne la changent pas. Enregistrez-en une nouvelle et supprimez l’ancienne.
- **Terminez la journée avec vos groupes, pas avec vos fenêtres.** Ajoutez les nouveaux onglets du jour à leurs groupes (voir [une routine quotidienne pour vos onglets](/blog/tabmerger-daily-workflow)), puis fermez les fenêtres.
- **Une session pour changer de journée entière, un groupe pour un projet.** Restaurer, c’est « commencer ma journée » ; **Tout ouvrir dans une nouvelle fenêtre**, c’est « ouvrir ce projet à côté de ce que j’ai déjà ».

</Section>
