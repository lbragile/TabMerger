<QuickAnswer>

여러 창과 프로젝트를 오가며 일한다면 **TabMerger**가 정답입니다. 열린 창을 모두 보여 주고, 한 번에 이름과 색이 있는 그룹으로 저장하며, 검색창 하나로 열린 탭·저장한 탭·최근에 닫은 탭을 찾고, Chrome, Edge, Firefox에서 종단 간 암호화로 동기화합니다. 다른 도구들은 더 좁은 용도에 집중합니다. **OneTab**은 클릭 한 번으로 탭을 목록으로 바꾸고, **Session Buddy**는 비정상 종료 후 로컬 복구를 맡고, **Toby**와 **Workona**는 시각적인 작업 공간을 만들며, **Tab Wrangler**는 쓰지 않는 탭을 대신 닫아 줍니다.

</QuickAnswer>

<Section id="pick" title="나에게 맞는 탭 관리 도구는?">

지금 실제로 겪는 문제에서 출발하세요.

- **“여러 창에서 프로젝트 여러 개를 동시에 진행해요.”** TabMerger는 창마다 이름과 색이 있는 그룹으로 저장하고 서로 섞이지 않게 나눠 둡니다. Toby, Workona, Simple Tab Groups(Firefox)도 프로젝트별로 정리합니다.
- **“브라우저가 비정상 종료되거나 다시 시작되면 탭이 사라져요.”** TabMerger의 자동 저장은 일정에 따라 열린 탭의 사본을 남기고, 최근에 닫은 탭에는 닫은 탭이 남습니다. Session Buddy, Tab Session Manager, Tabs Outliner는 저장된 세션을 중심으로 만들어졌습니다. 이 분야는 [세션 관리자 가이드](/blog/browser-session-manager)에서 설명합니다.
- **“컴퓨터를 두 대 써요.”** TabMerger Pro는 그룹과 세션을 종단 간 암호화로 동기화합니다. OneTab의 Backup & Sync, Toby, Workona, Tab Session Manager도 동기화를 지원합니다.
- **“브라우저가 느린데 탭이 80개나 열려 있어요.”** 창을 TabMerger 그룹에 저장한 다음 그룹 메뉴에서 닫으세요. OneTab은 클릭 한 번으로 목록으로 만들고, Tab Wrangler는 쓰지 않는 탭을 자동으로 닫습니다.

[탭이 너무 많을 때의 정리법](/blog/manage-too-many-tabs)은 어떤 도구와도 함께 쓸 수 있습니다. 개발자와 연구자를 위한 활용법은 [개발자를 위한 탭 관리](/blog/tab-management-for-developers)와 [리서치용 탭 정리](/blog/organize-tabs-for-research)를 참고하세요.

<Section id="why" title="TabMerger를 고르는 이유">

[TabMerger](/features)는 저희가 만든 도구로, 작업 창을 여러 개 동시에 열어 두는 사람을 위해 만들어졌습니다.

- **모든 창을 한눈에.** **현재 열린 탭**에 열린 창과 그 탭이 모두 표시되고, 메뉴 항목 하나로 전부 그룹에 저장할 수 있습니다.
- **이름과 색이 있는 그룹**으로 창을 나눠 관리합니다. 마우스나 키보드로 끌어서 놓기, 메모, 알림, 새 탭을 알아서 분류하는 URL 규칙도 있습니다(규칙 3개 무료, Pro는 무제한).
- **모든 것을 한 번에 검색.** <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>로 열린 탭, 저장한 탭, 최근에 닫은 탭을 검색하고, `group:`, `window:`, `closed:` 같은 필터도 쓸 수 있습니다.
- **잃어버리는 것이 없습니다.** 일정에 따른 자동 저장 또는 탭 수가 기준을 넘을 때의 자동 저장, 최근에 닫은 탭(무료 2일, Pro 30일), 저장된 세션, Pro의 자동 백업.
- **비공개 동기화.** Pro에서는 그룹과 세션이 기기 간에 항상 종단 간 암호화로 동기화됩니다. 서버는 키를 절대 갖지 않습니다.
- **쉽게 옮겨 오기.** OneTab 목록, 북마크 HTML, JSON을 가져오고 JSON으로 내보냅니다.
- **어디서 탐색하든.** Chrome, Edge, Firefox에서 18개 언어와 밝은 테마, 어두운 테마를 지원합니다. 계정 없이 바로 시작할 수 있습니다.

<Section id="tools" title="다른 선택지가 집중하는 것">

**OneTab.** 클릭 한 번으로 창의 모든 탭을 목록으로 바꾸며, 이 목록은 다시 시작하거나 비정상 종료된 뒤에도 남습니다. Chrome, Firefox, Edge, Safari에서 작동하고, 선택형 유료 기능인 Backup & Sync는 종단 간 암호화됩니다. 제거하면 목록이 삭제되므로 다른 도구로 옮길 때는 먼저 내보내세요. [OneTab 대안 가이드](/blog/onetab-alternatives)도 참고하세요.

**Session Buddy.** Chrome용 비정상 종료 복구 도구입니다. 지난 세션의 타임라인, 15가지 이상 형식의 가져오기와 내보내기를 제공하며 계정이 필요 없습니다. 모든 데이터가 내 기기에 남습니다.

**Toby.** 새 탭 페이지를 컬렉션 보드로 바꾸고, 프로젝트별 스페이스와 팀 플랜을 제공합니다. 무료 플랜에서는 저장 탭을 최대 60개까지 둘 수 있습니다.

**Workona.** 클라우드 앱에서 주로 일하는 사람을 위한 작업 공간입니다. 스페이스, 탭 일시 중지, 자동 저장, Google Drive와 Slack 같은 연동 기능을 계정 중심으로 제공합니다.

**Tab Manager Plus.** 입력해서 모든 창의 모든 탭을 필터링하고, 중복 탭을 강조하고, 창당 탭 수를 제한할 수 있습니다. 해당 브라우저 안에서는 창을 저장할 수도 있습니다.

**Tab Session Manager.** 이름과 태그가 있는 세션, 창을 닫을 때와 타이머에 따른 자동 저장, 탭 그룹, 클라우드 동기화, Session Buddy에서 가져오기를 지원합니다.

**Tabs Outliner.** 열린 창과 저장된 창을 메모를 달 수 있는 하나의 트리로 보여 줍니다. 제한 없이 무료이며, 1회 결제하는 Pro에서는 단축키와 매일 Google Drive 백업이 추가됩니다.

**Simple Tab Groups.** Firefox 전용입니다. 그룹을 전환하면 다른 그룹의 탭이 숨겨지며, Firefox 컨테이너와 JSON 백업을 지원합니다.

**Tab Wrangler.** 한동안 쓰지 않은 탭을 닫고, 다시 열 수 있도록 Tab Corral에 보관합니다.

</Section>
