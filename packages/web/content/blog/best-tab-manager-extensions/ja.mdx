<QuickAnswer>

複数のウィンドウやプロジェクトで作業するなら、選ぶべきは **TabMerger** です。開いているすべてのウィンドウを一覧表示し、名前と色の付いたグループにワンステップで保存し、開いているタブ・保存したタブ・最近閉じたタブを 1 つの検索ボックスから探せて、Chrome・Edge・Firefox でエンドツーエンド暗号化された同期ができます。ほかのツールはもっと限られた用途に特化しています。**OneTab** はワンクリックでタブをリストに変え、**Session Buddy** はクラッシュ時のローカル復元を担い、**Toby** と **Workona** は視覚的なワークスペースを作り、**Tab Wrangler** は使っていないタブを自動で閉じてくれます。

</QuickAnswer>

<Section id="pick" title="あなたに合うタブ管理ツールは？">

実際に困っていることから考えましょう。

- **「複数のウィンドウで、いくつものプロジェクトをかけ持ちしている」** TabMerger はウィンドウごとに名前と色の付いたグループへ保存し、混ざらないように分けておけます。Toby、Workona、Simple Tab Groups（Firefox）もプロジェクト単位で整理できます。
- **「ブラウザがクラッシュしたり再起動したりすると、タブがなくなる」** TabMerger の自動保存はスケジュールに沿って開いているタブのコピーを残し、最近閉じたタブには閉じたものが残ります。Session Buddy、Tab Session Manager、Tabs Outliner は保存したセッションを中心に作られています。このジャンルについては[セッションマネージャーのガイド](/blog/browser-session-manager)で解説しています。
- **「2 台のパソコンを使っている」** TabMerger Pro はグループとセッションをエンドツーエンドで暗号化して同期します。OneTab の Backup & Sync、Toby、Workona、Tab Session Manager も同期に対応しています。
- **「ブラウザが重く、タブが 80 個もある」** ウィンドウを TabMerger のグループに保存し、グループのメニューから閉じましょう。OneTab ならワンクリックでリストにまとめられ、Tab Wrangler は使っていないタブを自動で閉じます。

[タブが多すぎるときの整理術](/blog/manage-too-many-tabs)はどのツールとも組み合わせられます。開発者や研究者向けの使い方は、[開発者のためのタブ管理](/blog/tab-management-for-developers)と[リサーチのためのタブ整理](/blog/organize-tabs-for-research)をご覧ください。

</Section>

<Section id="why" title="TabMerger を選ぶ理由">

[TabMerger](/features) は私たちが作っている拡張機能で、作業用のウィンドウをいくつも同時に開いている人のために作られています。

- **すべてのウィンドウがひと目でわかる**。**現在開いているタブ** に、開いているすべてのウィンドウとそのタブが一覧表示され、メニュー項目 1 つでまとめてグループに保存できます。
- **名前と色の付いたグループ** でウィンドウを分けて管理。マウスでもキーボードでもドラッグ＆ドロップでき、メモ、リマインダー、新しいタブを自動で振り分ける URL ルールも使えます（ルールは無料で 3 個、Pro なら無制限）。
- **すべてを 1 つの検索で**。<Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> で、開いているタブ、保存したタブ、最近閉じたタブを検索でき、`group:`、`window:`、`closed:` などのフィルターも使えます。
- **何も失わない**。スケジュールに沿った自動保存や、タブ数がしきい値を超えたときの自動保存、最近閉じたタブ（無料で 2 日、Pro で 30 日）、保存したセッション、Pro での自動バックアップ。
- **プライベートな同期**。Pro では、グループとセッションが常にエンドツーエンドで暗号化されてデバイス間で同期されます。サーバーが鍵を持つことはありません。
- **乗り換えも簡単**。OneTab のリスト、ブックマーク HTML、JSON をインポートでき、JSON でエクスポートできます。
- **どこで閲覧しても**。Chrome・Edge・Firefox に対応し、18 言語、ライトとダークのテーマを用意。アカウントなしで使い始められます。

<Section id="tools" title="ほかの選択肢が得意なこと">

**OneTab**。ワンクリックでウィンドウ内のすべてのタブがリストになり、そのリストは再起動やクラッシュのあとも残ります。Chrome、Firefox、Edge、Safari で動作し、オプションの有料機能 Backup & Sync はエンドツーエンドで暗号化されます。アンインストールするとリストが削除されるので、乗り換えるときは先にエクスポートしておきましょう。詳しくは [OneTab の代替ツールのガイド](/blog/onetab-alternatives)をご覧ください。

**Session Buddy**。Chrome 向けのクラッシュ復元ツールです。過去のセッションのタイムライン、15 種類以上の形式でのインポートとエクスポートを備え、アカウントは不要。すべてがお使いのデバイス内に残ります。

**Toby**。新しいタブのページを、コレクションを並べたボードに変えます。プロジェクトごとのスペースやチーム向けプランがあり、無料プランでは保存タブを 60 個まで持てます。

**Workona**。クラウドアプリ中心で働く人のためのワークスペースです。スペース、タブの一時停止、自動保存、Google Drive や Slack などとの連携があり、アカウントを前提に作られています。

**Tab Manager Plus**。文字を入力して、すべてのウィンドウのすべてのタブを絞り込めるほか、重複タブを強調表示したり、ウィンドウごとのタブ数を制限したりできます。そのブラウザ内でなら、ウィンドウの保存もできます。

**Tab Session Manager**。名前やタグ付きのセッション、ウィンドウを閉じたときとタイマーでの自動保存、タブグループ、クラウド同期、Session Buddy からのインポートに対応しています。

**Tabs Outliner**。開いているウィンドウと保存したウィンドウを 1 つのツリーで表示し、メモを書き込めます。無料で制限なく使え、買い切りの Pro ではショートカットと Google Drive への毎日のバックアップが加わります。

**Simple Tab Groups**。Firefox 専用です。グループを切り替えると、ほかのグループのタブは非表示になります。Firefox のコンテナーに対応し、JSON でバックアップできます。

**Tab Wrangler**。しばらく使っていないタブを閉じ、あとで開き直せるよう Tab Corral に残しておきます。

</Section>
