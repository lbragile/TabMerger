<QuickAnswer>

在 [TabMerger](/features) 中打开**设置 → 通用 → 网址规则 → 管理**（Settings → General → URL rules → Manage），然后添加一条规则：一个地址模式（例如 `github.com/your-org/*`）以及它所属的分组。从此，你浏览时每个匹配的页面都会保存到该分组，标签页仍然打开。`*` 匹配任何内容；第一条匹配的规则生效。

</QuickAnswer>

<InstallCta>标签页自己归入正确的分组。Chrome、Edge 和 Firefox 均可免费使用。</InstallCta>

<Section id="problem" title="手动归类标签页坚持不了多久">

一周开始时一切井井有条：工作放一个分组，旅行放另一个，阅读放第三个。然后忙碌的一天开始了。同事发来一个 issue 链接，你查了两趟火车的时间，一次搜索找到一篇文章。每一个都该放到某处，可每一个都要拖一下，而你不会去拖。到了周五，分组已经过时，当前打开（Now Open）又堆成了一堆。

你最常打开的页面来自那么几个网站。这正是规则能够识别的。

</Section>

<Section id="why" title="网址规则为何这样设计">

- **复制而不是移动**。规则把页面的副本保存到分组，标签页保持打开。归类永远不会打断你正在读的内容。
- **在你浏览时留意**。标签页带着地址打开时，以及每次页面加载完成时，都会检查规则，所以你在标签页里点开的链接也会被归类。副本进入分组的第一个窗口。再次加载的页面（刷新或之后再访问）会被再次保存；分组 **⋯** 菜单中的**去除重复标签页**（Deduplicate tabs）可以清除重复项。
- **完整地址，不含协议**。模式与 `http://` 或 `https://` 之后的完整地址比较，所以你无需输入这部分，`localhost:3000/*` 照写就能用。
- **有意只用一个通配符**。`*` 表示任意一串字符，也可以为空。没有其他需要转义的特殊字符。模式按纯文本匹配，从不转换成正则表达式，所以再长的模式也能快速检查。
- **顺序决定结果**。两条规则都匹配时，靠上的那条生效，所以具体的规则可以放在笼统的规则上面。

</Section>

<Section id="steps" title="添加规则">

1. 打开 TabMerger，进入**设置** → **通用**（Settings → General）。在**网址规则**旁边，点击**管理**（Manage）。
2. 点击**添加规则**（Add rule）。输入模式，选择目标分组，然后点击对话框中的**添加规则**。
3. 为每个想要归类的网站重复以上操作，最后点击**保存**（Save）保存列表。

能帮你省下一轮调试的技巧：

- **以 `/*` 结尾**，即可覆盖整个网站。没有 `*` 时，模式只匹配一个确切的地址。
- **以 `*` 开头**，适用于使用子域名或 `www.` 的网站：`*example.com/*`。
- **字母必须照原样匹配**。浏览器用小写字母书写域名，所以你也这样写。
- **查询字符串也算在内**。`*youtube.com/watch*` 匹配视频，不管 `watch` 后面是什么。

</Section>

<Section id="order" title="规则顺序：具体的在前">

规则从上往下尝试。用每条规则旁边的箭头，把范围窄的规则（`github.com/your-org/design-system/*` → “Design system”）放在范围宽的规则（`github.com/your-org/*` → “Work”）上面。第一条匹配的规则负责归类页面，其余的会被跳过。

</Section>

<Section id="benefit" title="你能得到什么">

无需你动手归类，分组也始终保持最新。周二打开的页面，到周五已经在它所属项目的分组里了，在该分组中搜索就能找到。

</Section>

<Section id="habits" title="好习惯">

- **为每天打开的网站设置规则**，而不是每个只访问一次的网站。
- **每个项目域名或路径一条规则**，具体的规则放前面。
- **把规则与按项目划分的分组搭配使用**：参见[按项目整理标签页](/blog/organize-tabs-by-project)。开发者可以在[面向开发者的标签页管理](/blog/tab-management-for-developers)中找到更多模式。
- **时不时整理一下**，在规则经常填充的分组上使用**去除重复标签页**。

</Section>
