<QuickAnswer>

No [TabMerger](/features), abra **Configurações → Geral → Regras de URL → Gerenciar** (Settings → General → URL rules → Manage) e adicione uma regra: um padrão de endereço como `github.com/your-org/*` e o grupo a que ele pertence. A partir daí, toda página correspondente é salva nesse grupo enquanto você navega, e a aba continua aberta. `*` corresponde a qualquer coisa; vence a primeira regra que corresponde.

</QuickAnswer>

<InstallCta>Abas que se arquivam sozinhas no grupo certo. Grátis para Chrome, Edge e Firefox.</InstallCta>

<Section id="problem" title="Arquivar abas à mão não dura">

Você começa a semana organizado: o trabalho em um grupo, a viagem em outro, as leituras em um terceiro. Aí o dia acontece. Um colega manda o link de uma issue, você pesquisa dois horários de trem, uma busca traz um artigo. Cada um deveria ir para algum lugar, e cada um é um arrastar que você não vai fazer. Na sexta, os grupos estão desatualizados e Abertas agora (Now Open) virou uma pilha de novo.

As páginas que você mais abre vêm dos mesmos poucos sites. É exatamente isso que uma regra consegue reconhecer.

</Section>

<Section id="why" title="Por que as regras de URL funcionam assim">

- **Copiar, não mover.** Uma regra salva uma cópia da página no grupo e deixa a aba aberta. Arquivar nunca interrompe o que você está lendo.
- **Observa enquanto você navega.** Uma regra é verificada quando uma aba abre com um endereço e sempre que uma página termina de carregar, então um link que você segue dentro de uma aba também é arquivado. A cópia vai para a primeira janela do grupo. Uma página que carrega de novo (ao recarregar, numa visita posterior) é salva de novo; **Remover abas duplicadas** (Deduplicate tabs), no menu **⋯** do grupo, limpa as repetições.
- **O endereço inteiro, sem esquema.** Um padrão é comparado com todo o endereço depois de `http://` ou `https://`, então você nunca digita essa parte, e `localhost:3000/*` funciona do jeito que está escrito.
- **Um só curinga, de propósito.** `*` significa qualquer sequência de caracteres, inclusive nenhuma. Não há outros caracteres especiais para escapar. Os padrões são comparados como texto simples, nunca transformados em expressão regular, então até os longos são verificados rapidamente.
- **A ordem decide.** Quando duas regras correspondem, vence a de cima, então uma regra específica pode ficar acima de uma geral.

</Section>

<Section id="steps" title="Adicionar uma regra">

1. Abra o TabMerger e depois **Configurações** → **Geral** (Settings → General). Ao lado de **Regras de URL**, clique em **Gerenciar** (Manage).
2. Clique em **Adicionar regra** (Add rule). Digite o padrão, escolha o grupo de destino e clique em **Adicionar regra** na caixa de diálogo.
3. Repita para cada site que você quer arquivar e depois clique em **Salvar** (Save) para manter a lista.

Dicas que poupam uma sessão de depuração:

- **Termine com `/*`** para cobrir um site inteiro. Sem `*`, um padrão corresponde a um único endereço exato.
- **Comece com `*`** quando um site usa subdomínios ou `www.`: `*example.com/*`.
- **As letras precisam corresponder como estão escritas.** Os navegadores escrevem nomes de domínio em minúsculas, então escreva assim também.
- **Parâmetros de consulta contam.** `*youtube.com/watch*` corresponde a vídeos, seja o que for que venha depois de `watch`.

</Section>

<Section id="order" title="Ordem das regras: as específicas primeiro">

As regras são testadas a partir do topo. Coloque a regra estreita (`github.com/your-org/design-system/*` → “Design system”) acima da ampla (`github.com/your-org/*` → “Work”) usando as setas ao lado de cada regra. A primeira regra que corresponde arquiva a página, e as demais são ignoradas.

</Section>

<Section id="benefit" title="O que você ganha">

Seus grupos ficam em dia sem nenhum arquivamento da sua parte. Uma página que você abriu na terça já está no grupo do projeto dela na sexta, e uma busca nesse grupo a encontra.

</Section>

<Section id="habits" title="Bons hábitos">

- **Crie regras para os sites que você abre todo dia,** não para cada site que visita uma vez.
- **Uma regra por domínio ou caminho de projeto**, as específicas primeiro.
- **Combine regras com um grupo por projeto:** veja [organizar abas por projeto](/blog/organize-tabs-by-project). Quem programa encontra mais padrões em [gerenciamento de abas para desenvolvedores](/blog/tab-management-for-developers).
- **Faça uma limpeza de vez em quando** com **Remover abas duplicadas** nos grupos que as regras enchem com frequência.

</Section>
