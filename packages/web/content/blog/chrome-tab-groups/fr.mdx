<QuickAnswer>

Effectuez un clic droit sur un onglet et choisissez **Ajouter l’onglet à un groupe** (« Add tab to group ») pour créer un groupe, puis donnez-lui un nom et une couleur. Pour enregistrer un groupe, effectuez un clic droit sur son nom et choisissez **Fermer le groupe** (« Close group ») : Chrome le conserve, et vous le rouvrez depuis la barre de favoris ou via **⋮ → Groupes d’onglets** (« Tab groups »). Les groupes enregistrés suivent votre compte Google : en supprimer un le supprime partout. Pour garder vos groupes en lieu sûr pour de bon, enregistrez-les dans [TabMerger](/features) : il conserve le nom et la couleur du groupe Chrome de chaque onglet, et remet les onglets dans leurs groupes quand vous les rouvrez.

</QuickAnswer>

<Section id="basics" title="Comment fonctionnent les groupes d’onglets Chrome ?">

Un groupe d’onglets est une série d’onglets avec un nom et une couleur, dans une seule fenêtre.

1. Effectuez un clic droit sur un onglet et choisissez **Ajouter l’onglet à un groupe** → **Nouveau groupe** (« New group ») ou un groupe existant.
2. Nommez le groupe et choisissez une couleur. Plus tard, un clic droit sur le nom permet de le renommer, d’en changer la couleur ou d’y ajouter un nouvel onglet.
3. Faites glisser un onglet dans le groupe pour l’y ajouter ; clic droit sur un onglet → **Retirer du groupe** (« Remove from group ») pour l’en sortir.
4. Cliquez sur le nom du groupe pour le réduire à une simple étiquette, et cliquez de nouveau pour le développer.

Au clavier : appuyez sur <Kbd>F6</Kbd> jusqu’à ce que les onglets aient le focus, allez jusqu’au groupe avec <Kbd>Tab</Kbd>, puis la touche Menu ouvre le menu du groupe. <Kbd>Space</Kbd> ou <Kbd>Enter</Kbd> le réduit, et <Kbd>Ctrl</Kbd>+<Kbd>←</Kbd>/<Kbd>→</Kbd> le déplace.

<Section id="save" title="Comment enregistrer un groupe d’onglets et le retrouver ?">

**Fermer le groupe** est le bouton d’enregistrement de Chrome. Les onglets se ferment, pas le groupe : Chrome le conserve et le liste à deux endroits.

- **Barre de favoris :** une icône en grille avec le nom du groupe. Cliquez dessus pour le rouvrir.
- **Menu ⋮ → Groupes d’onglets :** vos groupes enregistrés.

Deux paramètres, dans **Paramètres → Apparence** (« Settings → Appearance »), gèrent la partie barre de favoris. Les deux étaient activés dans un profil Chrome 157 tout neuf.

<Section id="sync" title="Les groupes d’onglets se synchronisent-ils entre appareils ?">

Oui, via votre compte Google. L’aide de Chrome est claire sur l’effet secondaire : quand vous **supprimez** un groupe, ou que vous dégroupez ses onglets (**Dégrouper**, « Ungroup »), le groupe est retiré de votre appareil *et* de tous les autres appareils connectés au même compte. Le paramètre **Épingler automatiquement les nouveaux groupes d’onglets à la barre de favoris** (« Automatically pin new tab groups created on any device to the bookmarks bar ») épingle aussi les groupes créés ailleurs.

Concrètement :

- Les groupes créés sur un ordinateur peuvent apparaître sur un autre connecté au même compte ; c’est à cela que fait référence le paramètre d’épinglage.
- Faire du tri sur votre portable supprime les mêmes groupes sur votre ordinateur de bureau.

Firefox 159 a lui aussi des groupes d’onglets, avec **Enregistrer et fermer le groupe** (« Save and close group ») et une liste **Groupes fermés** (« Closed Groups ») ; les étapes et les captures de ce guide sont celles de Chrome. Sur Firefox, consultez [Groupes d’onglets dans Firefox](/blog/firefox-tab-groups).

</Section>

<Section id="limits" title="Où les groupes d’onglets montrent-ils leurs limites ?">

- **Une fenêtre chacun.** Un groupe vit dans une seule fenêtre. Enregistrer « tout ce que j’ai d’ouvert » sur trois fenêtres, c’est trois groupes ou plus.
- **Des adresses seulement.** Comme un favori, un groupe enregistré recharge la page à zéro : la position de défilement et la saisie des formulaires sont perdues.
- **Invisibles pour les extensions une fois fermés.** L’API `chrome.tabGroups` décrit les groupes présents dans une fenêtre ouverte : chaque groupe qu’elle renvoie a un `windowId`, fermer un groupe déclenche `onRemoved`, et aucun appel ne liste les groupes enregistrés et fermés. Un gestionnaire d’onglets ne peut pas sauvegarder un groupe que vous avez fermé tant que vous ne l’avez pas rouvert.
- **Les suppressions voyagent.** La synchronisation qui rend les groupes si pratiques propage aussi une erreur sur tous vos appareils.

Notre guide pour [enregistrer tous les onglets ouverts](/blog/save-all-open-tabs) compare les groupes aux favoris, à la restauration au démarrage et aux gestionnaires de sessions, et la [routine contre les onglets trop nombreux](/blog/manage-too-many-tabs) montre la place des groupes au quotidien.

</Section>
