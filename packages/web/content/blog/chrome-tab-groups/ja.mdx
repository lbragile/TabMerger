<QuickAnswer>

グループを作るには、タブを右クリックして「**タブをグループに追加**」（Add tab to group）を選び、名前と色を決めます。グループを保存するには、グループ名を右クリックして「**グループを閉じる**」（Close group）を選びます。グループは Chrome に残り、ブックマーク バーか **⋮ →「タブグループ」**（Tab groups）から開き直せます。保存したグループは Google アカウントに紐づくため、1 か所で削除するとすべてのデバイスから消えます。グループをずっと安全に残したいなら [TabMerger](/features) に保存しましょう。各タブの Chrome グループの名前と色を記録し、開き直すとタブをグループに戻します。

</QuickAnswer>

<InstallCta>Chrome のタブグループを安全に、検索できる形で、同期して残せます。Chrome、Edge、Firefox に無料で追加できます。</InstallCta>

<Section id="basics" title="Chrome のタブグループの仕組み">

タブグループは、1 つのウィンドウの中で名前と色が付いたタブのまとまりです。

1. タブを右クリックして「**タブをグループに追加**」→「**新しいグループ**」（New group）または既存のグループを選びます。
2. グループに名前を付け、色を選びます。あとから名前を右クリックすれば、名前の変更、色の変更、新しいタブの追加ができます。
3. タブをグループにドラッグすると追加できます。外すときは、タブを右クリック →「**グループから削除**」（Remove from group）を選びます。
4. グループ名をクリックするとラベル 1 つに折りたたまれ、もう一度クリックすると展開されます。

キーボードの場合：タブにフォーカスが移るまで <Kbd>F6</Kbd> を押し、<Kbd>Tab</Kbd> でグループに移動すると、メニューキーでグループのメニューが開きます。<Kbd>Space</Kbd> か <Kbd>Enter</Kbd> で折りたたみ、<Kbd>Ctrl</Kbd>+<Kbd>←</Kbd>/<Kbd>→</Kbd> で移動できます。

<Section id="save" title="タブグループを保存して元に戻すには">

「**グループを閉じる**」が Chrome の保存ボタンです。タブは閉じますが、グループは閉じません。Chrome はグループを残し、2 か所に表示します。

- **ブックマーク バー：** グループ名の付いたグリッドアイコン。クリックすると開き直せます。
- **⋮ メニュー →「タブグループ」：** 保存したグループの一覧。

ブックマーク バーへの表示は、**設定 →「デザイン」**（Settings → Appearance）にある 2 つの設定で決まります。新しい Chrome 157 のプロファイルでは、どちらもオンでした。

<Section id="sync" title="タブグループはデバイス間で同期されるか">

はい、Google アカウントを通じて同期されます。Chrome ヘルプは副作用をはっきり書いています。グループを**削除**したり、タブの**グループを解除**（Ungroup）したりすると、そのグループはお使いのデバイス*だけでなく*、同じアカウントでログインしている他のすべてのデバイスからも消えます。また「**新しいタブグループをブックマーク バーに自動的に固定する**」（Automatically pin new tab groups created on any device to the bookmarks bar）の設定は、別のデバイスで作ったグループも固定します。

実際には、次のようなことが起こります。

- あるパソコンで作ったグループが、同じアカウントでログインしている別のパソコンに現れることがあります。固定の設定が指しているのはこのことです。
- ノートパソコンで整理すると、デスクトップの同じグループも消えます。

Firefox 159 にもタブグループがあり、「**グループを保存して閉じる**」（Save and close group）と「**閉じたグループ**」（Closed Groups）の一覧があります。このガイドの手順とスクリーンショットは Chrome のものです。Firefox をお使いなら [Firefox のタブグループ](/blog/firefox-tab-groups)をご覧ください。

</Section>

<Section id="limits" title="タブグループの弱点">

- **1 グループにつき 1 ウィンドウ。** グループは 1 つのウィンドウの中にしか存在しません。3 つのウィンドウにまたがる「開いているものすべて」を保存するには、3 つ以上のグループが必要です。
- **保存されるのはアドレスだけ。** ブックマークと同じく、保存したグループはページを最初から読み込み直します。スクロール位置やフォームへの入力は失われます。
- **閉じている間は拡張機能から見えない。** `chrome.tabGroups` API が扱うのは、開いているウィンドウにあるグループです。返されるグループにはどれも `windowId` があり、グループを閉じると `onRemoved` が発生し、保存済みの閉じたグループを一覧にする呼び出しはありません。閉じたグループは、開き直すまでタブ管理ツールでバックアップできません。
- **削除も同期される。** グループを便利にしている同期が、誤操作もすべてのデバイスに広げます。

[開いているタブをすべて保存する](/blog/save-all-open-tabs)ガイドでは、グループをブックマーク、起動時の復元、セッション管理ツールと比較しています。[タブが多すぎるときの習慣](/blog/manage-too-many-tabs)では、日々の作業の中でグループをどう使うかを紹介しています。

</Section>

<Section id="tabmerger" title="TabMerger でグループをずっと残す">

Chrome、Edge、Firefox に対応した無料の拡張機能 [TabMerger](/features) は、開いている Chrome のタブグループを読み取ります。「**現在開いているタブ**」では各タブにグループの名前と色のタグが付き、ウィンドウを TabMerger のグループに保存してもそのタグは残ります。ここに保存しておけば、別のデバイスで Chrome のグループが削除されてもタブは影響を受けません。
