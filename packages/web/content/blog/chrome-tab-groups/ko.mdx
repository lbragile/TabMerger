<QuickAnswer>

탭을 마우스 오른쪽 버튼으로 클릭하고 **그룹에 탭 추가**(Add tab to group)를 선택해 그룹을 만든 다음, 이름을 붙이고 색을 고르세요. 그룹을 저장하려면 그룹 이름을 마우스 오른쪽 버튼으로 클릭하고 **그룹 닫기**(Close group)를 선택합니다. Chrome이 그룹을 보관하며, 북마크바나 **⋮ → 탭 그룹**(Tab groups)에서 다시 열 수 있습니다. 저장된 그룹은 Google 계정을 따라가므로, 하나를 삭제하면 모든 곳에서 삭제됩니다. 그룹을 오래도록 안전하게 보관하려면 [TabMerger](/features)에 저장하세요. 각 탭의 Chrome 그룹 이름과 색을 기억해 두었다가, 다시 열 때 탭을 그룹으로 되돌려 줍니다.

</QuickAnswer>

<Section id="basics" title="Chrome 탭 그룹은 어떻게 작동하나요?">

탭 그룹은 한 창 안에서 이름과 색이 붙은 탭 묶음입니다.

1. 탭을 마우스 오른쪽 버튼으로 클릭하고 **그룹에 탭 추가** → **새 그룹**(New group) 또는 기존 그룹을 선택합니다.
2. 그룹 이름을 정하고 색을 고릅니다. 나중에 이름을 마우스 오른쪽 버튼으로 클릭하면 이름이나 색을 바꾸거나 새 탭을 추가할 수 있습니다.
3. 탭을 그룹 안으로 드래그하면 추가되고, 탭을 마우스 오른쪽 버튼으로 클릭 → **그룹에서 삭제**(Remove from group)를 선택하면 빠집니다.
4. 그룹 이름을 클릭하면 라벨 하나로 접히고, 다시 클릭하면 펼쳐집니다.

키보드로 하려면: 탭에 포커스가 갈 때까지 <Kbd>F6</Kbd>를 누르고, <Kbd>Tab</Kbd>으로 그룹까지 이동한 다음 메뉴 키를 누르면 그룹 메뉴가 열립니다. <Kbd>Space</Kbd> 또는 <Kbd>Enter</Kbd>로 그룹을 접고, <Kbd>Ctrl</Kbd>+<Kbd>←</Kbd>/<Kbd>→</Kbd>로 그룹을 옮깁니다.

<Section id="save" title="탭 그룹을 저장하고 다시 불러오려면?">

**그룹 닫기**가 Chrome의 저장 버튼입니다. 탭은 닫히지만 그룹은 닫히지 않습니다. Chrome이 그룹을 보관하고 두 곳에 표시합니다.

- **북마크바:** 그룹 이름이 붙은 그리드 아이콘입니다. 클릭하면 다시 열립니다.
- **⋮ 메뉴 → 탭 그룹:** 저장한 그룹 목록입니다.

북마크바 쪽은 **설정 → 모양**(Settings → Appearance)에 있는 두 가지 설정이 담당합니다. 새 Chrome 157 프로필에서는 둘 다 켜져 있었습니다.

<Section id="sync" title="탭 그룹은 기기 간에 동기화되나요?">

네, Google 계정을 통해 동기화됩니다. Chrome 고객센터는 부작용을 분명히 밝힙니다. 그룹을 **삭제**하거나 **그룹 해제**(Ungroup)로 탭의 그룹을 풀면, 그 그룹은 내 기기*와* 같은 계정으로 로그인한 다른 모든 기기에서 삭제됩니다. **새 탭 그룹을 북마크바에 자동으로 고정**(Automatically pin new tab groups created on any device to the bookmarks bar) 설정은 다른 곳에서 만든 그룹도 고정합니다.

실제로는 이런 뜻입니다.

- 한 컴퓨터에서 만든 그룹이 같은 계정으로 로그인한 다른 컴퓨터에 나타날 수 있습니다. 고정 설정이 말하는 것이 바로 이것입니다.
- 노트북에서 정리하면 데스크톱의 같은 그룹도 삭제됩니다.

Firefox 159에도 탭 그룹이 있으며, **그룹 저장 후 닫기**(Save and close group)와 **닫힌 그룹**(Closed Groups) 목록을 제공합니다. 이 가이드의 단계와 스크린샷은 Chrome 기준입니다. Firefox를 쓴다면 [Firefox 탭 그룹](/blog/firefox-tab-groups)을 참고하세요.

</Section>

<Section id="limits" title="탭 그룹의 한계는 무엇인가요?">

- **그룹마다 창 하나.** 그룹은 한 창 안에만 있습니다. 창 세 개에 걸친 “열려 있는 모든 것”을 저장하려면 그룹이 세 개 이상 필요합니다.
- **주소만 저장.** 북마크처럼, 저장된 그룹은 페이지를 처음부터 다시 엽니다. 스크롤 위치와 양식에 입력한 내용은 사라집니다.
- **닫혀 있으면 확장 프로그램에 보이지 않음.** `chrome.tabGroups` API는 열린 창에 있는 그룹을 다룹니다. 반환되는 모든 그룹에는 `windowId`가 있고, 그룹을 닫으면 `onRemoved`가 발생하며, 저장된 닫힌 그룹을 나열하는 호출은 없습니다. 탭 관리 도구는 닫은 그룹을 다시 열기 전까지 백업할 수 없습니다.
- **삭제도 퍼짐.** 그룹을 편리하게 해 주는 동기화가 실수까지 모든 기기로 퍼뜨립니다.

[열린 탭을 모두 저장하는 방법](/blog/save-all-open-tabs) 가이드에서는 그룹을 북마크, 시작 시 복원, 세션 관리자와 비교하고, [탭이 너무 많을 때의 정리 루틴](/blog/manage-too-many-tabs)에서는 일상에서 그룹을 어디에 활용하면 좋은지 보여 줍니다.

</Section>

<Section id="tabmerger" title="TabMerger로 그룹을 오래 보관하기">

Chrome, Edge, Firefox용 무료 확장 프로그램 [TabMerger](/features)는 열려 있는 Chrome 탭 그룹을 읽어 옵니다. **현재 열린 탭**은 각 탭에 그룹 이름과 색으로 태그를 붙이며, 창을 TabMerger 그룹에 저장해도 이 태그가 유지됩니다. 여기에 저장해 두면 다른 기기에서 Chrome 그룹이 삭제되어도 탭은 그대로입니다.
