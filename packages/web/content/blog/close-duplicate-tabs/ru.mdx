<QuickAnswer>

В [TabMerger](/features) откройте меню **⋯** раздела **Сейчас открыто** и выберите **Удалить дубликаты вкладок**. Расширение находит каждую страницу, открытую больше одного раза, **во всех ваших окнах**, показывает, сколько вкладок закроет, и оставляет первую копию каждой. В Firefox есть встроенный пункт **Закрыть дублирующиеся вкладки** (Close Duplicate Tabs) в меню вкладки; справка Chrome не описывает никакого средства для удаления дубликатов.

</QuickAnswer>

<InstallCta>Уберите дубликаты вкладок из всех окон одним кликом. Бесплатно для Chrome, Edge и Firefox.</InstallCta>

<Section id="tabmerger" title="Как закрыть все дубликаты сразу?">

1. Откройте TabMerger. В разделе **Сейчас открыто** видны все открытые окна и вкладки.
2. Откройте его меню **⋯** и выберите **Удалить дубликаты вкладок**.
3. Проверьте число и нажмите кнопку удаления, здесь **Удалить 3 дубликата**. Лишние вкладки браузера закрываются; первая копия каждой страницы остаётся ровно там, где была.

<Section id="what-counts" title="Что считается дубликатом?">

TabMerger сравнивает **полный адрес** в стандартной форме, без учёта регистра букв:

<ComparisonTable
  head={['Эти две вкладки', 'Дубликаты?']}
  rows={[
    [<code>example.com/page</code>, 'Одна страница дважды: да, одна закрывается'],
    [<code>example.com/Page</code>, 'Отличается только регистр: да'],
    [<code>example.com/page#faq</code>, 'Другой якорь: нет, остаются обе'],
    [<code>example.com/page?ref=mail</code>, 'Другие параметры: нет, остаются обе'],
  ]}
/>

Так и задумано: две вкладки с разными разделами длинного документа или два поиска — для вас разные вкладки, поэтому они остаются. Уходят только настоящие повторы.

<Section id="builtin" title="Может ли браузер сам закрыть дубликаты?">

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

Справка Chrome не описывает средства для удаления дубликатов вкладок. Ближе всего **Поиск по вкладкам** (Tab Search, <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd>): введите название сайта, найдите повторы в списке и закройте их по одному кнопкой закрытия в каждой строке.

</BrowserPanel>
<BrowserPanel browser="edge">

В меню вкладки Edge есть **Duplicate tab**, который открывает ещё одну копию, то есть делает обратное тому, что нужно. Повторы придётся искать вручную и закрывать по одному, проходя вдоль панели вкладок.

</BrowserPanel>
<BrowserPanel browser="firefox">

Щёлкните любую вкладку правой кнопкой мыши и выберите **Закрыть дублирующиеся вкладки** (Close Duplicate Tabs), чтобы закрыть повторы, или **Закрыть дубликаты этой вкладки** (Close Duplicates of This Tab) — только для одной страницы.

</BrowserPanel>
</BrowserPanels>

</Section>

<Section id="prevent" title="Как с самого начала получать меньше дубликатов?">

- **Сначала ищите, потом открывайте.** <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> в TabMerger показывает, открыта ли страница уже или сохранена. Подробнее — в статье о том, [как найти вкладку среди сотен](/blog/find-a-tab-among-hundreds).
- **Объединяйте окна аккуратно.** Именно при объединении окон повторы сходятся вместе; удаляйте дубликаты сразу после [объединения окон](/blog/merge-browser-windows).
- **Сохраните, потом закройте.** Меньше открытых вкладок — меньше копий. Наш [порядок действий при слишком большом числе вкладок](/blog/manage-too-many-tabs) превращает это в привычку.

<InstallCta>Бесплатно для Chrome, Edge и Firefox. Для начала аккаунт не нужен.</InstallCta>
