<QuickAnswer>

在 [TabMerger](/features) 中，打开 **当前打开** 的 **⋯** 菜单，选择 **去除重复标签页**。它会 **在你的所有窗口中** 找出每个打开了不止一次的页面，显示将要关闭多少个标签页，并保留每个页面的第一份。Firefox 的标签页菜单里自带 **关闭重复标签页**（Close Duplicate Tabs）；Chrome 的帮助页面没有介绍任何去除重复项的功能。

</QuickAnswer>

<Section id="tabmerger" title="如何一次关闭所有重复项？">

1. 打开 TabMerger。**当前打开** 会列出所有已打开的窗口和标签页。
2. 打开它的 **⋯** 菜单，选择 **去除重复标签页**。
3. 核对数量，然后点击移除按钮，这里是 **移除 3 个重复项**。多余的浏览器标签页会关闭；每个页面的第一份原地保留，位置不变。

<Section id="what-counts" title="什么算重复？">

TabMerger 比较标准形式的 **完整地址**，不区分大小写：

<ComparisonTable
  head={['这两个标签页', '算重复吗？']}
  rows={[
    [<code>example.com/page</code>, '同一页面两次：算，关闭其中一个'],
    [<code>example.com/Page</code>, '只有大小写不同：算'],
    [<code>example.com/page#faq</code>, '锚点不同：不算，两个都保留'],
    [<code>example.com/page?ref=mail</code>, '参数不同：不算，两个都保留'],
  ]}
/>

这是有意为之：停在长文档不同章节的两个标签页，或两次搜索，对你来说是不同的标签页，所以会保留。只有真正的重复项才会被移除。

</Section>

<Section id="builtin" title="浏览器自己能关闭重复项吗？">

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

Chrome 的帮助页面没有介绍任何去除重复标签页的功能。最接近的是 **标签页搜索**（Tab Search，<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd>）：输入网站名称，在列表中找出重复项，再用每一行的关闭按钮逐个关闭。

</BrowserPanel>
<BrowserPanel browser="edge">

Edge 的标签页菜单里有 **Duplicate tab**，它会再打开一个副本，和你想要的正好相反。要找出重复项只能手动操作，沿着标签栏逐个关闭。

</BrowserPanel>
<BrowserPanel browser="firefox">

右键点击任意标签页，选择 **关闭重复标签页**（Close Duplicate Tabs）即可关闭重复项；如果只想处理一个页面，选择 **关闭与此标签页重复项**（Close Duplicates of This Tab）。

</BrowserPanel>
</BrowserPanels>

</Section>

<Section id="prevent" title="怎样从一开始就减少重复？">

- **先搜索，再打开**。在 TabMerger 中按 <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>，就能看到这个页面是否已经打开或已保存。详见[如何在数百个标签页中找到一个](/blog/find-a-tab-among-hundreds)。
- **合并窗口要小心**。合并窗口时最容易出现重复；[合并窗口](/blog/merge-browser-windows)之后马上去除重复项。
- **先保存，再关闭**。打开的标签页越少，副本就越少。我们的[标签页过多时的整理习惯](/blog/manage-too-many-tabs)能帮你养成习惯。
