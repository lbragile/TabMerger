<QuickAnswer>

[TabMerger](/features)에서 **현재 열린 탭**의 **⋯** 메뉴를 열고 **중복 탭 제거**를 선택하세요. 두 번 이상 열린 페이지를 **모든 창에서** 찾아내고, 닫을 탭 수를 보여 준 뒤, 페이지마다 첫 번째 탭을 남깁니다. Firefox의 탭 메뉴에는 **중복 탭 닫기**(Close Duplicate Tabs)가 기본으로 있고, Chrome 고객센터 페이지에는 중복 탭을 제거하는 기능이 나와 있지 않습니다.

</QuickAnswer>

<InstallCta>모든 창의 중복 탭을 클릭 한 번으로 정리하세요. Chrome, Edge, Firefox용 무료 확장 프로그램입니다.</InstallCta>

<Section id="tabmerger" title="모든 중복 탭을 한 번에 닫으려면?">

1. TabMerger를 엽니다. **현재 열린 탭**에 열려 있는 모든 창과 탭이 표시됩니다.
2. 이 섹션의 **⋯** 메뉴를 열고 **중복 탭 제거**를 선택합니다.
3. 개수를 확인하고 제거 버튼을 누릅니다. 여기서는 **중복 3개 제거**입니다. 남는 브라우저 탭이 닫히고, 각 페이지의 첫 번째 탭은 원래 자리에 그대로 남습니다.

<Section id="what-counts" title="무엇이 중복으로 간주되나요?">

TabMerger는 표준 형식의 **전체 주소**를 대소문자 구분 없이 비교합니다.

<ComparisonTable
  head={['이 두 탭', '중복인가요?']}
  rows={[

    [<code>example.com/Page</code>, '대소문자만 다름: 예'],
    [<code>example.com/page#faq</code>, '앵커가 다름: 아니요, 둘 다 남습니다'],
    [<code>example.com/page?ref=mail</code>, '매개변수가 다름: 아니요, 둘 다 남습니다'],
  ]}
/>

의도된 동작입니다. 긴 문서의 서로 다른 섹션을 연 두 탭이나 두 개의 검색 결과는 사용자에게 다른 탭이므로 남겨 둡니다. 진짜 중복만 사라집니다.

</Section>

<Section id="builtin" title="브라우저가 직접 중복 탭을 닫을 수 있나요?">

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

Chrome 고객센터 페이지에는 중복 탭을 제거하는 기능이 나와 있지 않습니다. 가장 가까운 기능은 **탭 검색**(Tab Search, <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd>)입니다. 사이트 이름을 입력하고, 목록에서 중복을 찾아 각 행의 닫기 버튼으로 하나씩 닫으세요.

</BrowserPanel>
<BrowserPanel browser="edge">

Edge의 탭 메뉴에는 **Duplicate tab**이 있지만, 이 기능은 사본을 하나 더 여는 것이라 원하는 것과 정반대입니다. 중복 탭은 탭 표시줄을 따라가며 직접 찾아 하나씩 닫아야 합니다.

</BrowserPanel>
<BrowserPanel browser="firefox">

아무 탭이나 마우스 오른쪽 버튼으로 클릭하고 **중복 탭 닫기**(Close Duplicate Tabs)를 선택하면 중복 탭이 닫힙니다. 한 페이지의 중복만 닫는 항목(Close Duplicates of This Tab)도 한국어 메뉴에서는 같은 이름 **중복 탭 닫기**로 표시됩니다.

</BrowserPanel>
</BrowserPanels>

</Section>

<Section id="prevent" title="처음부터 중복을 줄이려면?">

- **열기 전에 검색하세요.** TabMerger에서 <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>를 누르면 그 페이지가 이미 열려 있거나 저장되어 있는지 알 수 있습니다. 자세한 내용은 [수백 개의 탭 중에서 탭 찾기](/blog/find-a-tab-among-hundreds)를 참고하세요.
- **창은 신중하게 합치세요.** 중복은 창을 합칠 때 만납니다. [창을 합친](/blog/merge-browser-windows) 직후에 중복을 제거하세요.
- **저장한 다음 닫으세요.** 열린 탭이 적을수록 사본도 적어집니다. [탭이 너무 많을 때의 정리 루틴](/blog/manage-too-many-tabs)으로 습관을 만드세요.

<InstallCta>Chrome, Edge, Firefox용 무료 확장 프로그램입니다. 계정 없이 시작할 수 있습니다.</InstallCta>

</Section>
