<QuickAnswer>

Dans [TabMerger](/features), ouvrez le menu **⋯** de **Ouverts maintenant** et choisissez **Dédupliquer les onglets**. L’extension repère chaque page ouverte plus d’une fois, **dans toutes vos fenêtres**, indique combien d’onglets elle va fermer et garde la première copie de chacune. Firefox propose dans son menu des onglets une fonction intégrée, **Fermer les onglets en double** (« Close Duplicate Tabs ») ; les pages d’aide de Chrome ne décrivent aucun outil de suppression des doublons.

</QuickAnswer>

<InstallCta>Supprimez les onglets en double de toutes vos fenêtres en un clic. Gratuit pour Chrome, Edge et Firefox.</InstallCta>

<Section id="tabmerger" title="Comment fermer tous les doublons d’un coup ?">

1. Ouvrez TabMerger. **Ouverts maintenant** affiche toutes les fenêtres et tous les onglets ouverts.
2. Ouvrez son menu **⋯** et choisissez **Dédupliquer les onglets**.
3. Vérifiez le nombre et cliquez sur le bouton de suppression, ici **Supprimer 3 doublons**. Les onglets en trop se ferment dans le navigateur ; la première copie de chaque page reste exactement à sa place.

<Section id="what-counts" title="Qu’est-ce qui compte comme un doublon ?">

TabMerger compare l’**adresse complète** sous sa forme standard, sans tenir compte des majuscules et minuscules :

<ComparisonTable
  head={['Ces deux onglets', 'Doublons ?']}
  rows={[
    [<code>example.com/page</code>, 'Même page deux fois : oui, l’un est fermé'],
    [<code>example.com/Page</code>, 'Seule la casse diffère : oui'],
    [<code>example.com/page#faq</code>, 'Ancre différente : non, les deux restent'],
    [<code>example.com/page?ref=mail</code>, 'Paramètres différents : non, les deux restent'],
  ]}
/>

C’est voulu : deux onglets sur des sections différentes d’un long document, ou deux recherches, sont pour vous des onglets différents, donc ils restent. Seuls les vrais doublons partent.

</Section>

<Section id="builtin" title="Le navigateur peut-il fermer les doublons lui-même ?">

<BrowserPanels section="builtin">
<BrowserPanel browser="chrome">

Les pages d’aide de Chrome ne décrivent aucun outil pour supprimer les onglets en double. Ce qui s’en rapproche le plus est la **Recherche dans les onglets** (« Tab Search », <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>A</Kbd>) : saisissez le nom d’un site, repérez les doublons dans la liste et fermez-les un par un avec le bouton de fermeture de chaque ligne.

</BrowserPanel>
<BrowserPanel browser="edge">

Le menu des onglets d’Edge propose **Duplicate tab**, qui ouvre une copie de plus : l’inverse de ce que vous cherchez. Pour trouver les doublons, il faut le faire à la main, en les fermant un par un le long de la barre d’onglets.

</BrowserPanel>
<BrowserPanel browser="firefox">

Faites un clic droit sur n’importe quel onglet et choisissez **Fermer les onglets en double** (« Close Duplicate Tabs ») pour fermer les doublons, ou **Fermer les doublons de cet onglet** (« Close Duplicates of This Tab ») pour une seule page.

</BrowserPanel>
</BrowserPanels>

</Section>

<Section id="prevent" title="Comment avoir moins de doublons dès le départ ?">

- **Cherchez avant d’ouvrir.** <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd> dans TabMerger montre si la page est déjà ouverte ou enregistrée. Pour en savoir plus : [retrouver un onglet parmi des centaines](/blog/find-a-tab-among-hundreds).
- **Fusionnez les fenêtres avec soin.** C’est en combinant des fenêtres que les doublons se retrouvent ; dédupliquez juste après avoir [fusionné vos fenêtres](/blog/merge-browser-windows).
- **Enregistrez, puis fermez.** Moins d’onglets ouverts, moins de copies. Notre [routine contre l’excès d’onglets](/blog/manage-too-many-tabs) en fait une habitude.
