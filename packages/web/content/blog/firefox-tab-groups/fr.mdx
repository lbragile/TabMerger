<QuickAnswer>

Faites glisser un onglet sur un autre, ou faites un clic droit sur un onglet, pour créer un groupe dans Firefox. Pour le garder pour plus tard, faites un clic droit sur l’étiquette du groupe et choisissez **Enregistrer et fermer le groupe** (« Save and close group ») ; rouvrez-le depuis **Groupes fermés** (« Closed Groups ») ou la liste **Groupes d’onglets** (« Tab groups »). Les paramètres de Firefox Sync n’ont pas d’entrée distincte pour les groupes d’onglets : pour retrouver les mêmes groupes sur chaque appareil, et pouvoir les rechercher avec tout le reste, enregistrez-les dans [TabMerger](/features).

</QuickAnswer>

<Section id="basics" title="Comment fonctionnent les groupes d’onglets dans Firefox ?">

D’après l’interface de Firefox 159 elle-même :

1. **Créer :** faites glisser un onglet sur un autre, ou faites un clic droit sur un onglet et ajoutez-le à un nouveau groupe. Firefox demande un **Nom** (« Name ») et une couleur (bleu, cyan, gris, vert, orange, rose, violet, rouge ou jaune).
2. **Réduire :** cliquez sur l’étiquette du groupe pour le replier à la largeur d’un seul onglet.
3. **Gérer :** un clic droit sur l’étiquette donne **Enregistrer et fermer le groupe**, **Dissocier les onglets** (« Ungroup tabs »), **Supprimer le groupe** (« Delete group »), **Déplacer vers une nouvelle fenêtre** (« Move group to new window »), **Copier les liens dans le groupe** (« Copy links in group ») et **Partager le groupe** (« Share group »).

<Section id="save" title="Comment enregistrer un groupe et le récupérer ?">

- **Enregistrer :** clic droit sur l’étiquette du groupe → **Enregistrer et fermer le groupe**. Les onglets se ferment ; le groupe est conservé.
- **Rouvrir :** clic droit sur un onglet → ajouter à un groupe → **Groupes fermés**, ou ouvrez la liste **Groupes d’onglets** (Firefox y affiche **Groupes d’onglets récents**, « Recent tab groups »), choisissez le groupe, puis **Rouvrir le groupe d’onglets** (« Reopen tab group »).
- **Supprimer :** **Supprimer le groupe** le retire définitivement.

<Catch>un groupe enregistré vit dans ce profil Firefox. Ce n’est pas une sauvegarde et, d’après ce que montrent les paramètres de synchronisation, il ne vous suit pas sur un autre appareil.</Catch>

<Section id="sync" title="Les groupes d’onglets Firefox sont-ils synchronisés ?">

Les paramètres **Synchronisation** (« Sync ») de Firefox 159 listent ce qui est synchronisé : **Marque-pages, Historique, Onglets ouverts, Mots de passe, Adresses, Moyens de paiement, Modules complémentaires et Paramètres** (« Bookmarks, History, Open tabs, Passwords, Addresses, Payment methods, Add-ons and Settings »). « Onglets ouverts » est décrit comme « Une liste de ce qui est actuellement ouvert sur tous vos appareils synchronisés ». Il n’y a pas d’entrée distincte pour les groupes d’onglets : ne comptez donc pas voir un groupe enregistré apparaître sur votre autre ordinateur.

Pour la même chose dans Chrome, consultez notre [guide des groupes d’onglets de Chrome](/blog/chrome-tab-groups), qui eux se synchronisent via un compte Google.

</Section>

<Section id="tabmerger" title="Gardez vos groupes pour de bon avec TabMerger">

[TabMerger](/features) fonctionne dans Firefox, Chrome et Edge, et garde les groupes que le navigateur ne peut pas garder :

1. Cliquez sur **Ajouter un groupe**, nommez-le, puis choisissez **Fusionner avec l’actuel** dans son menu **⋯** : toutes les fenêtres et tous les onglets ouverts y sont enregistrés.
2. Fermez les fenêtres. Le groupe reste, avec chaque onglet, et se recherche avec <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>.
3. Rouvrez un onglet, une fenêtre ou tout, à tout moment.
