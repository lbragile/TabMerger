<QuickAnswer>

Firefox에서 그룹을 만들려면 탭 하나를 다른 탭 위로 끌어다 놓거나 탭을 마우스 오른쪽 버튼으로 클릭하세요. 나중을 위해 남겨 두려면 그룹 레이블을 마우스 오른쪽 버튼으로 클릭하고 **그룹 저장 후 닫기**(Save and close group)를 선택합니다. 다시 열 때는 **닫힌 그룹**(Closed Groups)이나 **탭 그룹**(Tab groups) 목록을 이용합니다. Firefox Sync 설정에는 탭 그룹 전용 항목이 없으니, 모든 기기에서 같은 그룹을 쓰고 다른 모든 것과 함께 검색하려면 [TabMerger](/features)에 저장하세요.

</QuickAnswer>

<Section id="basics" title="Firefox 탭 그룹은 어떻게 작동하나요?">

Firefox 159 화면 문구 기준입니다.

1. **만들기:** 탭 하나를 다른 탭 위로 끌어다 놓거나, 탭을 마우스 오른쪽 버튼으로 클릭해 새 그룹에 추가합니다. Firefox가 **이름**(Name)과 색(파란색, 청록색, 회색, 초록색, 주황색, 분홍색, 보라색, 빨간색, 노란색)을 묻습니다.
2. **접기:** 그룹 레이블을 클릭하면 탭 하나 너비로 접힙니다.
3. **관리:** 레이블을 마우스 오른쪽 버튼으로 클릭하면 **그룹 저장 후 닫기**, **그룹 해제**(Ungroup tabs), **그룹 삭제**(Delete group), **그룹을 새 창으로 이동**(Move group to new window), **그룹의 링크 복사**(Copy links in group), **그룹 공유**(Share group)가 나옵니다.

<Section id="save" title="그룹을 저장하고 되찾으려면?">

- **저장:** 그룹 레이블을 마우스 오른쪽 버튼으로 클릭 → **그룹 저장 후 닫기**. 탭은 닫히고 그룹은 남습니다.
- **다시 열기:** 탭을 마우스 오른쪽 버튼으로 클릭 → 그룹에 추가 → **닫힌 그룹**. 또는 **탭 그룹** 목록을 열어(Firefox는 여기에 **최근 탭 그룹**(Recent tab groups)을 표시합니다) 그룹을 고른 다음 **탭 그룹 다시 열기**(Reopen tab group)를 선택합니다.
- **삭제:** **그룹 삭제**를 선택하면 완전히 사라집니다.

<Catch>저장된 그룹은 이 Firefox 프로필 안에만 있습니다. 백업이 아니며, 동기화 설정으로 보면 다른 기기로 따라오지 않습니다.</Catch>

<Section id="sync" title="Firefox 탭 그룹은 동기화되나요?">

Firefox 159의 **Sync** 설정에는 동기화하는 항목이 나와 있습니다. **북마크, 기록, 열린 탭, 비밀번호, 주소, 결제 수단, 부가 기능, 설정**(Bookmarks, History, Open tabs, Passwords, Addresses, Payment methods, Add-ons and Settings)입니다. ‘열린 탭’의 설명은 ‘모든 동기화된 기기에서 열린 탭의 목록’입니다. 탭 그룹 전용 항목은 없으므로, 저장한 그룹이 다른 컴퓨터에 나타날 거라고 기대하지 마세요.

Chrome에서의 같은 기능은 [Chrome 탭 그룹 가이드](/blog/chrome-tab-groups)를 참고하세요. Chrome 그룹은 Google 계정으로 동기화됩니다.

</Section>

<Section id="tabmerger" title="TabMerger로 그룹을 오래 보관하기">

[TabMerger](/features)는 Firefox, Chrome, Edge에서 작동하며 브라우저가 지키지 못하는 그룹을 보관합니다.

1. **그룹 추가**를 클릭해 이름을 붙인 다음, 그룹의 **⋯** 메뉴에서 **현재 상태와 합치기**를 선택하세요. 열려 있는 모든 창과 탭이 그룹에 저장됩니다.
2. 창을 닫으세요. 그룹은 모든 탭과 함께 남고, <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>로 검색할 수 있습니다.
3. 언제든 탭 하나, 창 하나 또는 전부를 다시 여세요.
