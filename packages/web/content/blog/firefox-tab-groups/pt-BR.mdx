<QuickAnswer>

Arraste uma aba sobre outra, ou clique com o botão direito em uma aba, para criar um grupo no Firefox. Para guardar o grupo para depois, clique com o botão direito no rótulo dele e escolha **Salvar e fechar grupo** (“Save and close group”); reabra em **Grupos fechados** (“Closed Groups”) ou na lista **Grupos de abas** (“Tab groups”). As configurações do Firefox Sync não têm uma entrada separada para grupos de abas; então, para ter os mesmos grupos em todos os dispositivos e poder pesquisá-los junto com todo o resto, salve-os no [TabMerger](/features).

</QuickAnswer>

<Section id="basics" title="Como funcionam os grupos de abas no Firefox?">

Segundo a própria interface do Firefox 159:

1. **Criar:** arraste uma aba sobre outra, ou clique com o botão direito em uma aba e adicione-a a um novo grupo. O Firefox pede um **Nome** (“Name”) e uma cor (azul, ciano, cinza, verde, laranja, rosa, roxo, vermelho ou amarelo).
2. **Recolher:** clique no rótulo do grupo para reduzi-lo à largura de uma só aba.
3. **Gerenciar:** clique com o botão direito no rótulo para ver **Salvar e fechar grupo**, **Desagrupar abas** (“Ungroup tabs”), **Excluir grupo** (“Delete group”), **Mover grupo para nova janela** (“Move group to new window”), **Copiar links em grupo** (“Copy links in group”) e **Compartilhar grupo** (“Share group”).

<Section id="save" title="Como salvo um grupo e recupero depois?">

- **Salvar:** botão direito no rótulo do grupo → **Salvar e fechar grupo**. As abas fecham; o grupo fica guardado.
- **Reabrir:** botão direito em uma aba → adicionar a um grupo → **Grupos fechados**, ou abra a lista **Grupos de abas** (o Firefox mostra **Grupos de abas recentes** ali, “Recent tab groups”), escolha o grupo e depois **Reabrir grupo de abas** (“Reopen tab group”).
- **Excluir:** **Excluir grupo** remove o grupo de vez.

<Catch>um grupo salvo fica neste perfil do Firefox. Ele não é um backup e, pelo que as configurações de sincronização mostram, não vai com você para outro dispositivo.</Catch>

<Section id="sync" title="Os grupos de abas do Firefox sincronizam?">

As configurações de **Sincronização** (“Sync”) do Firefox 159 listam o que é sincronizado: **Favoritos, Histórico, Abas abertas, Senhas, Endereços, Métodos de pagamento, Extensões e Configurações** (“Bookmarks, History, Open tabs, Passwords, Addresses, Payment methods, Add-ons and Settings”). “Abas abertas” é descrito como “Uma lista do que está aberto em todos os dispositivos sincronizados”. Não há uma entrada separada para grupos de abas, então não conte com um grupo salvo aparecendo no seu outro computador.

Para a mesma ideia no Chrome, veja o [guia dos grupos de abas do Chrome](/blog/chrome-tab-groups), que sincronizam pela Conta do Google.

</Section>

<Section id="tabmerger" title="Guarde seus grupos de vez com o TabMerger">

O [TabMerger](/features) funciona no Firefox, no Chrome e no Edge e guarda os grupos que o navegador não consegue guardar:

1. Clique em **Adicionar grupo**, dê um nome e escolha **Mesclar com as atuais** no menu **⋯** dele: todas as janelas e abas abertas são salvas no grupo.
2. Feche as janelas. O grupo continua lá, com cada aba, e dá para pesquisar nele com <Kbd>Ctrl</Kbd>+<Kbd>K</Kbd>.
3. Reabra uma aba, uma janela ou tudo, quando quiser.
